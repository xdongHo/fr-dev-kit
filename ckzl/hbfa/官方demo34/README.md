## 数据依赖

- **内置数据**样板：自包含（EmbeddedTableData），设计器直接打开预览，免数据连接。
- **需连接**样板：引用 FRDemo `销量` 表（地区/销售员/产品类型/产品/销量）——comm 环境没有 FRDemo 时只看 XML 结构，或把数据集换成 `kfgj/fzpy/rowdata_codec.py element` 生成的内置数据集。

## 配套文件

- `官方demo-catalog.md`：34 个样板的逐个明细（单元格坐标级关键实现说明）——改写前读它省一半时间。
- `官方demo-manifest.json`：样板静态摘要（公式文本/数据集类型/控件事件计数），机器可读。

## fr_check 已知误报豁免口径（2026-11-19 实测登记）

35 个样板中 19 个跑 `fr_check.py` 退出码 1，**全部为 L1.5 规则对官方 demo 语法的系统性误报，非样板缺陷**：
- `chart_style(doc-4138)`：把 XML 颜色节点**属性名**（FineColor/color/newColor/gradientEndColor）当颜色值判非法——官方 demo 的颜色结构是 FR 设计器标准写法；
- `template_param(doc-157)`：把 `$WW` 等内置/图表引用参数判为"无同名控件绑定"。

**处置**：复制样板做候选后，若 fr_check 仅报上述两类，属随样板结构带入的已知误报，可豁免放行（豁免方式=报告逐条注明"官方demo34已知误报"）；其他错误照常修。根治需修 L1.5 规则本身（chart_style 应只取颜色**值**属性、template_param 应内置参数白名单），已登记 CHANGELOG 待办。
