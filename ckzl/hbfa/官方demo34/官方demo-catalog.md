# FineReport 典型 DEMO 模板库（CPT）

34 个高覆盖率的普通报表 `.cpt` 样板，按能力域分组，每个独占一类高频能力、彼此不重叠，覆盖模板制作约 80% 的常见需求。
定位是**参照实现**：生成新模板时先按能力域找样板，从 `assets/demos/` 复制对应 CPT 为候选文件，读它的 XML 结构、公式写法和属性组合，再按需求改写，而不是整份套用。

## 使用约定

- 全部为**普通报表 CPT**（`WorkBook/Report/WorkSheet`），不含决策报表 `.frm`。
- `需连接` 标记的样板引用 `FRDemo` 数据连接，读结构前需先建连接（或只看 XML）；其余为内置数据集，设计器可直接打开预览。
- 样板只证明「这种写法在真实模板中存在且自洽」，是参照物，不是目标模板已正确实现的证明；交付前仍要走 `scripts/analyze_template.py` 与 `scripts/layout_preflight.py` 校验。
- 完整静态摘要见 `references/demo-manifest.json`（公式文本、数据集类型、单元格/控件/事件计数）。

## 样板明细

### 01 分组与列表基础结构 — `01-展示用列表，汇总用分组.cpt`
- 内置数据｜32 单元格
- **三级纵向分组 + 横向分类扩展 + 分组汇总**的最小完整样本，同时演示「按列表展开」与「按分组汇总」两种口径。
- 关键实现（已核实）：`r6 c0–c2` 为「大类/中类/小类」三层纵向扩展（`Expand dir="0"` + `FunctionGrouper`），`r5 c7` 为「季节」横向扩展（`dir="1"`），汇总格 `SummaryGrouper`；`=&E7` 跨格引用。省-市-区层级直接照此叠层。

### 02 双向扩展与合并单元格 — `02-双向扩展实现合并单元格.cpt`
- 内置数据｜30 单元格，2 事件
- 纵向分组 + 横向扩展并存时的合并单元格处理，含填报式「调查表」版式。
- 关键实现：`=uniquearray(value("ds", 1, 4, B14))` 去重取值控制横向扩展列；`REGEXP($$$, "^[-.0-9_]+$")`、`isnull($$$)` 做填写校验。

### 03 交叉表 — `03-交叉表横向合并单元格.cpt`
- 内置数据（`Embedded2`）｜8 单元格，2 事件
- 交叉表行列双维度下横向合并单元格的做法。

### 04 分栏 — `04-图表按分类扩展及报表分栏.cpt`
- 内置数据（`Embedded1`）｜26 单元格
- 图表按分类扩展 + 报表分栏（一页多栏）。`=B7/=C7/=D7` 跨格引用分栏内容。

### 05 / 06 嵌入式主子报表 — `05-主子报表下拉树联动-主模板.cpt` / `06-…子模板.cpt`
- 需连接｜主 18 单元格 2 控件，子 1 单元格 2 控件
- 嵌入式主子报表 + 下拉树联动。主模板 `=if(len($name)=0, "", JOINARRAY(B5, ";"))` 汇总多选、`=replace(mid(A5, 3, len(A5)-4), '","', ",")` 清洗下拉树多选值；子模板 `=$name1` 接收父级参数。
- 区别于 24/25 的超链接父子：这里是**一个模板内嵌多个报表块**的形态。

### 07 分组分页与票据打印 — `07-票据打印（按条件分组且每页固定10条）（内置数据）.cpt` ★
- 内置数据｜73 单元格，6 控件，3 事件
- **按分组切页、每组固定 10 条/页** 的完整票据版式，含金额大写、合计份数/金额。
- 关键实现（已核实）：分组主键单元格 `c=0 r=0`（`DSColumn` + `FunctionGrouper`）挂 `<CellPageAttr pageBeforeRow="true"/>` → **分组前分页**；固定行高 `1008000` + `<PaperSize>` 把每组压成 10 行/页；`<ReportPageAttr><HR F="0" T="18"/>` → **表头 0–18 行跨页重复**；`=CNMONEY({C15})` 金额大写、`=count({C20})` 份数、`=SUM({E20})` 合计。

### 08 层次坐标 — `08-层次坐标对应相减.cpt`
- 内置数据（2 个）｜2 sheet，42 单元格
- 层次坐标三种典型用法集中在一个文件里，最值得先读的公式样板。
- 关键实现：`=B7[!0;!0]A{B6 = $F6 && A7 = $A7} - D7[!0;!0]A{...}` 按同组条件定位后相减；`=eval("F3[;F3:" + &G2 + "]A")` 动态拼接偏移量。

### 09 组内排名 — `09-组内前五名条件汇总.cpt`
- 内置数据｜23 单元格
- 关键实现：`=count(D8[!0;!0]A{B8 = $B8 && D8 > $D8}) + 1` 组内降序排名；`=IF(E8 > 5, 0, D8)` 超前 5 置 0；`=SUM(F8)` 汇总。

### 10 累计与差额 — `10-差额累积.cpt`
- 内置数据（多 Embedded + NameTableData）｜2 sheet，34 单元格
- 关键实现：`=sum(maparray(range(1, &I6), eval("e7[;e6:" + item + "]A") - eval("g7[;g6:" + item + "]A")))` 用 `maparray` + 动态层次坐标做区间累计。

### 11 序号重排 — `11-列表数据按条件断开后，序号重新从1开始.cpt`
- 内置数据｜8 单元格
- 列表按某条件「断开」后，序号重新从 1 起算。关键实现：`=if(C7 = "是", "", &C7)` 用标记位重排。

### 12 横纵扩展编号 — `12-横纵扩展的条件属性编号.cpt`
- 内置数据（`Embedded1`）｜11 单元格
- 横向+纵向都扩展时的统一编号。关键实现：`=seq()` 生成序列，条件属性 `col() != 1` 控制显示。

### 13 条件属性染色 — `13-分组排名+条件属性给最大和最小排名设置背景颜色.cpt`
- 内置数据｜86 单元格，49 公式，2 控件
- 排名 + 条件属性染色的实战版式。关键实现：`=D5 / E5` 派生率值，条件属性按排名切换背景色。

### 14 动态隐藏列 — `14-列数据全为空时隐藏列(内置数据集).cpt`
- 内置数据｜5 单元格
- 关键实现（已核实）：辅助格 `=JOINARRAY(B3,' ')` 拼串，条件属性公式 `C3=0` 挂 `ColWidthHighlightAction` → **列宽置 0 达成隐藏**（不是切「隐藏列」属性）。

### 15 折叠树（条件属性 + JS 式） — `15-条件属性实现扩展列折叠树.cpt`
- 内置数据｜29 单元格，3 事件
- 纯 CPT 的层级折叠展开，**不依赖树节点按钮**，靠参数 + 条件属性 + JS 实现。关键实现：参数 `$aaa` 存展开节点路径，`inarray/split/GREPARRAY` 增删节点，条件属性 `inarray(&A8, split($aaa, ",")) = 0 / > 0` 控制行显隐。
- 适用：要**分页预览 / 分页打印 / 冻结 / 导出保留结构 / 自定义展开层级** 的场景（树节点按钮式在这些场景受限）。

### 34 折叠树（树节点按钮式，官方标准） — `34-树节点按钮折叠树.cpt` ★
- 需连接（`ds1` DBTableData + `Tree1` RecursionTableData）｜26 单元格
- 帮助文档《折叠树》（编号 1066）的**标准做法**，也是最简单可靠的方式。关键实现（已核实）：递归树数据集 `RecursionTableData` 派生 `FR_GEN_0~4` 层级字段 → 各层单元格父子格串联（第 N 层左父格 = 上一层）→ 每层挂 **`TreeNodeToggleButton`**（树节点按钮）→ 用 `TableDataDictionary` 数据字典把 ID 显示成名称 → 条件属性 `len($$$)=0` 隐藏空行 → `PreviewType="2"`（数据分析预览）才能展开收起。
- **限制**：仅「数据分析预览」生效，不支持冻结，导出 Excel 后展开按钮丢失。

**折叠树选型规则（skill 路由）**：默认走 **34 树节点按钮式**（官方标准、最简）；仅当用户明确要求分页预览/打印、冻结、导出保留、自定义展开层级或下拉框控制层级时，改用 **15 条件属性式**。

### 16 三级联动 — `16-一个数据集使用公式实现三级联动.cpt` ★
- 需连接（`DBTableData` + `RecursionTableData`）｜22 单元格，4 控件，2 事件
- 省/市/区级联经典方案：只用一个递归树数据集，靠公式过滤实现三级联动。参数 `$a/$b/$c`，单元格 `=$a` 取上级值作下级过滤条件。

### 17 控件联动 — `17-下拉框和下拉树控件联动.cpt`
- 内置数据｜1 单元格，2 控件，1 事件
- 下拉框与下拉树互相联动，选项由 SQL/公式动态拼装：`=EVAL("[" + JOINARRAY(sql("FRDemo", "select ..."), ",") + "]")`。

### 18 参数面板 — `18-年报月报日报.cpt`
- 需连接｜15 单元格，14 控件，4 事件
- 多控件参数面板：年/月/日/类型四类控件联动，切换年/月/日报口径，含「时间范围请选择…」提示文案。

### 19 参数维度汇总 — `19-根据参数进行不同维度下汇总.cpt`
- 需连接｜8 单元格，3 控件
- 按参数切换汇总维度/表头。关键实现：`=if(len($EMPID) = 0, '省份', '编号')` 动态表头。

### 20 动态列 — `20-js结合sql实现部分动态列效果.cpt`

### 21 填报校验 — `21-校验填报值只能填写表里面的字段.cpt`
- 内置数据（`ces`）｜2 sheet，14 单元格，1 控件，3 事件

### 22 单行提交 — `22-自定义按钮实现判断是控件是否为空不为空则实现单行提交.cpt`

### 23 插入删除行 — `23-分组插入行并设置首行删除行不可用.cpt`

### 24 / 25 父子模板传参 — `24-子模板返回父模板-父.cpt` / `25-…子.cpt`
