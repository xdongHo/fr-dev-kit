# 外部依赖与归档声明（开源版）

> 本套件由内部个人版裁剪开源而来。部分知识文档中仍有指向**历史外部工作区**的引用
> （练习仓 `practice/`、夜间学习区 `fr_overnight`、插件学习区 `fr_plugin_learn`、
> 桌面需求目录等），这些目录**不随套件分发**，引用仅作方法溯源，不是断链 bug。
> `kfgj/check_refs.py` 将这类引用降级为 WARN（已声明外部前缀/文件名），不影响闸门。

## 一、不随套件分发的外部工作区（引用仅为溯源）

| 前缀/名称 | 原性质 | 处置 |
|---|---|---|
| `practice/topic_*` | FR API 练习仓（历史学习产出） | 未随包；文档中"可移植 practice/…"为历史溯源 |
| `fr_overnight` | 夜间学习工作区（含 merge_batch 等中间产物） | 未随包 |
| `fr_plugin_learn` | 插件学习/复刻区 | 已迁出至套件主人本机归档 |
| `fr_dev_kit` / `fr_dev_kit_v1` / `fr_dev_kit_v2` / `fr_dev_kit_v2.1` | 旧版本工具包 | 已被本 comm 版取代，本机独立目录 |
| `reportlets` / `webapps` / `webroot` / `web-inf` | FineReport 服务器工程目录 | 属用户 FR 环境，不在套件内 |
| `临时/` | 历史临时归档 | 已清理 |
| `desktop` 前缀 | 本机桌面路径（历史需求拆分目录等） | 环境相关 |
| `_runs/` | 闸门报告/战役证据（可再生成） | gitignore，不入库 |

## 三、对开源使用者的含义

1. 文档中出现上述前缀的路径引用属正常现象（WARN-EXT），不需要修复；
2. 示例中的连接名/表名已统一改为 `demo_connection` / `fin_demo_*` 等中性名，
   请按你自己的数据库与 FR 工程替换；
3. 历史实证数字（如"某夜间批次回归"）为原主人环境的实测记录，仅作能力参考。
