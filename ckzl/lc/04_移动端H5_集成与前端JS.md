## 25. 移动端 / H5 预览

### 25.1 无头构造移动端预览链接

标准 URL 形态（doc-2432）：

- 普通报表：`http://<IP>:8075/webroot/decision/view/report?viewlet=<相对路径>.cpt`
- 决策报表：`http://<IP>:8075/webroot/decision/view/form?viewlet=<相对路径>.frm&op=h5`
- 端口固定 8075，上下文固定 /webroot/decision；`op` 取值：`view` 普通预览 / `write` 填报预览 / `h5` 移动端 H5，缺省默认普通。

> ⚠️ **决策报表（.frm）不支持填报预览**（填报预览仅 .cpt 可用）。
> ⚠️ H5 填报模板在决策系统挂载时，展示终端若只勾平板/手机而不勾 PC，HTML5 端报「该页面不对当前终端显示」——H5 填报实际走 PC 解析链路，必须勾 PC。无头脚本应显式传 IP，避免 `http://:8075/...`（丢 IP）。
> HTML5 端预览须装「HTML5 移动端展现插件」；App 端预览无需该插件。
> 来源:帆软官方帮助 doc-2432

**`__bypagesize__=false`（强制不分页，doc-3643）**：**凡模板使用移动端折叠展开树（或任何依赖初始折叠状态的移动端插件），预览/分发链接必须带该参数**，否则移动端强制分页会让第 2 页起的数据自动展开（「设了收起却是展开的」）。移动端分页是**服务端强制行为**、与模板配置无关，表现为「设计器里配置全对、移动端效果不对」。等价替代：预览类型改 `op=write`（填报）。建议链接构造器检测到模板单元格含树节点属性时自动追加该参数。
> 来源:帆软官方帮助 doc-3643

### 25.2 移动端 JS 超链注记

- JS 超链**本身支持移动端**，但 `window.open` / `window.parent.*` 等桌面接口不支持（官方原话：「要看接口支不支持移动端」）。生成移动端模板时应改用受支持的 FR 接口，而不是禁用整类 JS 超链（doc-4204 §2.4）。
- 来源:帆软官方帮助 doc-4204

### 25.3 移动端不支持项清单

| 不支持项 | 说明 |
|---------|------|
| 工具栏全屏预览 / 导出 | 见 doc-1695 注3 |
| 参数面板按钮触发全屏预览（requestFullscreen） | doc-1788 |
| 各导出方式 | 见 §23.4 |
| 扩展图表刷新方案（dealReloadChartAjax） | 见 07 §12.8（doc-3115） |
| 折叠展开树以外的分页依赖初始折叠状态 | 见 §25.1 `__bypagesize__=false` |

> 移动端（H5/App）**整体不支持全屏预览**；生成器遇「移动端全屏预览」需求应直接判不支持，而非尝试拼 JS。

> 来源:帆软官方帮助 doc-1788

### 25.4 中文参数 URL 编码提醒

凡经 URL 给报表传中文参数值（或 cpt 路径含中文），必须先做 percent-encode（`encodeURIComponent` / 等价 `URLEncoder.encode(value,"UTF-8")`）。kit 的「浏览器 localhost 预览校验」步骤若带中文参数，URL 未编码会乱码，可能误判「参数未生效」。IE（GBK）与 FR 服务器（UTF-8）编码不一致是根因；正式集成不能依赖终端用户换浏览器，而要靠编码函数。

> 来源:帆软官方帮助 doc-575

### 25.5 移动端主页（管理首页）

移动端主页 = 平台侧「管理系统>目录管理>管理首页」挂载模板，模板本身无特殊 XML 节点（普通 .frm/.cpt，无头构建不涉及平台配置）；唯一可复用构建点 = 主页模板标题（`ReportWebAttr#setTitle`，标题规则见 doc-724）。速查：

- HTML5 端主页 URL = `http://ip:端口号/webroot/decision/url/mobile`（验收判据）；
- 移动端主页模板功能限制：**不支持参数界面、翻页、收藏、离线、批注**——首页模板避免参数面板、一屏式布局；
- App 端更换主页挂载模板后**必须重新登录 App** 才显示新主页；
- 主页刷新：App 点「主页」图标刷新；H5 由 管理系统>移动平台>其它 配置（开启「底部首页切换按钮」→ 点主页图标刷新；不开启时「刷新设置」=按钮刷新/不刷新）。

> 来源:帆软官方帮助 doc-2508（与 doc-724 主页主题同族）

### 25.6 App 平台配置（内置服务器地址 / 升级提醒 / 消息代理）

Custom App（无法上架商城、只能分发下载链接）交付的必配项，三组字段的平台级配置（落 FineDB、无 XML）；**唯一安全写法 = `MobileConfig` 原地 mutate**（`getAppUpgradeConfig()` 字节码 `getfield + Conf.get()` 返回**本体**、非 clone，必须原地 mutate）：

```java
Configurations.update(new WorkerAdaptor(MobileConfig.class) {
    public void run() {
        AppUpgradeConfig c = MobileConfig.getInstance().getAppUpgradeConfig();
        c.setServerEmbedded(TRUE);
        c.setEmbeddedServerName(..);
        c.setEmbeddedServerUrl(..);
        c.setAppUpgradeOn(TRUE);
        c.setBaseVersion(..);
        c.setMinVersion(..);
        c.setUpgradeTitle(..);
        c.setUpgradeLog(..);
    }
});
MobileConfig.setAppMsgProxy(String); // 消息代理：内网/离线部署必配，否则推送外联帆软云
```

- `<init>` 实读默认值：appUpgradeOn=false / baseVersion=0 / serverEmbedded=false / 5 个 String 全 `""`；
- ⚠️ **禁止走 `MobileService#setAppUpgradeConfig(Bean)` 路径**：其 Worker 有两道嵌套 ifeq 门（isAppUpgradeOn false 则后 7 字段全不写、isServerEmbedded false 则 embeddedServerName/Url 不写），「只改了子项、整段静默丢弃」——decision Bean 写入铁律见 08 §19.1；
- 排障两条（App 收不到推送 / 内置服务器地址改了不生效）见 08 §16.2。

> 来源:帆软官方帮助 doc-4252

## 26. 嵌入与被嵌入（集成）

分两个方向：

**① 被嵌入**——宿主页：

```html
<iframe name="reportFrame" src="{origin}/{context}/decision/view/report?viewlet={路径}&op=view"></iframe>
```

- 同工程可用相对路径、跨工程必须绝对地址；
- 前置条件（单点登录、模板认证、关闭 Security Headers）属平台配置，jar 内无对应可编程类（`Security`/`XFrame`/`FrameOptions` 全部 0 命中），**不要试图用 Java 关闭**。

> ⚠️ **勘误（doc-879，2026-08-09）**：上一条「关闭 Security Headers……jar 内无对应可编程类……不要试图用 Java 关闭」**已被证伪**——关闭 Security Headers 实际有两条一等公民 Java API 路径：① 底层 `com.fr.security.WebSecurityConfig`（fine-core-10.0.jar，extends DefaultConfiguration）→ `getInstance().setFrameOptionsEnabled(false)` / `setContentTypeOptionsEnabled(false)`，`extends DefaultConfiguration` ⇒ 直接 setXxx 不落 FineDB，**写入侧必须自行包** `Configurations.update(new Worker(){ run(){...} targets(){ return new Class[]{WebSecurityConfig.class}; } })`；② decision 层 `com.fr.decision.webservice.v10.security.SecurityService` + `SecurityBean`（fine-decision-10.0.jar）→ `setSecurityBean(bean)` 字节码**已自包事务**（内部 `new SecurityService$1 → Configurations.update`），调用方无需再包，且字段集是路径①的超集（多 HstsEnabled/SecuredResponse/VerifyTokenIp 三项 decision 专属策略）。路径②是**全量覆盖**型 API（12 字段逐个 `getInstance().setXxx(bean.isXxx())`、无 ifnull 守卫，与 doc-3474 MobileOtherSettingsService 同构），必须 read-modify-write：`bean = svc.getSecurityBean()` → mutate → `svc.setSecurityBean(bean)`，**禁止 `new SecurityBean()` 只填部分字段**（否则其余 10 项刷成 false 默认值）。生产建议改用 `WebSecurityConfig.setContentSecurityPolicyHeader("frame-ancestors 'self' https://oa.example.com")` 精确放行而非关 X-Frame-Options（08 §16.11 已有此建议，此处补字节码依据：该方法真实存在、String 型 Holder）。实践示例：`practice/topic_879_java/SecurityHeaderToggleBuilder.java`。

> 来源:帆软官方帮助 doc-879

**② 嵌入**——网页框控件 `com.fr.form.ui.IframeEditor`（`extends FieldEditor`，`public static XML_TAG="Iframe"`，`getXType()="iframe"`，`setSrc/setParameters(ParameterProvider[])/setOverflowx/setOverflowy/supportMobile`），XML 属性实读 `src`/`overflowx`/`overflowy` + `<Parameters>`：
- **src 填模板路径时引擎自动转 reportlet URL，不必手拼**（`createJSONConfig` ldc 含 `'reportlet'`）。

跨文件契约：`Hyperlink#setTargetFrame(name)` 必须与宿主页 `<iframe name=...>` 同名；不同名不报错、只是改在新窗口打开。

> 来源:帆软官方帮助 doc-918

## 28. 超链接装配补充

### 28.1 超链 9 类对照表补充：XML 子标签 + 属性名

对照表增加「XML 子标签 + 属性名」维度（真正承载字段的是 `JavaScript` 类的**下一层子节点**，不记就无法拼出可用的 XML）：

- 邮件行：`com.fr.js.EmailJavaScript` → 子节点 `<EmailJS mailTo cc bcc title mainText showTplContent/>`（注意各超链类的子标签名都不是类名直译：`EmailJavaScript` → `EmailJS`）；
- 公共外层：`<NameJavaScriptGroup><NameJavaScript name="..."><JavaScript class="...">`（`NameJavaScript#readXML` 兼容旧标签 `Hyperlink`）。

> 来源:帆软官方帮助 doc-4195

### 28.2 超链参数传递（9 种超链共有）

挂在父类 `com.fr.js.AbstractJavaScript` 上：

- 参数构造 `new com.fr.base.Parameter(String, Object)` → `setParameters(com.fr.stable.ParameterProvider[])`（**无 addParameter**）；
- 值有两条通道：常量（服务端 quoteFrObject 加引号）与公式 `new com.fr.base.Formula("B3")`（落成 `(FR.formulaEvaluator(..., <recalc>))()`，recalc 即 `setShouldRecalculate(boolean)`）；
- 消费侧：对 `JavaScriptImpl` 是 JS 形参名，对 `ReportletHyperlink`/`WebHyperlink` 则是 URL query 参数。

> 参数值可以是公式（「传当前行的值」）官方文档全程未演示，只给常量字符串；kit 生成行内超链时应支持公式值。

> 来源:帆软官方帮助 doc-4195

### 28.3 长 JS 外置：`addJSImort`（官方拼写错误）

`com.fr.js.JavaScriptImpl#addJSImort(String path)`（⚠ FR 官方方法名拼写错误，不是 addJSImport）→ .cpt 里落 `<JSImport>` 节点（位置在 `<Parameters>` 之后、`<Content>` 之前），运行期先生成 `FR.$import("<path>", 'js');` 再执行 Content。

> 比整段塞 `setContent` 体积小、可复用、改一次不用重生成所有 cpt；拼写坑必须写进 kit，否则模型会写成 addJSImport 而编译不过。

> 来源:帆软官方帮助 doc-4195

## 29. 图表 JS 接口速查（doc-4067）

图表交互类需求的无头构建落点 = 把 JS 挂到**图表事件**（点击/钻取后事件）内嵌；接口清单（官方 FAQ §3.3 全部为 JS 接口）：

- 获取图表对象：`_g().getChartByName("chart0")`（chartName 与 Java 侧 `Chart#setChartName` 对应，单元格图表骨架见 08 §16.15）；
- 图表排序、自动数据点提示轮播、显示部分系列、图表刷新；
- 地图类：地图数据点轮播、JS 移动地图中心点、钻取；
- ⚠️ 刷新 API 区分：普通图表 `chart.dataRefresh()`；**扩展图表不支持 dataRefresh()**，必须 `FR.Chart.WebUtils.getChart("chartN").dealReloadChartAjax()`（07 §12.8，且不支持移动端）。

> 来源:帆软官方帮助 doc-4067

## 30. 前端 JS 请求 API：FR.ajax（doc-602）

`FR.ajax(options)` = 封装 jQuery.ajax 的浏览器端 API（**无 com.fr.* Java API 可直接调用**，无头构建的落点是「把含 FR.ajax 的 JS 注入 .cpt」）：

- options：`url` 必填；`data`（KV 串或对象，**自动做中日韩文编码**，GET 自动拼 URL）；`type`（POST/GET，默认 GET）；`dataType`（xml/html/script/json/text/jsonp，**移动端不支持 xml/html/script**）；`success(data,textStatus)` / `error(xhr,textStatus,errorThrown)` / `complete(xhr,textStatus)`（成功/失败后均调用，以 `textStatus=='success'` 判成功）；`timeout` 毫秒；`async`（默认 true，false 会锁浏览器）；回调内 `this.xxx` 可取该请求的选项值。
- 典型范式：请求 `/webroot/decision/login/info` + `FR.jsonDecode(res.responseText)` 实现**不刷新页面探测登录态**（`u.data.ip/time/city` 返回上次登录 ip/时间/城市）；跨域用 `dataType:"jsonp"`。
- 无头注入点两个：① 单元格超链 `com.fr.js.JavaScriptHyperlink`（XML `<HyperLinkList><HyperLink class="com.fr.js.JavaScriptHyperlink"><Content><![CDATA[js]]></Content></HyperLink></HyperLinkList>`，setContent 签名与单元格挂载入口【待核验】）；② 按钮「点击」事件（XML `<Event><Listener eventname="click"><Script><![CDATA[FR.ajax(...)]]></Script></Listener></Event>`，控件事件精确 Listener 类名【待核验】——核验样本：设计器新建按钮加「点击」事件后导出 .cpt 抓取 XML）。

> 来源:帆软官方帮助 doc-602
