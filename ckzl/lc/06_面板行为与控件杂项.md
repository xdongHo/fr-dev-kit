## 31. 参数面板折叠与高度联动（doc-2938）

> 来源: 帆软官方帮助 doc-2938

四条要点：

1. **高度双写入口**：`FormParameterUI.setDesignSize(Dimension)` 是**高度唯一入口**（→ `<DesignAttr height>`，运行时即 `FR.parameterContainerHeight`）；`WParameterLayout.setDesignWidth(int)` 只管宽，两者不同步；
2. **折叠高度是派生量不是入参**：= designH − 被隐藏行的垂直占位，生成器用 BoundsWidget 坐标算，**别照抄官方魔数 105**；
3. **折叠动作要四件事一起改**：`.parameter-container` height、`FR.parameterContainerHeight`、`#content-container` 的 top 与 height——漏任一项都是错位；冻结表另需 `FR.layoutFrozen`；
4. **三条禁区**：分页预览 + 冻结自适应差 / 填报多 sheet 不要用 / 不支持移动端。

## 32. 参数面板显示/隐藏的两条路径（doc-2188）

> 来源: 帆软官方帮助 doc-2188

| 路径 | 做法 | 行为 |
|------|------|------|
| 静态（headless 首选） | `WParameterLayout.setDisplay(boolean)` → `<WParameterLayout display>` | 预览时不渲染、**无占位**，纯 Java 一行、零副作用 |
| 运行时可切 | 工具栏自定义按钮 JS 切 `.parameter-container` 的 `visibility` | 保留占位空白、不回流；改 `display:none` 才收占位但需实测自适应 |

> ⚠️ 选路判据：用户是否需要**运行时切换**——不需要就静态 `setDisplay`，不要一上来就上 JS 方案（白白写出 `<WebPageContent>` 并脱离全局配置）。
### 32.1 showWindow 总开关（ReportParameterAttr 级，doc-2025）

§32 只记 `WParameterLayout.display` 一条静态隐藏路径；补 doc-2025「showWindow 总开关」——参数面板「突然不显示」的根因形态：

- **参数面板整体显示开关** = `<ReportParameterAttr showWindow="true|false">`（官方原文：false 改 true 即修复）；Java 侧 `com.fr.main.parameter.ReportParameterAttr#setShowWindow(boolean)`（签名未核实）；
- **生成规范：无头生成器对含参数面板模板一律显式写 `showWindow="true"`**（缺省行为未核实，显式最稳妥）——漏写/误写 false 会复现「面板不显示且零报错」；
- 与 §32 `WParameterLayout.setDisplay`（布局级静态隐藏）**区分层级**：showWindow 是面板整体开关、display 是布局显示属性；两开关是否为同一 GUI 复选框的双重序列化**未核实，列入核验待办**；
- 修复动作 = 文本编辑器改 showWindow 值 + **UTF-8 无 BOM 保存**（文档硬性要求，与 kit 铁律 A 一致）；
- **常见问法**：「点击查询前不显示报表内容」怎么设置？→ 即本节参数面板隐藏/显示两条路径（§32 静态 `WParameterLayout.display` / §32.1 `showWindow` 总开关）；该 GUI 复选框与两开关的对应关系未核实（见上行核验待办），headless 生成首选 §32 静态路径。

## 33. 单元格控件查询（doc-1828）

> 来源: 帆软官方帮助 doc-1828

把查询入口从参数面板搬到报表正文单元格时，生成器须同时产出**三件套**（缺一静默失效）：

1. **正文单元格下拉框控件**（如 C2，`<Widget widgetName="area">` + `<Dictionary><DSColumn>`）挂「编辑后事件」桥接 JS；
2. `<ParameterUI>` 内**同名 `visible="false"` 隐藏控件**（面板高度设 0 彻底隐藏）；
3. 数据集 SQL 用 `1=1 ${if(len(area)==0,"","and 地区='"+area+"'")}`。

桥接 JS 逐字：

```javascript
var a=this.getValue();
var b=contentPane.parameterEl.getWidgetByName("area");
b.setValue(a);
_g().parameterCommit();
```

> 与「单元格 `nofilter` 过滤」（doc-2394 方法①）互补：这是「单元格控件 → 参数面板桥接 → 重查」机制，用于「下拉框嵌在报表里筛选」。

## 34. 控件属性 → 继承层 → setter → XML 三方对照（doc-255 / doc-4195）

> 来源: 帆软官方帮助 doc-255 / doc-4195

FR 控件的属性 setter **几乎都不在控件类自身**，而分散在继承链上（`com.fr.form.ui.ComboBox` dump 出来只有 `setWidgetValue`/`setDependenceMap` 两个属性 setter）。按继承层级而非按控件建表：

| 继承层 | setter → XML | 备注 |
|--------|--------------|------|
| `Widget` | `setWidgetName`/`setEnabled`/`setVisible` → `<WidgetName>`/`<WidgetAttr disabled invisible>` | **⚠ Java 正义、XML 反义**（enabled↔disabled 语义反相） |
| `FieldEditor` | `setAllowBlank`/`setErrorMessage`/`setFontSize` → `<allowBlank>`/`<EMSG>`/`<fontSize>` | 后两者分别 `isNotBlank`、`!= DEFAULT_FONT_SIZE` 才写出；**字体大小挂在公共父类上，填报控件其实也能设，只是设计器不给入口** |
| `RegexFieldEditor` | `setRegex`/`setRegErrorMessage` → `<Reg class=..>`/`<regMsg>` | — |
| 各具体控件 | 自有层 | — |

**4 处名字不一致（doc-255）**：`removeRepeat`→`<noRepeat>`、`errorMessage`→`<EMSG>`、`waterMark`→`<watermark>`（小写）、`setEnabled/setVisible`→`<WidgetAttr disabled= invisible=>`（**语义反相**）；以及 **2 处条件写出**：`DelayTime`（`delayTime==200` 时不写）、`fontSize`（等于 `DEFAULT_FONT_SIZE` 时不写）——做「生成 → 读回 diff」校验时会把「等于默认值故不写」误判为丢失。

**填写规则 8 选项 ↔ `com.fr.form.ui.reg.*` 8 实类**（doc-4195）：邮编是 `PostCardReg` 不是 PostCodeReg；邮箱 `MailReg` 在 fine-core jar 而非 engine jar。

## 35. GUI 复选框 ↔ Java 哨兵值（doc-259）

> 来源: 帆软官方帮助 doc-259

FR 设计器上大量「需要 X / 启用 X」型**复选框在 Java API 侧没有对应 boolean**，而是用极值/null 哨兵表达「未启用」。已确认实例：`NumberEditor.minValue/maxValue` 默认 `∓Double.MAX_VALUE`（常量池实读 `∓1.7976931348623157E308`），`writeXML` 判「不等于哨兵才输出属性」。

> ⚠️ **封装生成器时必须提供显式复位方法**（如 `clearRange()`），**禁止用 `0`/空串当「未设置」**——把 GUI 步骤直译成 Java 时，「取消勾选最小值」最自然的写法是 `setMinValue(0)`，而这实际是「把下限设成 0」，语义完全相反；且模板能生成、校验能通过、预览也正常，只在用户输入负数被拦时才暴露（继「XML 属性名≠字段名」之后的第四类静默失败源）。

## 36. 下拉框选中后复选框默认全选（doc-3512）

> 来源: 帆软官方帮助 doc-3512

「下拉框选中后目标复选框默认全选」联动范式：

- 源控件挂「编辑后（afteredit）」事件 JS，用 `FR.remoteEvaluate('=sql(...)')` 取目标 ComboCheckBox 全部选项并 `setValue` 全选；
- 目标 ComboCheckBox 须 `ReturnValues` `Type=string` + `Separator=','`；
- 联动依赖部署期关闭「管理系统>安全管理>安全防护>脚本调用公式限制」（否则预览报「此调用存在安全风险」）。

> 与 §30.1 求值时机对照呼应：此处必须用 `FR.remoteEvaluate`（事件触发时求值），不能用 `${=}`（面板生成时求值，取不到用户刚选的值）。practice/topic_3512 已沉淀可运行注入器。
