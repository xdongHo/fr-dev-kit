## Web 集群配置 > 平台操作（3篇）

### 106. 配置开启集群

- **doc-view ID**: 2443
- **路径**: 部署集成 > Web 集群配置 > 平台操作 > 配置开启集群
- **核心概念**: - 新增「设为基准节点」按钮，基准节点支持热切换 - 缓存逻辑优化 - 在使用过程中，状态服务器、文件服务器等组件出现问题导致工程无法访问时， 不会自动切换成节点内存、节点间同步，将主动进行消息提示 - 重启过程中，若状态服务器、文件服务器连接失败，将进入部署向导页面，可修改相关配置 - 单个工程已不能满足用户需求，用户需要较高的并发支撑性能。

**业务场景四要素：**
- 统计指标方案: 不涉及（本文为部署/集成/运维操作说明，无具体统计指标）
- 业务场景: 注：「节点间自动同步」不适用于多节点，否则会因节点间通信问题影响使用，仅两个节点时使用，大于两个节点时需使用「文件服务器共享」。
- 人员岗位: 未在文中明确指定（面向系统管理员/运维人员/实施人员）
- 功能应用场景: 注：「节点间自动同步」不适用于多节点，否则会因节点间通信问题影响使用，仅两个节点时使用，大于两个节点时需使用「文件服务器共享」。
