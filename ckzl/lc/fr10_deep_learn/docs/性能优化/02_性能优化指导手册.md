### 2. 性能优化指导手册

- **doc-view ID**: 435
- **路径**: 性能优化 > 性能优化指导手册
- **核心概念**: 诸如报表加载时间长、系统内存溢出、服务器崩溃等性能问题，影响因素可能有很多，很多时候想要排查也是无从下手。为了帮助用户在遇到这些性能问题时，可以进行自检调优，现给出性能优化指导方案，可以根据步骤排查工程性能问题，优化系统性能。

**业务场景四要素：**
- 统计指标方案: 不涉及（本文为性能优化/技术说明文档，无具体统计指标）
- 业务场景: 该方案不适用的场景：单模板的 SQL 不多；有 SQL 执行复杂，数据库性能不好；有模板的 SQL 实际没有使用。
- 人员岗位: 未在文中明确指定（面向报表开发者/运维人员/系统管理员）
- 功能应用场景: 详情参考 性能优化插件 下的并行取数功能。

**关键代码/公式/API：**
- 配置文件/参数: `-Dfineio.direct_mem_limit`
- 配置文件/参数: `-Dfineio.read_mem_limit`
- 配置文件/参数: `-Dfineio.write_mem_limit`
- 配置文件/参数: `-Dfineio.cache_mem_limit`
