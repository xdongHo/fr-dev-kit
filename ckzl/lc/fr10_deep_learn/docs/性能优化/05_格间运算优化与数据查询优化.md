## 优化模板 > 数据查询优化（2篇）

### 10. 巧用参数注入

- **doc-view ID**: 1000
- **路径**: 性能优化 > 优化模板 > 数据查询优化 > 巧用参数注入
- **核心概念**: 在实际应用会出现多数据集关联报表，报表的展现速度会很慢，使用 SQL 语句关联多个数据表又十分复杂。FineReport 提供「动态参数注入」功能，可加快报表的展现速度，又不用编写复杂的 SQL 语句。

**业务场景四要素：**
- 统计指标方案: 新建数据集，SQL 语句为： select a.订单ID,订购日期,到货日期,发货日期,产品ID,单价,数量,进价,折扣 from 订单 a,订单明细 b where a.订单ID=b.订单ID
- 业务场景: 注：动态参数注入只适用于「小数据量」的模板加快速度使用。大数据量的模板反而会降低加载速度。
- 人员岗位: 未在文中明确指定（面向报表开发者/运维人员/系统管理员）
- 功能应用场景: 注：动态参数注入只适用于「小数据量」的模板加快速度使用。大数据量的模板反而会降低加载速度。

**关键代码/公式/API：**
- SQL: `SELECT * FROM 订单；ds2：SELECT * FROM 订单明细`
- SQL: `SELECT * FROM 订单明细 where 订单ID =${orderid}`
- SQL: `select a.订单ID,订购日期,到货日期,发货日期,产品ID,单价,数量,进价,折扣 from 订单 a,订单明细 b where a.订单ID=b.订单ID`
