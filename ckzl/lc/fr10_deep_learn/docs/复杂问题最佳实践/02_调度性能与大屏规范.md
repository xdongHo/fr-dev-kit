# 复杂问题最佳实践 · 调度性能与大屏规范

> 来源: [拆分图谱](../00_拆分图谱与来源.md) §复杂问题最佳实践


## 五、定时调度与自动化

### 5.1 定时任务前置约束

| # | 约束 | 原因 |
|---|------|------|
| 1 | 所有模板参数有默认值 | 调度侧不弹参数面板 |
| 2 | 不依赖前端交互控件取值 | `_g()`/`window.contentPane` 在调度渲染时不可用 |
| 3 | 数据集执行时间受 `ScheduleSettingConfig.taskTimeout` 限制 | 超时则任务失败 |
| 4 | 按用户分发结果，过滤条件需用 `$fine_username` | 用户级数据隔离 |

### 5.2 定时调度故障排查

**两级判定口诀：**

**第一级「有没有件」**：看 `%FR_HOME%/webapps/webroot/WEB-INF/schedule/<任务名>/`
| 现象 | 根因 | 解法 |
|------|------|------|
| 有件但发不出去 | 清理策略/通道问题 | 检查发送配置 |
| 有件但 0KB | 文件名公式展开超 255 字符 | 缩短文件名公式 |
| 根本没件 | 行式引擎缺插件 | 安装行式引擎插件 |

**第二级「件对不对时候」**：
| 现象 | 根因 | 解法 |
|------|------|------|
| 产物时刻整体偏移 N 小时 | JVM 时区 | `-Duser.timezone` |
| 数据窗口错一天 | 服务端日期公式 + 时区错配 | 统一时区配置 |

### 5.3 .frm 定时导出约束

- .frm 只能选「预览」执行类型
- 自适应布局在定时调度结果中失效（按固定大小导出）
- Word 附件不支持 FRM 图表组件
- 组件间 ≥8px 间隙，否则定时导出报 RuntimeException

### 5.4 定时调度避坑指南

| 坑 | 说明 | 解决方案 |
|----|------|----------|
| 定时配置不落 .cpt | 存在 FineDB，静态检查管不到 | 部署前人工确认 |
| 前端依赖失效 | `_g()` 在调度渲染时不可用 | 业务逻辑下沉到数据层 |
| 时区偏移 | 产物时间错位 | 统一 JVM 时区 |
| 0KB 产物 | 文件名公式超 255 字符 | 缩短公式 |
| 自适应布局失效 | 定时导出按固定大小 | 使用绝对布局 |
| widgetName 必须全大写 | 写小写不报错、导不出来 | 统一大写命名 |

## 六、性能优化总纲

### 6.1 SQL 层优化

| 策略 | 说明 |
|------|------|
| 参数化查询 | `${if(len(para)==0, "1=1", "字段='"+para+"'")}` 避免全表扫描 |
| 级联参数格式化 | ORDER BY 必须在 `${if(...)}` 宏之后 |
| 数据集复用 | 多个单元格引用相同数据时使用同一数据集 |
| 共享数据集 | 多模板共用相同查询使用「服务器数据集」 |
| 禁止 HSQL 连接 | 内存争用导致卡顿 |

### 6.2 渲染层优化

| 策略 | 说明 |
|------|------|
| gotoPage `noCache="lazy"` | 只重算当前块（推荐默认） |
| 延迟加载 | `afterinit + setTimeout` 延迟非核心组件 |
| 组件合并数据集 | 减少并发查询次数 |
| 条件属性数量控制 | 单单元格不超过 5 个 |

### 6.3 导出层优化

| 策略 | 说明 |
|------|------|
| 行式引擎 | 大数据量导出使用行式引擎插件 |
| 流关闭 | OutputStream 必须关闭后再落盘 |
| 避免 JDK 问题版本 | jdk1.8.0_262/8u231/8u192 不建议用于导出 |
| 图片尺寸限制 | 宽高任一 >56364px 触发 imageSizeExceedsLimit |

### 6.4 部署层优化

| 策略 | 说明 |
|------|------|
| Tomcat 8.5.57+ | 最低兼容版本 |
| URIEncoding=UTF-8 | 防止中文乱码 |
| JVM 参数 | `-Dfile.encoding=UTF-8 -Djava.awt.headless=true` |
| 连接池参数 | maxConn/maxWaitTime/minConn 合理设置 |
| Oracle processes | 上限需关注（`V$process` / `V$parameter`） |

## 七、故障排查速查表

### 7.1 模板类故障

| 错误信息 | 原因 | 解法 |
|---------|------|------|
| `11300003 单元格计算死循环` | 公式行偏移引入循环引用 | 检查公式引用链 |
| `Index: 0, Size: 0` | `TableDataMap` 自闭合 | 使用完整 `<TableDataMap>...</TableDataMap>` |
| 下拉为空 | Dictionary class 错误 | 用 `TableDataDictionary` + `NameTableData` |
| 字体过大 | FRFont size 参数理解错 | size 是 pt 值，不是 pt×8 |
| 行高不协调 | FU 换算错误 | 表头 1442289(10mm), 明细 1153643(8mm) |
| 冻结不生效 | columnrow 索引 | 行号需 +1 |

### 7.2 部署/运行时故障

| 错误信息 | 原因 | 解法 |
|---------|------|------|
| `ClassNotFoundException: LicenseContext` | 独立运行 FR API | 忽略，文件正常生成 |
| 级联参数静默失败 | Parameter 自闭合 / SQL 未多行格式化 | 检查 XML + SQL 格式 |
| 中文乱码 | JDBC URL 未带 characterEncoding | 追加 `?useUnicode=true&characterEncoding=utf8` |
| WebSocket 启动失败 | 端口被占用 | 等 2 分钟再重启 |
| `Database is not initialized` | **内存不足**（不是数据库问题） | 检查 ENV_HOME 可写性 + JVM 内存 |
| `Can't load AMD 64-bit .dll` | JDK 位数不匹配 | 统一 32/64 位 |

### 7.3 导出/打印故障

| 错误信息 | 原因 | 解法 |
|---------|------|------|
| 导出文件 0 字节 | OutputStream 未 close | 确保流关闭后再落盘 |
| JS 效果导出后消失 | 符合预期 | 效果必须落到模板/后台属性 |
| FineDB 锁导致导出失败 | 内置 HSQL 不支持多线程 | 迁外接库 |
| Oracle 丢列 | colNames 大小写不一致 | 按 SQL 返回列名对齐 |
| 空日期导出失败 | JDBC 驱动对空日期处理差异 | JDBC URL 追加 `zeroDateTimeBehavior=convertToNull` |

## 八、决策报表(.frm)铁律

| # | 铁律 | 静默失效表现 |
|---|------|------------|
| 1 | WidgetName 全表单唯一（body+参数面板共用命名空间） | `getWidgetByName` 返回 undefined 无报错 |
| 2 | JS 取组件一律 `_g().getWidgetByName(name)` | `this.options.form` 跨容器取不到 |
| 3 | 组件必须显式命名 | JS 永远够不着 |
| 4 | 两套 `setCompState` 同名不同义 | 设错对象静默失效 |
| 5 | 隐藏控件桥接不可删除 | 删掉即参数无处承载 |
| 6 | .frm 控件即参数，无需 `parameterCommit` | 套用 .cpt 逻辑会失败 |
| 7 | `value()` 不联动 | 改了输入下游不动 |
| 8 | 组件间 ≥8px 间隙 | 定时导出报 RuntimeException |
| 9 | 报表块不支持 `afterinit` 事件 | 事件静默不触发 |

## 九、.frm 大屏设计规范

### 9.1 设计分辨率

| 分辨率 | percent 系数 | 场景 |
|--------|------------|------|
| 1920×1080 | 1.2 | 标准大屏（最常见） |
| 1536×864 | — | 大屏变体 |
| 1440×960 | 1.0 | 分析面板 |
| 1366×768 | 0.9 | 驾驶舱 |

### 9.2 大屏架构模式

```
1920×1080 设计 → 960×540 body（ResolutionScaling=1.2）
├── 顶部标题区（Label/表格）
├── 左侧面板（KPI 指标）
├── 中央主图（地图/主图表）
├── 右侧面板（明细/辅助图表）
├── 底部图表行（趋势/对比）
└── 右下补充（补充信息）
```

### 9.3 命名规范

| 前缀 | 类型 | 示例 |
|------|------|------|
| `reportN` | 报表块 | report0, report1 |
| `chartN` | 图表块 | chart0, chart1 |
| `labelN` | 标签 | label0, label1 |
| `tabN` | Tab 块 | tab0, tab1 |
| `para_N` | 参数控件 | para_area, para_month |

### 9.4 Tab 轮播配置

```xml
<ChangeAttr enable="true" changeType="button" timeInterval="5" .../>
```
- `enable="true"` → 启用自动切换
- `timeInterval="5"` → 5 秒切换
- 隐藏标题区：`<BoundsAttr height="0"/>`

## 十、论坛高频问答补充（batch10 来源）

> 来源：帆软论坛问答对比分析 batch10（2026-08-25）
> 涵盖报表美化、数据集SQL、决策报表、填报、定时调度、数据连接、高级报表、集成扩展、交互钻取等

### 10.1 报表美化
- 分组报表隔行变色用 `COUNT(A1)%2=0` 而非 `ROW()%2=0`（避免分组内错乱）
- FR11 原生支持斑马纹样式，无需条件属性
- 斑马纹在填报模式下不影响数据

### 10.2 数据集SQL与安全
- **数据集参数比模板参数更安全**：预编译防SQL注入（`${}` 模板参数是字符串拼接）
- 日期型参数在SQL中要用引号包裹：`WHERE date >= '${start}'`
- 大量IN参数改用临时表关联提升性能（避免IN列表过长）
- 避免WHERE中对字段使用函数（导致索引失效）

### 10.3 决策报表自适应
- 缩放后文字模糊：用CSS font-size基准值解决
- 组件重叠：调整z-index或改用Tab布局分页
- FR11支持多分辨率预览切换（设计时可选1920/1366/移动端）
- 1920设计1366显示：用"横向自适应"缩放逻辑

### 10.4 填报交互
- `location.reload()` 可能导致**重复提交**，改用 `contentPane.gotoFirstPage()` 更安全
- FR11支持填报成功后原生跳转设置
- 刷新时需注意保留URL参数

### 10.5 定时调度与邮件
- 定时调度支持Cron表达式精确控制执行频率
- 支持从数据库表读取邮件列表实现批量发送
- 可通过前置SQL实现条件发送（如：有新数据才发送）
- 邮件主题支持 `${参数名}` 变量
- SMTP需注意465(SSL)/587(TLS)端口选择

### 10.6 数据连接
- PostgreSQL连接需配置`pg_hba.conf`的IP白名单
- URL可加 `?currentSchema=myschema` 指定Schema
- URL可加 `?characterEncoding=UTF-8` 解决编码问题
- FR11支持在线下载数据库驱动（无需手动放jar）

### 10.7 动态列
- FR10+支持"动态数据列"功能（报表属性→高级→勾选）
- 动态列数量建议不超过100列（性能瓶颈）
- Java程序数据集方案最灵活但开发成本最高

### 10.8 嵌入网页/iframe
- 跨域iframe需目标站点配置CORS
- `X-Frame-Options` 头部控制是否允许iframe嵌入
- HTTPS报表不能嵌入HTTP页面（混合内容被浏览器拦截）
- 决策报表"Web页面"组件支持参数传递：`URL?param=${param}`

### 10.9 报表钻取
- 超链接支持当前窗口/新窗口/对话框三种打开方式
- 条件钻取可根据值跳转不同报表：`${if(value>100, "a.cpt", "b.cpt")}`
- 决策报表可用Tab块切换实现无页面跳转钻取
- 对话框钻取适合不想离开主报表的场景
