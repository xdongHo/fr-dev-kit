# 复杂问题最佳实践 · 层次坐标与条件属性

> 来源: [拆分图谱](../00_拆分图谱与来源.md) §复杂问题最佳实践


## 一、层次坐标高级用法

### 1.1 核心语法速查

| 类型 | 语法 | 说明 |
|------|------|------|
| 相对纵向 | `Cellx[Celly:-1]` | 上一个值（环比常用） |
| 相对横向 | `Cellx[;Celly:-1]` | 横向上一个值 |
| 绝对取值 | `Cellx[Celly:2]` | 第 2 个值 |
| 倒数取值 | `Cellx[Celly:!-1]` | 最后一个值 |
| 全量扩展 | `Cellx[!0]` | 所有扩展值（占比/汇总） |
| 条件筛选 | `Cellx[!0]{条件}` | 条件汇总/分组排名 |
| 位置序号 | `&Cellx` | 扩展位置（判断首行） |
| 当前值 | `$Cellx` | 当前位置的值（条件比较基准） |

### 1.2 六大复杂计算公式模板

#### ① 环比（本月/上月）
```
=IF(&B2 > 1, C2 / C2[B2:-1], 0)
```
- `&B2 > 1`：非第一组才计算
- `C2[B2:-1]`：上一个的值
- **封装函数**：`=MOM(A1, B1)` — 引擎内部优化，性能更好

#### ② 同比（本月/去年同月）
```
=IF(&A2 > 1, C2 / C2[A2:-1, B2:+0], 0)
```
- `C2[A2:-1, B2:+0]`：去年同月（双向偏移）
- **关键**：`B2:+0` 确保月份不变

#### ③ 逐层累计（组内累计，跨组重置）
```
=C2 + D2[B2:-1]
```
- 跨年时自动重置（B2 是月份父格，跨组后找不到上一组）
- **封装函数**：`=LAYERTOTAL(B2, C2, D2)`

#### ④ 跨层累计（全局累计，不重置）
```
=IF(&B2 > 1, D2[B2:-1] + C2, D2[A2:-1, B2:!-1] + C2)
```
- 第一个月：当前值 + 上一年最后一个月的累计（跨组继续累计）
- **封装函数**：`=CROSSLAYERTOTAL(A2, B2, C2, D2)`

#### ⑤ 占比
```
=C2 / SUM(C2[!0])
```
- **封装函数**：`=PROPORTION(C2)`

#### ⑥ 排名
```
组内排名: =COUNT(C2[!0]{A2=$A2 && C2>$C2}) + 1
全局排名: =COUNT(C2[!0]{C2>$C2}) + 1
```
- **封装函数**：`=SORT(C2)` 降序 / `=SORT(C2, false)` 升序

### 1.3 双向扩展（交叉表）

```
Cellx[Celly:-k ;Cellz:p]     ← 第 p 列，纵向偏移 -k
Cellx[Celly:k ;Cellz:p]      ← 第 k 行第 p 列交叉处的值
Cellx[Celly ;Cellz:k]        ← 获取第 k 列所有值
Cellx[Celly:k ;Cellz]        ← 获取第 k 行所有值
```

### 1.4 性能优化

| 策略 | 说明 |
|------|------|
| 优先封装函数 | `MOM()`、`SORT()` 比手写公式性能好（引擎内部优化） |
| 减少 `!0` 全量扫描 | 缩小条件范围，避免遍历后再筛选 |
| 禁用行式引擎 | 行式引擎不支持层次坐标 |
| SQL 层预聚合 | 能在 SQL 完成的汇总不要在报表层做 |

### 1.5 避坑指南

| 坑 | 说明 | 解决方案 |
|----|------|----------|
| 行式引擎不支持 | 开启行式引擎后层次坐标失效 | 关闭行式引擎 |
| 新计算引擎不支持 | 新计算引擎插件不支持层次坐标 | 使用旧引擎 |
| 父格排序冲突 | 层次坐标先于排序计算，结果可能错乱 | 改用条件属性中的新值 |
| 跨 sheet/报表块不支持 | `{}` 条件过滤在跨 sheet 时不生效 | 改用公式嵌套 |
| 大小写不敏感 | `A1[A1:1]` = `a1[a1:1]` | 统一命名风格 |
| 公式末尾 `A` 后缀 | 表示跟随父格扩展，遗漏会导致不扩展 | 确认扩展行为 |

## 二、条件属性与动态样式

### 2.1 十二种属性类型

| 属性 | XML 类名 | 典型用途 |
|------|---------|---------|
| **颜色** | `ForegroundHighlightAction` | 负值红色、超标预警 |
| **背景** | `BackgroundHighlightAction` | 斑马纹、状态标记 |
| **字体** | `FRFontHighlightAction` | 关键数据加粗加大 |
| **形态** | `ValueHighlightAction` | 值映射（1→是，0→否） |
| **缩进** | — | 左右缩进像素，层级视觉缩进 |
| **行高** | `RowHeightHighlightAction` | 动态隐藏行（值=0） |
| **列宽** | `ColWidthHighlightAction` | 动态隐藏列（值=0） |
| **分页** | `PageHighlightAction` | 分组分页打印 |
| **超级链接** | `HyperlinkHighlightAction` | 条件跳转 |
| **边框** | `BorderHighlightAction` | 突出重点单元格 |
| **控件** | `WidgetHighlightAction` | 条件显示填报控件 |
| **新值** | `ValueHighlightAction` | 数据脱敏、状态文字化 |

### 2.2 五种公式联动模式

```python
# 模式一：单元格值比较
C2 > 2000

# 模式二：层次坐标函数
max(C2[!0]) = C2   # 当前值等于整列最大值

# 模式三：行号/列号函数
ROW()%2 == 0       # 偶数行（斑马纹）

# 模式四：参数联动
C2 > ${threshold}

# 模式五：控件联动
C2 = $$控件名
```

### 2.3 条件属性作用域

| Scope val | 作用域 | 用途 |
|-----------|--------|------|
| 0 | 当前单元格 | 精确控制单个格子 |
| 1 | 当前行 | 斑马纹、空行隐藏 |
| 2 | 当前列 | 整列高亮/隐藏 |

### 2.4 最佳实践

1. **命名规范**：每个条件属性务必命名（如 "销量>2000红色"）
2. **优先级**：后添加的优先级更高
3. **作用域选择**：格子级/行级/列级按需选择
4. **ObjectCondition 优先**：简单比较用 `ObjectCondition` 而非 `FormulaCondition`（性能更好）
5. **批量相同样式用 Style**：仅差异部分用条件属性

### 2.5 避坑指南

| 坑 | 说明 | 解决方案 |
|----|------|----------|
| 条件属性不联动 | 颜色条件不影响字体条件判断 | 每个属性独立设置完整条件 |
| 形态不支持分页预览 | 条件形态在分页预览下无效 | 用"新值"替代形态做值替换 |
| 填报+新值冲突 | 填报控件与条件新值同时使用导致新值无效 | 分开设计或用其他方案 |
| 填报未提交不生效 | 条件属性仅对已入库值生效 | 引导用户先提交再查看 |
| 隐藏列失效 | `ColWidthHighlightAction` 多一道 `Report.KEY==null` 守卫 | 排查求值环境而非条件公式 |
| 0mm 行高隐藏失效 | `RowHeightHighlightAction` 仅当 `rowHeight.more_than_zero()` 才写出 | 改用非零等价值 |
| 颜色值格式 | XML 中颜色为有符号十进制整数 | 使用工具自动转换（公式：`argb = 0xFF000000 | int(hex[1:], 16)`） |

## 三、填报性能优化

### 3.1 提交架构四层

```
用户点击提交
├─ ① 格式校验（控件级，录入时已限制）
├─ ② 非空校验（TopVerifier，提交前触发）
├─ ③ 业务规则校验（TopVerifier，提交前触发）
└─ ④ 提交入库（BuiltInSQLSubmiter + DMLConfig）
```

### 3.2 DMLConfig 四种模式

| 模式 | 用途 | 性能 |
|------|------|------|
| **IntelliDMLConfig** | 智能增删改（默认） | 常规场景 |
| **InsertConfig** | 纯插入 | 新增场景 |
| **DeleteConfig** | 纯删除 | 清空场景 |
| **混合模式（先删后插）** | DeleteConfig + InsertConfig 串行 | **大数据量最快** |

### 3.3 提交性能优化

| 策略 | 说明 | 效果 |
|------|------|------|
| `skipUnmodified="true"` | 跳过未修改行 | 大数据量回填显著提升 |
| 先删后插 | DeleteConfig + InsertConfig | 比逐行 IntelliDML 快 |
| 批量提交 | 避免逐行提交 | 减少数据库交互 |
| 填报分页 | `__cutpage__=v` | 大数据明细必须分页 |

### 3.4 渲染性能优化

| 策略 | 说明 |
|------|------|
| 避免直接显示控件 | 大数据量不开 `<ShowWidgets show="true"/>` |
| 避免 `sql()` 函数 | 扩展行多时用数据集 SQL |
| 控件级校验优先 | 录入时即时反馈，减少提交失败重试 |

### 3.5 Excel 导入优化

| 策略 | 说明 |
|------|------|
| 导入前清空 | `beforeimportexcel` 事件 + DeleteConfig 清空 |
| 批量行数控制 | 避免单次导入过大数据量 |
| 标记导入 | 大数据量用 ExcelMarkImport 插件 |

### 3.6 填报避坑指南

| 坑 | 说明 | 解决方案 |
|----|------|----------|
| 控件与条件新值互斥 | 不能同时使用填报控件和条件属性新值 | 分开设计 |
| Excel 导入不触发控件校验 | 导入数据绕过控件级校验 | 用模板级 TopVerifier 兜底 |
| 定时调度不触发 Web 事件 | `_g()` 在调度渲染时不可用 | 业务逻辑下沉到提交配置 |
| WebWriteContent 永久覆盖 | 一旦写出，模板脱离服务器统一配置 | 谨慎使用 |
| 自定义按钮不可删除 | 设计器 UI 无法删除已添加的自定义按钮 | 备份模板 |
| 移动端限制 | get/setCellValue 不支持、Excel 导入不支持 | 移动端使用简化方案 |
| Oracle 必须带 schema | `<Table schema="..." name="..."/>` | Oracle 场景必须填写 schema |
| isKey ≠ 数据库主键 | isKey 充当更新/删除的 WHERE 条件 | 理解其语义 |
| 提交顺序依赖 | 多个内置 SQL 从上到下串行执行 | 合理安排提交顺序 |

## 四、图表交互与联动

### 4.1 图表绑定模式

| 绑定模式 | 适用图表 | 说明 |
|---------|---------|------|
| 分类-值 | 柱形、条形、折线、面积 | 分类做 X 轴，值做 Y 轴 |
| 分类-系列-值 | 多系列图 | 三维绑定 |
| 名称-值 | 饼图、漏斗图 | 名称做标签，值做占比 |
| X-Y | 散点图、气泡图 | 两个数值轴 |
| 指标-范围 | 仪表盘 | 指针值 + 最大值 |
| 起止时间 | 甘特图 | 任务名 + 开始/结束时间 |
| 层级关系 | 树图 | 父子节点关系 |
| 多指标 | 雷达图 | 多个维度指标 |

### 4.2 三种联动机制

#### 机制一：FormHyperlink（点对点）
```xml
<Hyperlink class="com.fr.form.main.FormHyperlink" target="chart1">
  <Parameters>
    <Parameter name="area">
      <Value>$$$</Value>
    </Parameter>
  </Parameters>
</Hyperlink>
```
- 四链校验：target=真实 WidgetName → 超链参数名=目标数据集参数名 → SQL 含 `${参数}` → 参数有默认值

#### 机制二：DynamicParamHyperlink（广播）
- 把被点击值写进模板参数 → 凡 SQL 引用该参数的数据集自动重查 → 所有绑该数据集的组件刷新

#### 机制三：隐藏控件桥接（自动轮播联动）
```xml
<InnerWidget class="com.fr.form.ui.ComboBox">
  <WidgetName name="area"/>
  <WidgetAttr invisible="true"/>
</InnerWidget>
```
- JS: `_g().getWidgetByName('area').setValue(x)` → 无需 `parameterCommit()`

| 维度 | 机制一 | 机制二 | 机制三 |
|------|-------|-------|-------|
| 触发源 | 用户点击 | 用户点击 | 点击/轮播/定时器 |
| 目标 | 点对点 | 广播(跨数据集) | 广播(按模板参数) |
| 载体 | Hyperlink | Hyperlink | 参数(同名绑定) |

### 4.3 轮播联动四要素

1. ds1 全量绑源图（决定轮播序列）
2. ds2 含参（带默认值）绑所有目标图
3. 联动项按 WidgetName 引用目标
4. 联动动画 ∈ {重新加载, 增量刷新}

### 4.4 图表选择决策树

```
分析目的？
├── 比较 → 柱形图/条形图（多系列/堆积/百分比）
├── 趋势 → 折线图/面积图（双轴/曲线/阶梯）
├── 占比 → 饼图/环形图/玫瑰图（多层/南丁格尔）
├── 分布 → 散点图/气泡图/箱形图（聚类/趋势线）
├── 流程 → 漏斗图（基础/连续）
├── 进度 → 甘特图（多项目/里程碑）
├── 评估 → 雷达图（柱形/多系列）
├── 监控 → 仪表盘（试管型/多指针/自动刷新）
└── 地理 → 地图（GIS/三维/钻取）
```

### 4.5 图表性能优化

| 瓶颈 | 原因 | 解决方案 |
|------|------|---------|
| 大量数据点 | 百万级数据绑定到图表 | 数据集预聚合，限制返回行数 |
| 空数据提示不渲染 | 地图类永远不支持空数据提示 | 设计时考虑 |
| 缓存失效 | 修改后需手动清除缓存 | `setNeedResetCache(true)` |
| 移动端适配 | 重布局下数据点提示超 6 行需下滑 | 控制提示文案 ≤6 行 |

### 4.6 图表避坑指南

| 坑 | 说明 | 解决方案 |
|----|------|----------|
| 地图不支持空数据提示 | `VanChartMapPlotGlyph.isSupportEmptyData()` 硬返回 false | 设计时考虑 |
| 图表附件缓存 | 修改后仍是旧图 | 手动 `setNeedResetCache(true)` |
| JS 效果导出后消失 | JS 纯前端、导出走服务端 | 效果必须落到模板/后台属性 |
| 扩展图表刷新 API 不同 | 普通用 `chart.dataRefresh()`，扩展用 `dealReloadChartAjax()` | 区分调用方式 |
| .frm 定时导出限制 | 自适应布局失效、word 不支持图表 | 使用固定布局 |
