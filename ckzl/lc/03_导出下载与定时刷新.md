## 23. 导出 / 下载

### 23.1 Excel 导出三模式 URL 范式

Excel 导出有三种范式,由 `extype` 参数区分,无头 HTTP GET 可直接触发（等价于工具栏按钮）:

| 模式 | URL 参数 | 行为 | 重复标题 | sheet 命名 |
|------|---------|------|---------|-----------|
| 分页导出 | `format=excel&extype=page` | 按模板分页结果导出 | 每页重复 | — |
| 原样导出 | `format=excel&extype=simple` | 连续不分页导出 | 只一次 | — |
| 分页分Sheet | `format=excel&extype=sheet` | 每页一个 sheet | 每页重复 | `page1`/`page2`… |

> ⚠️ 行式引擎开启后**不支持分页分Sheet导出**（`extype=sheet` 静默失效）。
> 来源:帆软官方帮助 doc-1123

**分 Sheet 导出的两种 URL 范式（doc-3233）**:

| 范式 | URL 形态 | 说明 |
|------|---------|------|
| 按参数分 Sheet | `?reportlets=<encodeURIComponent(JSON数组[{reportlet,参数:值}])>&format=excel&__filename__` | 一次导出多份模板/多组参数,各自成 Sheet |
| 分组分 Sheet | `?viewlet=<cpt>&format=excel&extype=sheet&__filename__` | 同一模板按分组/分页切 Sheet |

- ⚠️ `extype=sheet`(切 Sheet)与 `extype=simple`(原样)**互斥**,误用 simple 会静默单 Sheet;
- URL 过长会触发浏览器 400(请求头太大);
- 挂载决策平台须用 `/webroot/decision/view/report` 前缀;
- 均不支持移动端。
> 来源:帆软官方帮助 doc-3233

**预览/调试参数补充**：
- `&__bypagesize__=false` — 取消分页，全部数据一页显示（用于调试整页效果或导出整页）。
- 来源:帆软官方帮助 doc-368

### 23.2 大数据集导出

大数据集导出 = 把数据集直接流式落盘为 Excel，核心是**绕开单元格渲染**。它与普通导出的本质边界（doc-3610/1736）：

- **普通导出走单元格**（带格式、经过报表计算）；
- **大数据导出走 SQL**（无格式、跳过报表计算、SXSSF 流式）；
- 无头生成时若需求是「导出百万行」，应直接导向大数据集导出配置，而不是堆单元格样式（可复用 doc 的「生产者消费者 + SXSSF」作为 kit 自带导出脚本设计蓝本）。

**三条可选路线（选型表）**：

| 路线 | 形态 | 模板类型 | 触发方式 | 适用 |
|------|------|---------|---------|------|
| 路线0 原生流式导出（doc-1407） | 无需任何插件 | cpt / cptx | 预览 URL 加 `&format=excel`（FR 8.0/9.0/10.0 默认流式；仅 7.1.1 需 `&extype=stream`） | 整表大数据导出，最轻量、纯无头 |
| 路线A 大数据集导出插件（doc-3610） | 按钮「大数据集导出 Excel」事件 | cpt + cptx | GUI 事件配置（事件节点名未公开，XML 落点 TODO） | 老插件事件链 |
| 路线B 新计算引擎（doc-3342） | 工具栏自定义按钮 + JS POST `{webapp}/decision/url/report/v10/direct/export` | **仅 cptx** | XML 落点已 VERIFIED | 导出数据集而非整表、要按钮触发；**无头生成优先** |

> **无头选型依据**：无头生成优先路线B（可生成、可静态校验），其硬前置 = 新计算引擎插件 + 模板转 cptx + 只用分页预览/新分页预览；路线A 的事件节点名未公开，生成器只能写占位；路线0 最轻量，适合「脚本一把出 xlsx」。
> ⚠️ 行式引擎下 `format=excel` 即流式；装「Excel 流式导出支持行式引擎插件」后升级为 xlsx 流式。流式导出只支持 `.xlsx`，不支持 `.xls`（doc-1407）。
> 来源:帆软官方帮助 doc-4524/1407/3610/3342

**产物形态矩阵（doc-1120，收口 1120/1121/1123/1407）**：

| 行式引擎 | poi2007_fat.jar | 流式插件 | 实际产物 |
|---------|----------------|---------|---------|
| 关 + 量在临界点内 | — | — | 单个 Excel（超限数据溢出到下一 sheet） |
| 关 + 量超临界点 | — | — | **导出失败但 HTTP 200、文件非空、打不开**（必须校验字节头） |
| 开 | — | — | 多个 .xls 打成 1 个 zip（回退 2003） |
| 开 | — | 装 | 流式 .xlsx |

> ⚠️ **结构性矛盾：「开行式引擎」与「想拿单个 .xlsx」天然冲突** —— 行式引擎会让导出回退 2003 且改为多文件打包；要单个 .xlsx 必须装流式插件。`extype=sheet` 在行式引擎下也静默失效。
> ⚠️ 开行式引擎时「单个 Excel 最大行数」须同时满足：是「固定行数分页」每页行数的**整数倍**且 ≤ 65536；65536 本身几乎永远是非法值（每页 40 行时最大 65520）。且必须先设固定行数分页，行数约束才成立。
> 来源:帆软官方帮助 doc-1120/1121/1123/1407

**硬约束与产物层约定（doc-4524/4518）**：

- 大数据集导出路线**仅支持关系型数据库数据集**，不支持 spider 数据集 / 程序数据集（doc-4518 §2.3）；若模板数据源是 spider/程序数据集，只能改走普通数据集或换行式引擎/流式路线。在数据集选型阶段就标注，而非拼完模板才暴露。
- 数据量硬上限：建议 ≤ **1000W 行 × 20 列**，超大可能只导出部分数据且无报错（doc-4524）。
- 每 **100W 行**自动落到下一个 sheet（doc-4518 §2.5），下游脚本必须按多 sheet 收产物，不能只读 sheet1。
- 部署容器（如 Tomcat）超时过小会让 8w×20 这类大查询静默失败无文件（doc-4518 §2.11），无头导出应放宽超时；进度条默认 5s 后才显示（§2.1），脚本侧不要据此误判卡死。
- 无头触发范式：`?viewlet=<tpl>&format=excel&__filename__=<名>`（doc-4524）。
- 多值参数（paramStr）必须写成对象字面量 `{key:"v1','v2"}`（值间用 `','` 硬拼、整体双引号）再 encodeURIComponent；写成 `[`/`]`/`'` 数组或 `{val:...}` 一律导出为空（doc-4518 §2.10）。
- 来源:帆软官方帮助 doc-4524/4518

### 23.3 导出耗时归因 SOP

先判请求形态，再查根因（doc-4418）：

| 请求形态 | 语义 | 慢的时候查哪 |
|---------|------|------------|
| 带 `sessionID` 的导出 | **复用预览结果、不重算** | 模板/渲染侧（查 SQL 是白费） |
| `?viewlet=x.cpt&op=export` | **每次重新取数计算** | 先查 info 日志的 SQL 耗时 |

- 第1刀：数据库驱动（SQLServer 低版本 sqljdbc 换 sqljdbc42）。
- 第2刀：模板侧（图表缺 j2v8 回退 nashorn；`webimage()` 指向自有服务地址会同步等待）。
- 免费二分：**预览也慢** ⇒ 取数或 webimage；仅导出慢 ⇒ 导出专有环节（重新取数/图表渲染/写文件）。
- **批量导出提速手法**：同一张模板连续导出多份时，先预览一次取得 sessionID，再用带 sessionID 的导出请求，整段省掉重复取数计算；仅当参数不同、必须重算时才用 `viewlet=..&op=export`。注意：此处的 sessionID 与 doc-3342 `direct/export` 的 sessionID 是同一个值但**用途不同**（那里是会话定位，这里是性能开关）。
- 来源:帆软官方帮助 doc-4418

### 23.4 导出文件名随筛选值变化

两条互补机制（doc-1822/3707）：

1. **模板内动态文件名**：「模板 Web 属性 > 标题」写公式，如 `${参数1+"_后缀_"+参数2}`（headless = 注入 `<ReportWebAttr><Title>` 公式）——默认工具栏导出即得到动态文件名，无需 JS 导出按钮。注意：标题公式同时是浏览器页标题；参数默认值为空会带空段，应给默认值。
2. **URL 覆盖文件名**：导出 URL 加 `&__filename__=<值>`——自定义 JS/无头 HTTP 导出时覆盖文件名。

> 两者并存时 `__filename__` 优先（待核验）；两者都依赖「面板控件 WidgetName 与模板参数同名」这一命名铁律；移动端不支持任一导出方式。
> 来源:帆软官方帮助 doc-1822/3707

### 23.5 导出触发位置

同一套导出 URL 范式（servletURL + viewlet + format），仅触发点不同（doc-1819）：

| 触发点 | 写法要点 |
|--------|---------|
| 参数面板按钮 | 按钮 click 事件拼 URL（window.open）（doc-3460/3233/4524/1822） |
| 工具栏自定义单格式按钮 | 「为模板单独设置」工具栏 + ToolBarButton，点击事件拼 `servletURL+'?viewlet='+encodeURI(encodeURI(reportName))+'&format=<text/word/excel/pdf>'`；事件**必须声明 `servletURL`/`reportName` 两个参数（公式）**，漏声明则导出 URL 静默为空；`format` 合法取值：text/word/excel/pdf（doc-1819） |
| 报表路由面板 | 参数面板下拉选另一份报表再导出，`window.location` 重定向（doc-3710） |

> 无头 HTTP 触发只需一次 `urllib.parse.quote`（浏览器双层 encodeURI 是地址栏专用，脚本侧双层多余）。
> 来源:帆软官方帮助 doc-1819/3710

### 23.6 导出兼容性禁忌

- **分散对齐、文本方向自定义角度（非0）** 在浏览器端以图片渲染，导出 word/excel 时**失效**：凡需导出 excel/word 的模板保持默认对齐（doc-217 §2.3.1/§2.3.2）。
- 来源:帆软官方帮助 doc-217

### 23.7 URL 触发导出（无头批量导出）

导出 URL 范式：`.../view/report?viewlet=<cpt>&op=write&id=<值>&format=excel&extype=simple&__filename__=<名>`：

- 等价于 JS `window.open` 批量导出，可脱离 GUI 直接触发；
- 约束：不支持移动端、不支持新填报预览、需 `op=write` 老填报链路、浏览器弹窗需放行。

> 来源:帆软官方帮助 doc-3460

### 23.8 三类 Excel 导出选型表

| 路径 | 行为 | 适用 |
|------|------|------|
| ① `_g().exportReportToExcel('simple')` | 走报表计算、保留格式 | 常规量级 |
| ② URL `&format=excel&extype=sheet`（doc-3233） | 走报表计算、分 Sheet | 需要分 Sheet |
| ③ `_g().directExportToExcel(dsName,fileName,params,colNames)` | **跳过报表计算**、SXSSFWorkbook 流式、只导 SQL 结果集 | 仅明细表、仅关系型库、百万级明细 |

③ 的边界：格式/条件属性/公式列全丢；不支持移动端；建议 ≤1000W 行×20 列；**无工具栏/URL 入口，只能由按钮点击事件的 JS 触发**。误把 ① 用于百万级导出会超时/OOM；误把 ③ 用于带格式的汇总报表，导出结果丢格式却不报错。

> 来源:帆软官方帮助 doc-2597

## 24. 决策报表定时刷新（表单级事件）

铁律（doc-1457）：

- 定时刷新必须挂「body 初始化后事件」（`<Form><Body><Events>` 的 **afterinit**），**不是控件事件**；挂到控件或误用 gotoPage 会导致不刷新或丢失交互态。
- JS 写法：`setInterval('location.reload();', 10000);`（毫秒单位）；要支持取消必须存句柄 `var timer = setInterval(...); clearInterval(timer);`（匿名定时器无法取消，会叠加越刷越快）。
- JS 必须裸写在 `<![CDATA[...]]>` 内，否则 FR 把 `location.reload()` 当标签解析而失效。
- **整页 reload vs 单报表块刷新**的粒度取舍：大屏用整页 reload；局部刷新用 `report0.gotoPage(1,{...},"lazy")`（doc-1894，第三参 `"lazy"` 只重算单块，true 重算全部→大模板性能差）。整页 reload 会重连数据集并**重置所有控件选中态**。
- 表单级(body)支持的事件名**不止 afterinit**(doc-2372):`<Form><Body><Events>` 同一挂载点也支持 `click`(如「点击 body 全屏」);事件名字典与宿主写法见 07 §12.13。
- 来源:帆软官方帮助 doc-1457/1894

### 24.1 Tab 轮播（表单级定时行为第三种场景）

在「定时刷新挂 body afterinit」铁律下并列第三种场景：

- JS：`_g().getWidgetByName('tabpane0').getShowIndex()` / `showCardByIndex(i)`；
- 轮播写法用 `(i+1) % Tab页数`，不要照抄官方的 `if(aa==2)`；
- 选型：Tab 布局自带「轮播」属性能满足时不要注 JS（少一段 CDATA、少一个定时器）。

> 来源:帆软官方帮助 doc-2005
