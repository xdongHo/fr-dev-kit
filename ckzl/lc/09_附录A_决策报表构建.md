## 附录A: 完整 Java API 示例

```java
import com.fr.main.impl.WorkBook;
import com.fr.report.worksheet.WorkSheet;
import com.fr.report.cell.DefaultTemplateCellElement;
import com.fr.report.cell.cellattr.core.group.DSColumn;
import com.fr.report.cell.cellattr.core.group.FunctionGrouper;
import com.fr.report.cell.cellattr.CellExpandAttr;
import com.fr.base.Style;
import com.fr.general.FRFont;
import com.fr.base.background.ColorBackground;
import com.fr.base.CoreDecimalFormat;
import com.fr.data.impl.EmbeddedTableData;
import com.fr.stable.unit.FU;
import java.awt.Color;
import java.io.FileOutputStream;
import java.util.*;

public class Example {
    public static void main(String[] args) throws Exception {
        WorkBook wb = new WorkBook();
        
        // 数据集
        EmbeddedTableData ds = new EmbeddedTableData();
        ds.setName("ds1");
        ds.addColumn("产品", String.class);
        ds.addColumn("销量", Integer.class);
        List rows = new ArrayList();
        rows.add(Arrays.asList("苹果汁", 100));
        rows.add(Arrays.asList("牛奶", 200));
        ds.getRowDataConf().get().setRowData(rows);
        wb.putTableData("ds1", ds);
        
        // 样式 — 统一 padding + 微软雅黑
        Style hdr = Style.DEFAULT_STYLE
            .deriveFRFont(FRFont.getInstance("微软雅黑", 1, 9))
            .deriveBackground(ColorBackground.getInstance(new Color(0x4F9EC2)))
            .deriveBorder(1, Color.GRAY, 1, Color.GRAY, 1, Color.GRAY, 1, Color.GRAY);
        Style dat = Style.DEFAULT_STYLE
            .deriveFRFont(FRFont.getInstance("微软雅黑", 0, 9))
            .deriveBorder(1, Color.GRAY, 1, Color.GRAY, 1, Color.GRAY, 1, Color.GRAY);
        
        // Sheet — FU 值（§5.5 权威换算）
        WorkSheet sheet = new WorkSheet();
        sheet.setRowHeight(0, FU.getInstance(1440000));   // 表头 10mm
        sheet.setRowHeight(1, FU.getInstance(1152000));   // 明细 8mm
        
        // 表头
        DefaultTemplateCellElement h = new DefaultTemplateCellElement(0, 0, "产品");
        h.setStyle(hdr); sheet.addCellElement(h);
        
        // 数据
        DSColumn dsc = new DSColumn(); dsc.setDSName("ds1"); dsc.setColumnName("产品");
        dsc.setGrouper(new FunctionGrouper());
        DefaultTemplateCellElement c = new DefaultTemplateCellElement(0, 1, dsc);
        c.setStyle(dat);
        CellExpandAttr exp = new CellExpandAttr();
        exp.setExtendable(CellExpandAttr.Vertical_EXTENDABLE);
        c.setCellExpandAttr(exp);
        sheet.addCellElement(c);
        
        // 导出
        wb.addReport("sheet1", sheet);
        wb.export(new FileOutputStream("output.cpt"));
    }
}
```

## 18. 决策报表(.frm)构建补充：组件树约束 / 允许全屏 / 重叠模式（doc-2326 + doc-2483 + doc-3630）

> 来源: 帆软官方帮助 doc-2326（决策报表组件操作）/ doc-2483（组件全屏开关控制）/ doc-3630（模板限制-组件重叠）/ doc-3138 / doc-1656

**① 组件树操作配套约束（doc-2326）**：

- **组件名称（WidgetName）非空且全局唯一**——后台靠组件名定位初始化事件目标对象，为空/重复则初始化事件失效（doc-2326 §2.2 注2）；Java 落点候选 `Widget#setWidgetName(String)`（待核验），XML 对应 `<WidgetName>` 节点；与 fr_check.py「无重复 WidgetName」校验及 kit 04 §7.3 三处一致铁律互证；
- 复制/粘贴命名语义：设计器粘贴后新组件名 = 原名 + `_c`，可作生成器克隆组件默认命名；
- 待核验：z-order（绝对布局重叠时层别，Java 落点 = 容器内 addWidget 顺序 vs zIndex 属性）、报表块组件候选类名 `com.fr.form.ui.ReportBlock`。

**② 移动端属性「允许全屏」（doc-2483）**：

- 属性承载 = 组件基类 `com.fr.form.ui.Widget` 的移动端属性（报表块 Report / 图表块 Chart 共用），候选 `setAllowFullScreen(boolean)/isAllowFullScreen()`（[TODO] 待环境核实）；XML 落点 = .frm 内组件节点下移动端属性节点（[TODO]）；
- **默认值差异铁律：报表块默认 false（不勾选）、图表块默认 true（勾选）**——无头构建必须显式设置、不能依赖设计器默认，否则报表块/图表块移动端行为与交付预期不符（漏设置 = 静默风险）；
- 移动端默认双击组件即可全屏；勾选组件移动端右上角出现全屏符号；交付 .frm 时按组件确认全屏开关（明细表格类建议关、图表/大屏类建议开）；
- 基线样本 = 官方模板 `%FR_HOME%\webapps\webroot\WEB-INF\reportlets\demo\Phone\analytics\sales\员工销售额-phone.frm`（report0=false / chart1=true，可实读定位 XML）。

**③ 组件重叠模式（doc-3630，原建议内容截断部分以推断标注）**：

- 绝对布局 `WAbsoluteBodyLayout` + `WBodyLayoutType`（doc-958 已核）+ 组件基类 `com.fr.form.ui.Widget` + 坐标 x/y/width/height（绝对布局像素坐标）；重叠 = 多组件坐标区域相交，叠放层次机制（原建议内容截断，待核验后固化）。

**④ 图表块「交互属性>排序」待核条目（doc-3138 + doc-1656）**：

- 移动端图表块全屏时排序/刷新按钮的出现条件 = 图表块勾选「交互属性>排序」；Java 类与 XML 节点待核验（核验源 = 含排序交互属性的官方决策报表 .frm 反读 + jar 字节码实读，与 doc-1656 图表切换交互属性合并核验）。
