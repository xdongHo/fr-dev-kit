# FR11 图表 核心结论

> 降级自 `ckzl/lc/fr11_knowledge/chart图表/references/chart_summary.md`；完整文档条目大表（doc-view ID + 标题 + 核心概念 + API）见本目录 `references\chart_summary.md`。

## 主题速览
- 主题范围：图表类型/图表样式/图表特效/扩展图表/ECharts/地图；共 240 篇文档（doc-view ID 覆盖 173~5116），其中 25 篇提及 FR11 子版本号（11.0.x），0 篇解析失败。
- 标题关键词频次：图表 91、地图 43、数据 20、自定义 20、单元格 7、插件 5、FVS 4、大数据 3。
- 图表插入方式两种：「单元格元素图表」随父格扩展可生成多个图表；「悬浮元素图表」可随意拖放、不受单元格限制；决策报表的图表块不支持悬浮元素图表。
- 图表数据源两种：「数据集数据」（直接取数据集，系列名可选字段值或字段名）与「单元格数据源」（数据需先计算，必须点 F(x) 进入公式定义，直接输入会被判为普通文本）。
- 图表规模：基础（内置）图表共 20 大类 49 小类；扩展图表插件共 9 大类 20 小类；第三方插件图表按需安装。

## 核心结论

### 常见问法：图表怎么做？柱状图/折线图在哪选？/ echarts 图表在帆软里怎么用、轮播刷新怎么配？/ 图表扩展与数据源重构怎么做？/ 图表数据用单元格还是数据集？

| 口语问题 | 落点（本文件实读内容） |
|---|---|
| 柱状图/折线图等图表类型在哪选、怎么插到报表里 | 内置图表 20 大类 49 小类；插入两种方式：单元格元素图表（随父格扩展）/悬浮元素图表（随意拖放；决策报表图表块不支持悬浮）【实测·本文件主题速览】 |
| echarts 图表怎么引用模板数据集、怎么定时刷新 | ECharts 插件先添加数据结构再 getData('name')；ECharts 不支持监控刷新，改用 autoRefresh(time)；扩展图表不支持 dataRefresh()，改用 dealReloadChartAjax()【实测·本文件核心结论】 |
| 图表数据源选哪种、为什么我输的公式变成文本 | 「数据集数据」直接取数据集；「单元格数据源」必须点 F(x) 进公式定义，直接输入会被判普通文本【实测·本文件主题速览】 |
| 图表样式（标题/图例/标签/坐标轴）能改哪些 | 通用属性 8 种：标题、图例、标签、系列、坐标轴、数据表、背景、提示（数据表仅柱形/折线/面积/组合图支持）【实测·本文件核心结论】 |
- 图表样式通用属性共 8 种：标题、图例、标签、系列、坐标轴、数据表、背景、提示；其中「数据表」仅柱形图、折线图、面积图、组合图支持。
- 图表交互属性共 6 项：监控刷新、全屏、取消全屏、排序、导出、超级链接；注意：图表数据来源于单元格数据时不支持监控刷新。
- 大数据模式：数据量达万级时图表加载慢，开启大数据优化可提速约 20 倍；适用折线图、面积图、散点图、气泡图、点地图、流向地图、组合地图。
- 地图体系：区域/点/组合/热力/流向/钻取地图，钻取层级为国家>省>市>区；内置高德、mapbox 等 GIS 图层；11.0.6 起支持自定义高德/WMS/WMTS 图层，且 11.0.6+「地图配置」界面需联网请求高德 API，否则地理信息、自定义图片图层无法显示（建议 Chrome）。
- 地图联动：通过参数联动「钻取地图」与其他组件时，因地图各层级数据需先汇总处理，联动图表必须使用单元格数据源。
- 坑点：多层饼图只适用于数据全为正数，负数会被当成正数聚合；词云建议数据超过 30 条；11.0.4 优化钻取地图，作用于整个模板尺寸的交互操作不再重置钻取层级。
- 图表切换与联动：同一位置添加多个图表可用「按钮切换/轮播切换」；接口 FR.Chart.WebUtils.getChart(chartId).showIndexChart(index) 可跳转指定图表（不支持扩展图表）。
- ECharts 图表（插件）引用模板数据集：先添加数据结构，再在代码中 getData('name') 调用；ECharts 不支持监控刷新，需用 autoRefresh(time) 定时刷新；扩展图表不支持 dataRefresh()，改用 dealReloadChartAjax()。
- 超级链接传参是实现钻取/联动的核心：参数名是「钥匙」，目标模板参数是「门牌号」；「动态参数」类型超链可实现当前页钻取与模板全局联动刷新。

## 关键 API 与版本要点

### 常见问法：前端 JS 怎么获取图表对象、getChart 取不到怎么办？/ 多个图表切换轮播怎么跳到指定那张？/ 地图钻取（下钻/返回上级）接口怎么调？/ 图表点击排序怎么做？

| 口语问题 | 落点（本文件实读内容） |
|---|---|
| getChart 取图表对象取不到/大小写报错 | FR.Chart.WebUtils.getChart(chartID)，chartID 为字符串且区分大小写、须与组件名完全一致（单元格 "A1"、悬浮 "Float1"、图表块 "chart0"）；多图表轮播取索引用 11.0.3 新增 getCurrentChartIndex()【实测·本文件】 |
| 按钮/轮播切换时跳到指定图表 | FR.Chart.WebUtils.getChart(chartId).showIndexChart(index)（不支持扩展图表）【实测·本文件核心结论】 |
| 地图下钻/返回、缩放接口 | 11.0.2 新增 chart.drillUp(index)/getLayerIndex()/getLayerNames()；缩放 chart.setMapZoom({zoomLevel:5, viewCenter:[110,40]})，zoomLevel 一般 0-18【实测·本文件】 |
| 图表排序 | chart.sortChart(sortType)【实测·本文件】 |
- 获取图表对象：FR.Chart.WebUtils.getChart(chartID)，chartID 为字符串且区分大小写、须与组件名完全一致（单元格 "A1"、悬浮 "Float1"、图表块 "chart0"）；11.0.3 新增 getCurrentChartIndex() 解决多图表轮播下取 chartIndex 失败问题。
- 排序接口 chart.sortChart(sortType)；地图缩放接口 chart.setMapZoom({zoomLevel: 5, viewCenter: [110, 40]})，zoomLevel 一般 0-18，值越大越细致。
- 11.0.2 新增钻取地图官方接口：chart.drillUp(index)、chart.getLayerIndex()、chart.getLayerNames()。
- 11.0.3：图表切换按钮/轮播悬浮内容支持自定义文本；多分类轴新增「显示逻辑」（整体/分层显示，最多三层分类）；甘特图支持「当前时间线」与绘图区轴边框设置。
- 11.0.2：漏斗图「图表样式>系列」新增升序排序（可制作金字塔图）；图表标签自定义字符颜色支持「自动」。
- 11.0.6：图表条件显示可选条件新增「汇总字段值」（图形值与另一字段值对比，用于预警/系列值对比）；地图「地理信息>区域」支持合并区域、圆形选区、内置「中国行政区」目录。
- 11.0.4：图表全屏时背景取色逻辑优化、文字自适应；10.0 升 11.0 图表效果异常可安装「图表数据源兼容插件」切回旧版取数逻辑。
