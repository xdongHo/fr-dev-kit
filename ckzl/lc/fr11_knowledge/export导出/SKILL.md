# FR11 导出 核心结论

> 降级自 `ckzl/lc/fr11_knowledge/export导出/references/export_summary.md`；完整文档条目大表（doc-view ID + 标题 + 核心概念 + API）见本目录 `references\export_summary.md`。

## 主题速览
- 主题范围：Excel导出/PDF导出/Word导出/图片导出/CSV；共 48 篇文档（doc-view ID 覆盖 225~5031），其中 12 篇提及 FR11 子版本号（11.0.x），0 篇解析失败。
- 标题关键词频次：导出 46、插件 11、报表 7、数据 5、大数据 5、数据集 4、JS 3。
- 导出通道两种：浏览器端导出（先选格式，服务器内存中生成内容后由 servlet 推送客户端）与设计器端导出（菜单文件>输出）。
- Excel 导出三种效果：原样导出、分页导出、分页分 sheet 导出；程序导出另有大数据量导出方式。
- 决策报表（frm）导出必须使用接口或插件实现，与普通报表（cpt）不同；旧版决策报表需装「决策报表导出插件」。

## 核心结论

### 常见问法：报表怎么导出成 Excel 文件发给业务？/ 数据量太大导出 PDF/Excel 太慢，有没有流式导出？/ FR11 内置导出的密码和水印怎么配、密码支持公式吗？/ 导出 Excel 是 0KB 或和预览不一致怎么排查？

| 口语问题 | 落点（本文件实读内容） |
|---|---|
| 导出 Excel 给业务（原样/分页/分 sheet） | 导出通道两种（浏览器端选格式导出/设计器端 文件>输出）；Excel 三种效果：原样、分页、分页分 sheet【实测·本文件主题速览】 |
| 大数据量导出慢/内存溢出（流式方案） | 「大数据集导出」按数据集结果后台流式导出、无需前台展示；「Excel 流式导出支持行式引擎插件」流式处理可导几百万行【实测·本文件核心结论】 |
| 导出水印/密码（内置导出怎么配） | 11.0.9 起导出 Excel/Word 新增「导出水印」；密码项更名（Excel「编辑密码/文件保护」、PDF「文件密码」）；11.0.13 密码支持公式；「仅限预览」导出不支持复制单元格【实测·本文件】 |
| 导出 0KB/损坏/与预览不一致排查 | 0KB/空白原因众多（11.0 性能插件已拆分内置）；效果不一致常见于行高/换行/分页、页眉页脚两类【实测·本文件】 |
- 大数据量导出 Excel 的坑：PC 端大数据导出要么数据分散到多个 sheet，要么导出失败、内容无效；「大数据集导出」直接按数据集结果后台流式导出，占用资源少、速度快，无需前台数据展示。
- 内存优化：大数据 Excel 导出很占内存，大并发下易内存溢出；「Excel 流式导出支持行式引擎插件」流式处理、内存占用低，可导出几百万行数据。
- URL 直接导出：服务器开启后无需打开模板，地址栏键入「报表访问地址+导出参数+导出格式」即可导出（如 &format=excel，参数用 &参数名=xxx 拼接）；post 方式用 FR.doHyperlinkByPost 实现。
- JS 导出：工具栏自定义按钮可只导出单一格式文件；分 sheet 导出通过给 URL 添加「导出格式参数+导出页数参数」实现；大数据集导出调用 _g().directExportToExcel("ds5","导出测试",paramStr,colNames)。
- 内容保护：11.0.9 起导出 Excel/Word 新增「导出水印」；密码项更名（Excel「需要密码/保护密码」→「编辑密码/文件保护」，PDF「需要密码」→「文件密码」）与水印共同构成内容保护；11.0.13 密码支持公式，「仅限预览」导出文件不支持复制单元格内容。
- 特殊字符导出：11.0.6「模板>模板导出属性」新增「通用」Tab，勾选「特殊字符导出优化」后以内置字体 noto-cjk 导出；仍异常需装字体管理插件上传备用字体。
- 插件内置化：图片导出设置插件 11.0.7 已内置（生效范围改为只对单张模板生效，JAR 更新后插件自动禁用）；11.0.5 模板导出属性新增「Image」Tab。
- Word 导出：默认固定行高导致二次编辑不能自动调行高，需在「模板>模板导出属性」设置行高可变；报表页眉页脚可同时导出至 Word。
- 排查思路：导出 Excel 为 0KB/损坏/打开空白原因众多（11.0 中性能插件功能已拆分内置）；导出效果与预览不一致常见于行高/换行/分页、页眉页脚两类问题。
- 批量导出：11.0.1 起控件的导出事件支持批量导出多个普通报表（如主表连带子表）；多 CPT 合并导出 Excel/PDF 用插件，可选模板与用户平台目录权限一致，可预设 sheet 名与顺序。

## 关键 API 与版本要点

### 常见问法：Java 程序里怎么把报表导出 Excel？/ 不打开模板直接用 URL 导出参数怎么拼？/ JS 大数据集导出 directExportToExcel 怎么传参？

| 口语问题 | 落点（本文件实读内容） |
|---|---|
| 程序导出 API | ExcelExporter（原样导出）、StreamExcel2007Exporter（流式 07），配合 workbook.execute(parameterMap, actor) 计算、setVersion(true) 指定版本【实测·本文件】 |
| URL 直接导出 | 报表访问地址+导出参数+导出格式（如 &format=excel，参数 &参数名=xxx 拼接）；post 方式用 FR.doHyperlinkByPost【实测·本文件核心结论】 |
| JS 大数据集导出传参 | _g().directExportToExcel("ds5","导出测试",paramStr,colNames)；11.0.10 新增 CSV 类型与 enCoding 编码参数【实测·本文件核心结论/关键API】 |
| 定时调度附件导出失败（行式引擎） | 勾选 Word/Excel/PDF 存档且模板启用行式引擎会报「快照生成失败」Not supported yet，需装对应支持行式引擎的插件【实测·本文件】 |
- 程序导出 API：ExcelExporter（原样导出）、StreamExcel2007Exporter（流式 07），配合 workbook.execute(parameterMap, actor) 计算、setVersion(true) 指定版本。
- 大数据集导出：11.0.10 新增支持导出 CSV 类型文件、支持修改编码格式；11.0.5 优化 JS/插件两种大数据集导出场景（日志细化、错误代码、交互界面优化）。
- 11.0.5：内网等原因导致预览正常但导出图片空白的问题，改为返回带提示信息的图片，不再直接返回空白图片。
- 富文本单元格导出时按富文本字体导出，单元格显示字号跟随富文本最大字号。
- itext7 导出及国际化换行插件：导出更快，统一基于 Webkit 的 ICU 国际化分词换行，统一前后台换行效果。
- CSV 导出：需装「导出CSV」插件；繁体系统或 UTF-8 编码乱码时加装 CSV 导出编码插件自定义编码，不受服务器编码限制。
- 定时调度附件存档勾选 Word/Excel/PDF 时，若报表启用了行式引擎会导出失败（报「快照生成失败」Not supported yet），需装对应支持行式引擎的插件。
