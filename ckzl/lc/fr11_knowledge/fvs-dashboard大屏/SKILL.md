- 65 篇 FVS 文档（标题含 FVS，跨分类专题聚合；在 15 分类中分属图表/决策报表/皮肤主题/二次开发等）

## 核心结论

### 常见问法：FR11 那种酷炫大屏（三维城市那种）怎么搭？/ FVS 是什么、和普通决策报表什么关系？/ 大屏能放哪些组件（轮播器/视频/控件）？/ FVS 支持移动端吗、要不要买 License？

| 口语问题 | 落点（本文件实读内容） |

| FVS 是什么 | 专为大屏可视化场景打造的产品，基于 FineReport 设计器开发、以插件交付（JAR 2021-11-15 / 插件 V1.0.0 起，doc-view-4222）；65 篇文档跨图表/决策报表/皮肤主题/二次开发等分类聚合【实测·本文件】 |
| 能放哪些组件 | 组件六大类：三维（三维城市/自定义模型）、图表（普通+扩展）、文字（富文本/标题/表格）、媒体（视频/监控视频/图片）、容器（网页框/轮播器）、控件（11.0.6/V1.5.0 新增六种，支持参数联动）【实测·本文件】 |
| 移动端与 License | FVS 不支持移动端；需在 License 注册中购买对应功能【实测·本文件主题速览】 |
- 产品形态：B/S 端技术，兼具 B/S 便捷高效与 C/S 安全稳定；所见即所得编辑
- 核心亮点：三维城市一键生成、自定义模型导入、多分页故事大屏、分页平滑过渡、所见即所得编辑、4 种自适应模式（自动/宽度铺满/高度铺满/无）、内置图标背景装饰素材、点九图填充
- 组件体系六大类（doc-view-4210）：三维（三维城市/自定义模型）、图表（普通+扩展图表）、文字（富文本/标题/表格）、媒体（视频/监控视频/图片）、容器（网页框/轮播器）、控件（11.0.6/V1.5.0 新增六种：文本框、日期时间、下拉框、下拉复选框、单选按钮组、复选按钮组，支持参数联动）
- 插件硬件与安装要求见 doc-view-4188；V1.2.0 起 jxbrowser 缺失检测
- 分页切换三种方式：分页跳转事件、JavaScript 事件、表格超链传参（doc-view-4220）；控件结合 JS 事件也可切换分页/轮播器 Tab（doc-view-5003/5007）
- 资源复用（11.0.9/V1.12.0）：可复用模板、组件、图片、视频四类本地/在线资源，快速搭大屏（doc-view-5065）
- 字号限制：图表与表格组件不受最小字号限制，其余组件小于最小字号时按最小字号显示（doc-view-5059）
- **常见问法**：FVS 大屏字体随分辨率自适应/缩放怎么设置？→ 整屏缩放走「4 种自适应模式」（自动/宽度铺满/高度铺满/无，见上「核心亮点」）；字号本身另受最小字号限制（上行 doc-view-5059）——两者配合，逐条目详见 `references/fvs_dashboard_summary.md`
- 表格工具栏（V1.11.0）支持分页按钮切换分页；音频播放/暂停可实现（doc-view-5131）

## 关键 API 与版本要点

### 常见问法：可视化看板 duchamp 接口怎么调？/ FVS 轮播器怎么取当前索引、切卡片？/ FVS 分页切换有哪几种方式？/ FVS 大屏的 JS 事件接口对什么模板生效？

| 口语问题 | 落点（本文件实读内容） |
|---|---|
| duchamp 接口适配线 | 11.0.7 起配合「FVS大屏编辑模式」插件 V1.8.0+ 支持 duchamp 接口，并补充支持决策报表全部接口（接口明细与 doc-view 见 ckzl/lc/fr11_knowledge/js-api二次开发/SKILL.md「FVS 大屏」行）【实测·跨文件实读】 |
| 轮播器取索引/切卡片 | 轮播器组件接口 getShowIndex()、showCardByIndex()（11.0.9/V1.9.1 起）、setTabVisible（V1.10.1 起）【实测·本文件】 |
| 分页切换方式 | 三种：分页跳转事件、JavaScript 事件、表格超链传参（doc-view-4220）；控件结合 JS 事件也可切换分页/轮播器 Tab（doc-view-5003/5007）【实测·本文件核心结论】 |
| 接口生效范围 | FVS 大屏报表接口仅适用于装了「FVS大屏编辑模式」插件的模板，用于 FVS 大屏报表 JS 事件（doc-view-5103）【实测·本文件】 |
- 版本主线：11.0.2/V1.2.0 字体统一 px + 自定义模型组件 → 11.0.4/V1.3.0 jxbrowser 6.23/7.22 → 11.0.6/V1.5.0 六种控件 + V1.5.1 样式圆角/毛玻璃/倒影/阴影 + V1.6.0 Unity 组件 + V1.8.0 画布「双向铺满」→ 11.0.9/V1.9.1 轮播器接口、V1.10.1 `setTabVisible`、V1.11.0 表格工具栏/地面特效、V1.12.0 资源复用
- 轮播器组件接口：`getShowIndex()`、`showCardByIndex()`（11.0.9/V1.9.1 起）、`setTabVisible`（V1.10.1 起）
- FVS 大屏报表接口仅适用于装了「FVS大屏编辑模式」插件的模板，用于 FVS 大屏报表 JS 事件（doc-view-5103）
