# FVS / 图表空数据自定义提示（如「暂无已超时数据」）

> 来源：社区03批次 T-shequ03-009 miss 消化卡（bbs.fanruan.com/wenda/question/231643）｜ KB_AUDIT_TAG=KV1 ｜ 2026-09-12
> 依据：`chart_summary` doc-view-2336/3241、`fvs_dashboard_summary` doc-view-4339、`ckzl/lc/08_技术选型与调试.md` §16.6、`WQ-DSH-0006`；FVS 端 UI 细节未经原文核验处标【推演】。

## 1. 问题

FVS 大屏里某图表没有数据时，默认空白提示不友好，想自定义提示内容——例如显示「暂无已超时数据」这样的占位文案。

## 2. 结论（先答）

| 场景 | 做法 | 提示物 |
|------|------|--------|
| 所有图表统一换默认空提示 | 设计器菜单栏「服务器」→ 图表空数据提示 → 自定义提示**图片** | 图片 |
| 单个图表、要显示**文字**文案（本问场景） | 条件属性控制图表与提示组件显隐 + `ROWCOUNT("ds1")==0` 判空 | 文字/图片组件 |

## 3. 方案 A：全局空数据提示（有据）

- 入口：设计器菜单栏「服务器」下自带「图表空数据提示」功能，进入设置界面自定义提示图片。
- 两个注意点：设置的是**提示图片**而非文字；且**作用于所有图表**（想单图表单独给文案必须走方案 B）。
- 依据：`ckzl/lc/fr11_knowledge/chart图表/references/chart_summary.md` L490，doc-view-2336「图表自定义空数据提示」。

## 4. 方案 B：单图表 + 自定义文字（有据，本问推荐）

- 官方示例做法（doc-view-3241）：
  1. 报表里插入图表 + 自定义提示（文本/图片组件，文案如「暂无已超时数据」）；
  2. 用**条件属性**控制图表与提示组件的隐藏/显示；
  3. 判空公式：`ROWCOUNT("ds1") == 0`（ds1 为该图表绑定数据集，示例 `SELECT * FROM 销量 where 地区='${地区}'`）。
- 依据：同文件 L642，doc-view-3241「单个图表自定义空数据提示」。

## 5. FVS 侧适用性

- FVS 图表组件「内容的设置项，与在普通报表/决策报表中使用方法基本一致，有区别的点见该文档第 5 章」（依据：fvs_dashboard_summary doc-view-4339）→ §3/§4 思路同样适用于 FVS 图表。
- 【推演】FVS 大屏上方案 B 的载体：图表组件 + 文本组件组合，判空用图表数据集 ROWCOUNT 或图表加载结束事件 JS 判断；FVS 插件各版本 UI 入口有差异，以所用插件版本文档为准。

## 6. 排错：空数据提示不生效

按 `ckzl/lc/08_技术选型与调试.md` §16.6「图表空数据提示不生效的四步判定序」排查（L386 起；内部实现参考 `com.fr.plugin.chart.ToJSONHelper#addChartEmptyDataStyleConf`）。
