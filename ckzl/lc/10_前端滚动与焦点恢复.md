# 前端滚动与焦点恢复（冻结表头报表）
> 问法入口（2026-09-13 收官补，P5-008）：「表格/行数不固定 怎么滚动展示全部」「内容超一屏向上滚动」→ 本文件滚动与焦点恢复方案；动态分页加载另见 ckzl/lc/fr11_knowledge/js-api二次开发/。

> 适用场景：报表配置了冻结表头，页面包含展开/缩小按钮，点击按钮触发参数查询后页面刷新，
> 需要回到点击前的浏览位置（纵向滚动 + 横向列位置）。

### 常见问法：点查询/展开按钮后滚动位置丢了，怎么回到点击前的地方？

| 症状/口语问题 | 动作 | 出处（本文件§+行号） |
|---|---|---|
| 冻结表头+展开/缩小按钮，点完查询页面刷新就跳回顶部 | 走本文件终极方案：底部隐藏行 `<script>`（不依赖 afterinit/afterload 时机）+ 按钮唯一 id + 单元格前缀匹配恢复 | §2 L33-108；适用场景 L13-14 |
| scrollIntoView 了但只有冻结区回去、明细不动 | `scrollIntoView()` 只滚最近可滚动祖先（冻结表头 div）；要手动 `document.getElementById('frozen-center')` 设 scrollTop + 按单元格定位横向 | §1 L27、§3 L114 |

## 1. 问题背景与 DOM 结构

FR 冻结表头后，页面被拆成**多个独立 table 块**，各自有独立的滚动容器：

| 容器 | 作用 | 说明 |
|------|------|------|
| `#frozen-center` | 中间明细数据区 | 纵向+横向滚动，`parent: slimScrollDiv`（slimScroll 插件接管） |
| `#frozen-west` | 左侧冻结列区 | 与 `#frozen-center` 纵向同步 |
| 冻结表头 table | 顶部表头（含按钮） | 独立 table，不随明细滚动 |

**关键认知**：
- `scrollIntoView()` 只滚动最近的**可滚动祖先**（= 冻结表头 div），不会滚明细 table —— 这是"只有冻结区域回去"的根因
- 直接设置 `#frozen-center.scrollTop` 可能被 slimScroll 重置
- 单元格 id 格式：`CF{row}-{sheet}-{col}`，如按钮 `CF2-0-76`、明细同列 `CF27-0-76`
- **id 后半段会变**（`-0-76` 是刷缓存用的），只能信任第一个 `-` 前的**前缀**（`CF2`）
- 列宽会随展开/收缩变化，横向不能用数值恢复，必须**按单元格定位**

## 2. 终极方案（11+ 次迭代验证）

**核心思路**：不依赖 afterinit/afterload 事件（时机不可靠），改用**底部隐藏行 `<script>` 标签**，
script 随 HTML 渲染自动执行，不依赖事件时机、不与按钮动态参数 JS 冲突。

### 2.1 按钮分配唯一 id

每个展开/缩小按钮的 HTML 用**不同的 id**（原来都是 `id='add'`）：

```
id='add_show001'  id='add_show002'  ...  id='add_show014'
```

⚠️ 按钮 cell 有两处 HTML：`<O>`（正常显示）+ `<HighlightAction>`（条件属性，切换时显示另一张图），**两处都要改 id**。

### 2.2 底部新增隐藏行（行高=0）

- 找到报表最大行号 `max_row`，新增行 `max_row+1`
- **条件属性行高设为 0**（隐藏该行）
- 该行任意一个单元格设置 `showAsHTML="true"`，内容为 `<script>...</script>`

⚠️ 修改 `RowHeight` 时注意：`<![CDATA[` 标记只能出现一次，用 `split(',')` 拼接时不要把 CDATA 标记混进值里（会导致 `For input string: "<![CDATA[1442289"` 报错）。

### 2.3 script 内容

```javascript
/* 1. 注册事件委托（页面加载时执行一次） */
$(document).off('click.__exp').on('click.__exp', "div[id^='add_'] img", function(e) {
  var div = $(this).closest("div[id^='add_']");
  var divId = div.attr('id') || '';
  var prefix = divId.replace('add_', '');   // add_show005 → show005
  var fc = document.getElementById('frozen-center');
  window.__exp_prefix = prefix;             // 存按钮的 show 前缀
  window.__exp_scrollTop = fc ? fc.scrollTop : 0;  // 存纵向位置
});

/* 2. 页面刷新后自动恢复（script 每次渲染都执行） */
if (window.__exp_prefix) {
  var prefix = window.__exp_prefix;
  var st = window.__exp_scrollTop || 0;
  window.__exp_prefix = null;
  window.__exp_scrollTop = null;
  var n = 0;
  var timer = setInterval(function() {
    n++;
    var fc = document.getElementById('frozen-center');
    var fw = document.getElementById('frozen-west');
    if (fc && fc.scrollHeight > 100) {
      var tds = fc.getElementsByTagName('td');
      for (var i = 0; i < tds.length; i++) {
        var tid = tds[i].getAttribute('id') || '';
        if (tid.indexOf(prefix) === 0) {   // 前缀匹配：CF2-... 或 show005-...
          clearInterval(timer);
          fc.scrollTop = st;               // 恢复纵向
          if (fw) fw.scrollTop = st;       // 左冻结列同步
          var cRect = fc.getBoundingClientRect();
          var tRect = tds[i].getBoundingClientRect();
          fc.scrollLeft += (tRect.left - cRect.left - 30);  // 恢复横向（按单元格定位）
          break;
        }
      }
    }
    if (n > 50) clearInterval(timer);      // 最多等 10 秒
  }, 200);
}
```

### 2.4 关键点

| 要点 | 说明 |
|------|------|
| **存储** | 用 `window.__exp_*` 变量（查询刷新后仍有效）；参数面板隐藏控件也可但不如 window 直接 |
| **前缀匹配** | `tid.indexOf(prefix) === 0`，不匹配完整 id（后半段会变） |
| **横向** | 用 `getBoundingClientRect()` 找目标 td 的实际位置，滚动 `scrollLeft += delta`，不存数值 |
| **等待** | `setInterval` 轮询等 `scrollHeight > 100`（DOM 渲染完），不固定延时 |
| **不要用** | `scrollIntoView`（只滚冻结区域）、固定 `setTimeout`（渲染未完成）、存 scrollLeft 数值（列宽会变） |

### 常见问法：scrollTop 设了又弹回 0 / script 不执行 / RowHeight CDATA 报错，怎么排查？

| 症状/口语问题 | 动作 | 出处（本文件§+行号） |
|---|---|---|
| 设置 scrollTop 后用户一滚就弹回 0 | slimScroll 接管所致：读用原生 `fc.scrollTop`（slimScroll 同步更新原生值），设用 `$(fc).slimScroll({scrollTo: st})` 双保险 | §3 L115 |
| afterinit 里挂的委托不触发、__exp_prefix 是 undefined | 事件时机不可靠，改底部隐藏行 `<script>` 随渲染自动执行 | §3 L116、§2 L35-36 |
| 报 For input string: "<![CDATA[1442289" | RowHeight 拼接时 CDATA 标记混进了值：`<![CDATA[` 只能出现一次，`split(',')` 别把标记拼进数字 | §2.2 L54、§3 L118 |
| 页面打不开报 Missing catch or finally after try | 检查 CDATA 内残留的 `*/` 注释碎片、`try` 关键字 | §3 L117 |
| 事件委托分不清点的是哪个按钮 | 每个按钮唯一 id `add_show001`~`add_show014`；`<O>` 与 `<HighlightAction>` 两处 HTML 都要改 | §2.1 L43-46、§3 L119 |
| 恢复没生效想逐步定位 | F12 Console 四步：查 `window.__exp_*` / 按钮 id 唯一性 / script 是否渲染 / 滚动容器 scrollHeight，代码照抄 §4 | §4 L121-140 |

## 3. 踩坑记录

| 坑 | 现象 | 解决 |
|----|------|------|
| `scrollIntoView` 只滚冻结区域 | 按钮回来了但明细数据没动 | 手动找 `#frozen-center` 设 scrollTop + 按单元格定位横向 |
| slimScroll 重置 | 设置 scrollTop 后用户滚动时弹回 0 | 事件委托读原生 `fc.scrollTop`（slimScroll 同步更新原生值）；设置时可用 `$(fc).slimScroll({scrollTo: st})` 双保险 |
| afterinit 委托不触发 | `window.__exp_prefix` 为 undefined | 改底部隐藏行 script 方案 |
| JS 语法错误 `Missing catch or finally after try` | 页面打不开 | 检查 CDATA 内是否有残留的 `*/` 注释碎片、`try` 关键字 |
| RowHeight CDATA 嵌套 | `For input string: "<![CDATA[1442289"` | CDATA 标记只保留一层 |
| 按钮 id 重复 | 事件委托分不清点的是哪个 | 每个按钮唯一 id：`add_show001`~`add_show014` |

## 4. 诊断方法

浏览器 F12 Console（Designer 填报预览）：

```javascript
// 1. 检查变量是否写入
console.log(window.__exp_prefix, window.__exp_scrollTop);

// 2. 检查按钮 id 是否唯一
$("div[id^='add_']").each(function(i){ console.log(i, $(this).attr('id')); });

// 3. 检查 script 是否渲染
document.querySelectorAll('script').forEach(function(s){
  if (s.textContent.indexOf('__exp') >= 0) console.log('FOUND exp script');
});

// 4. 检查滚动容器
var fc = document.getElementById('frozen-center');
console.log(fc ? 'scrollH=' + fc.scrollHeight + ' scrollTop=' + fc.scrollTop : 'NOT FOUND');
```
