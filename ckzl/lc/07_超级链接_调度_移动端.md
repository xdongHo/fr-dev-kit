## 11. 超级链接（六类总表 + 动态参数 / JavaScript 详解）

> 来源: 帆软官方帮助 doc-3556（图表联动-当前表单对象）/ doc-4202（超级链接-动态参数）/ doc-4204（超级链接-JavaScript脚本）/ doc-1839（JS实现获取超链URL参数值）/ doc-4241（JS实现超链跳转前判断子模板是否有数据）

### 11.1 六类超链总表（doc-3556 汇总，选型看终端支持）

超链知识散落 4202/4204/4207/4209/3556 五篇，寻址方式与终端支持互不相同甚至相反——生成器选型时必须查表：

| 类型 | 适用模板 | 寻址方式 | 取值来源 | 终端支持 |
|------|---------|---------|---------|---------|
| ① 网络报表 ReportletHyperlink | .cpt + .frm | 目标模板路径 | 参数 `=$$$` | PC+App+HTML5 |
| ② 动态参数（doc-4202） | .cpt + .frm | 模板参数名 | 设计期字面量 | PC+App+HTML5 |
| ③ JavaScript（doc-4204） | .cpt + .frm | 任意前端逻辑 | 参数 `=$$$`/`=A2` | 看所用接口（window.open 不支持移动端） |
| ④ 联动单元格图表（doc-4207） | .cpt | 单元格名（A5） | 参数 `=$$$` | PC+App+HTML5 |
| ⑤ 联动悬浮元素（doc-4209） | .cpt | 悬浮元素名（Float1） | 参数 `=$$$` | **仅 PC 分页预览** |
| ⑥ 当前表单对象/当前决策报表对象（doc-3556） | .frm | WidgetName | 图表源=系列名称/分类名；单元格源=`=A2`/`=$$$` | PC+App+HTML5 |

- 联动四链一致性（断一处即静默失效）：超链 target 指向真实 WidgetName/单元格 ↔ 超链参数名 = 目标组件所绑数据集参数名 ↔ 数据集 SQL 含 `${参数名}` ↔ 参数有默认值（首屏不空）。
- ⚠️ 组件重命名 = 联动整体失灵且完全静默（WidgetName 是跨组件唯一引用键）。

### 11.2 动态参数超链（doc-4202，点击列头重提交报表）

- 本质：单元格挂「动态参数」超链，点击时 FR 用超链携带的参数值**重新提交报表**（等效 parameterCommit + 新参数），无需 JS/按钮。最典型用法 = 排序切换：数据集 SQL `SELECT * FROM 订单 ORDER BY 订购日期 ${a}`，同一列头挂两条超链分别给 `a=ASC`/`a=DESC`。
官方样本 `%FR_HOME%\webapps\webroot\WEB-INF\reportlets\doc\SpecialSubject\HyplinkReport\动态参数超链实现排序.cpt`）。
- **两条铁律**：① 超链参数名必须 = 数据集 `${a}` 参数名；② SQL `${a}` 占位符必须存在同名模板参数——缺任一 FR 不报错，只是点了排序无效（静默）。
- 超链参数值是设计期固定的字面量（ASC/DESC），无 SQL 注入面；官方确认支持 App/HTML5 端。

> 参考 `practice/topic_4202/inject_dynamic_param.py`。

### 11.3 JavaScript 超链（doc-4204 三类并列 + doc-1839 站内/外链 + doc-4241 服务端开关）

**JS 超链 = .cpt 里「点击单元格执行任意前端逻辑」的唯一通用挂点**（逐行导出/弹窗/联动父页）。XML 形态：

```xml
<C>
  <HyperlinkGroup>
    <NameJavaScript name="JavaScript脚本">
      <JavaScript class="com.fr.js.JavaScriptImpl">
        <Parameters>
          <Parameter>
            <Attributes name="ID"/>
            <O t="XMLable" class="com.fr.base.Formula">
              <Attributes><![CDATA[=A2]]></Attributes>
            </O>
          </Parameter>
        </Parameters>
        <Content><![CDATA[ ... ]]></Content>
      </JavaScript>
    </NameJavaScript>
  </HyperlinkGroup>
</C>
```

（HyperlinkGroup/NameJavaScript 节点名为**推断待核验**；官方样本 `%FR_HOME%\webapps\webroot\WEB-INF\reportlets\doc\SpecialSubject\HyplinkReport\JavaScript超链导出Excel.cpt`）

- 超链参数名 = **JS 变量名**（须合法 ASCII JS 标识符且非保留字，中文字段名直接当参数名是高频坑）；参数值用公式 `=A2` 才能「每行取本行值」，前提是挂超链格与 A2 在同一扩展父子链（否则 N 行按钮全取同一个值，静默）。
- ⚠️ **生成器禁用 str.format/f-string 拼含 `${servletURL}` 的 JS**（FR 服务端占位符与 python 模板语法冲突）；`<Content>` 是 CDATA，JS 含 `]]>` 会截断 XML。
- `FR.cjkEncode(整条URL)` 是中文项目站内导出的必需项。

**站内 vs 外链（doc-1839，与 doc-4204 站内导出互为镜像，四维对照）**：

| 维度 | 站内（doc-4204） | 外链（doc-1839） |
|------|-----------------|-----------------|
| URL 前缀 | `${servletURL}` | 写死 `http://host/path`，**协议头不可省**（省了按相对路径解析 → 拼到报表服务域名下 404） |
| 中文编码 | `FR.cjkEncode(整条URL)`（FR 私有编码，只有 FR 服务端能解回） | `encodeURIComponent(单个值)` |
| 典型用途 | `format=excel` 导出 | 跳第三方系统 |
| 失败表现 | 乱码 404 | 拼到报表服务域名下 404 |

> 判据不是「要不要编码」而是「URL 指向谁」——两篇写法**互斥不可混用**。参考 `practice/topic_1839/check_url_hyperlink.py`。

**跳转前判断数据（doc-4241，服务端开关告警）**：JS 超链 + `FR.remoteEvaluate("SQL(...)")` 在服务端先跑子模板查询，非空才跳转、否则弹窗——双分支必须齐全（缺 alert 分支 = 永远跳/永远不跳的静默）。`SQL(ds, sql, 1)` 第三参 1 = 返回第一列数组，用 `.length` 判空。
- ⚠️ `FR.remoteEvaluate`/`FR.doHyperlinkByPost` 依赖公式引擎，FR10 默认「安全防护 → 脚本调用公式限制」开启时会拦截——**此开关是服务端配置、不是 .cpt 属性、生成期无法自检**，凡模板 JS 用到必须向部署方确认已关闭。
- 该 JS 超链方案不支持 App/HTML5 端（仅 PC 分页预览）。

> 参考 `practice/topic_4241/gen_precheck_hyperlink.py`；可复用 JS 超链骨架。

### 11.4 超链类型 × 导出存活性（doc-3321）

> 来源: 帆软官方帮助 doc-3321（超链接导出到Excel）

FineReport 自带 Excel 导出**不保留任何超链**，需装「Excel 超链接导出」插件（FR10.0 / JAR>=2018-07-31 / V1.0，**设计器+服务器均装**）。装后仅三类能进 Excel：网络报表（`com.fr.js.ReportletHyperlink`）、网页链接（`com.fr.js.WebHyperlink`）、Sheet链接（插件新增）；**图表交互超链官方明确不导出**；JS 超链无法表达为 Excel 超链。

| 超链类型 | 类名 | Web预览 | Excel导出 | 移动端 | 插件依赖 |
|---------|------|---------|----------|--------|---------|
| 网络报表 | `ReportletHyperlink` | ✅ | ✅（装插件后） | ✅ | Excel超链接导出插件 |
| 网页链接 | `WebHyperlink` | ✅ | ✅（装插件后） | ✅ | Excel超链接导出插件 |
| Sheet链接 | 插件新增 | ✅ | ✅（装插件后） | — | Excel超链接导出插件 |
| 图表交互 | — | ✅ | ❌ | — | — |
| JS 超链 | `JavaScriptImpl` | ✅ | ❌（无法表达） | 看接口 | — |

> 无头生成的模板若下游要导 Excel，选错超链类型会**静默降级成纯文本、零报错**——最难排查的一类问题。

> ⚠️ **移动端列「看接口」细化为「按 JS 接口区分」**（来源: 帆软官方帮助 doc-1396 / doc-946，doc-3741 归口）：JS 超链在移动端是否生效**取决于 JS 内容**——`FR.logoutApp()` 等 App 接口经 JS 超链在移动端 App 生效（doc-1396 实证：单元格 JS 超链触发 App 登出），而 `FR.remoteEvaluate`/`doHyperlinkByPost` 类 JS 超链仅 PC 分页预览（见 §11.3 doc-4241/doc-946）。生成器不得一刀切「JS 超链不支持移动端」——「移动端登出按钮」可程序化产出（载体 = 单元格 JS 超链 + `JavaScriptImpl#setContent`，doc-1396 批）。

### 11.6 动态参数超链真实类名（doc-4195 + doc-4624）

> 来源: 帆软官方帮助 doc-4195（超级链接）/ doc-4624（超级链接）

⚠️ **全库改名**：「动态参数」超链的真实类是 `com.fr.js.ParameterJavaScript`（extends `com.fr.js.AbstractJavaScript`）；kit 现存的 `com.fr.js.DynamicParamHyperlink` / `DynamicParamLink` 两个写法**均不存在**。字节码探针 `jar_class_probe.py --jars C:/frjars find DynamicParam` 全量 jar 仅 3 命中（`com.fr.base.DsDynamicParamsKey` + 两个 hibernate `DynamicParameterizedType`），**无任何超链类**。

- 类特性：`dump` 结果只有 `<init>()` / `actionJS(Repository)` / `createJSONObject(Repository)` / private `createParaJSON()`——**类上零 setter**，参数只能走继承来的 `AbstractJavaScript#setParameters(com.fr.stable.ParameterProvider[])`。
- 这是继 doc-223 已纠正的 `JavaScriptHyperlink`→`JavaScriptImpl`、`NetworkReportLink`→`ReportletHyperlink`、`EmailHyperlink`→`EmailJavaScript` 之后的**第四例「按 GUI 中文名直译类名」系统性误记**；「GUI 面板上的中文名（动态参数/网页链接/邮件）与类名无任何构词关系，必须 find 一遍」。
- **统一核验**（doc-4624）：用官方随装模板 `doc\SpecialSubject\HyplinkReport\动态参数超链实现排序.cpt` 反查真实类名与节点层级，固化进 §11.2 与 `fr_rules_doc` 校验器——两处 class 名互相矛盾且均未在 kit 全库找到真实样例，属「节点名未核验前不要伪造 XML」的待办。

### 11.7 超链装配：NameJavaScriptGroup 追加（doc-4195）

> 来源: 帆软官方帮助 doc-4195（超级链接）

超链追加用 `Elem#getNameHyperlinkGroup()` 取旧组，为空才 `new NameJavaScriptGroup()` + `setNameHyperlinkGroup(...)`，再 `addNameHyperlink(new NameJavaScript(name, js))`——**与 `HighlightGroup` 对照说明**：`NameJavaScriptGroup` 有 add 方法可**原地追加**；`HighlightGroup` 没有、必须重建数组（doc-958 铁律「读旧→合并→整体 set」）。若把重建数组的写法照搬过来，每挂一条超链就抹掉同格已有超链（一个格子挂多条超链是常规用法）。

### 11.8 超链跳转到指定 sheet/锚点（doc-4298）

> 来源: 帆软官方帮助 doc-4298（超链跳转到指定 sheet 页）

跨模板定位的高频需求标准范式（主模板 + 子模板两段）：

- 主模板：`com.fr.js.ReportletHyperlink`（非 NetworkReportLink）指向子模板并**强制 `&op=write`**（填报预览，否则 `_g()`/contentPane 不可用、JS 不生效），参数 `a=$$$`（取被点击格当前值）。
- 子模板：注入「加载结束」`<Listener>`（afterload）执行 `$(".fr-sheetbutton-container").eq(b).trigger("click")`，b 即 `WorkBook.addReport` 的 **0 起下标**（sheet 序号）。
- 该「加载结束」JS **无法用 FR Java API 表达**，走「Java 建承载层 → writeTemplateWorkBook → Python 注入节点」流水线；方案**不支持 App 端 / HTML5 端**预览。
- 参考 `practice/topic_4298_java/SheetHyperlinkBuilder.java`。

### 11.9 网页链接 WebHyperlink 与文件下载硬约束（doc-2637）

> 来源: 帆软官方帮助 doc-2637（超链查看文件）

- 标准范式：`DefaultTemplateCellElement#setHyperLink(new com.fr.js.WebHyperlink(url))`（可 `setTargetFrame("_blank")`）；XML 落在 `<HyperLink><WebHyperlink url="..."/></HyperLink>`。类/方法经 fine-report-engine-10.0.jar 字节码核验（`<init>(String)` / `setURL` / `setTargetFrame`）。
- 与 `ReportletHyperlink`（网络报表/跨模板）是**两条不同类链**：挂法同（`setHyperLink`）但用途、XML 标签不同——「文件下载/外链」场景**不得误用 ReportletHyperlink**（链接打开的会是报表而非文件）。
- **文件下载两条硬约束**：① 文件**绝不能放进 `webapps/webroot/WEB-INF`**（移动端读不到），只能放 webroot 工程目录；② URL 里的 `/webroot` 是**应用上下文名（工程名）**，严谨写法用 `com.fr.stable.ProductConstants.getWebAppName()` 拼接，**禁止在生成脚本里硬编码 `webroot`**（工程改名现场静默 404，与 doc-2804「禁止硬编码目录名」同源）。两条都是「配错不报错、只在改过工程名/移动端才暴露」的静默坑。
- 参考 `practice/topic_2637_java/ViewFileHyperlinkBuilder.java`。

### 11.10 超链 Java 面分层：模板属性 vs 运行时行为（doc-2637）

> 来源: 帆软官方帮助 doc-2637 / doc-918 / doc-4241

超链不能当纯模板属性处理，按两层落地：

- **模板属性层**：`com.fr.js.ReportletHyperlink`（`setReportletPath` / `setTargetFrame("_self")` / `setShowParameterInterface` / `setExtendParameters`）、`com.fr.js.JavaScriptImpl`（`setContent` / `setParameters` / `setShouldRecalculate`）；挂载唯一入口 `com.fr.report.cell.AbstractCellElement#setNameHyperlinkGroup(NameJavaScriptGroup)` + `new NameJavaScript(name, js)`（声明在抽象基类上，不在 `TemplateCellElement`/`CellElement` 接口，见 §11.7）。
- **运行时行为层**：`extendParameters` 的实际效果由 Web 会话（`SessionPoolManager.getSessionIDInfor` + `getParaInParameterContainer`）+ 两级过滤器 + 20 字符门共同决定——**无头侧只能保证开关落盘、不能保证参数真的传过去**，交付说明须写明该边界；「**显式声明超链参数**」比「勾继承」更可靠，生成器默认显式声明。

### 11.11 网络报表超链构建铁律（doc-3030）

> 来源: 帆软官方帮助 doc-3030（模板认证下的超级链接继承权限）

- 主→子报表跳转一律用网络报表超链**纯模板路径 + 参数传参**（`setPath`/`addParameter`/`setTarget` ↔ XML `<ReportletHyperlink><Path>/<Parameters>/<Target>`；kit 已核类名 `com.fr.js.ReportletHyperlink`，doc-947/2128；doc-3030 原文记 `com.fr.report.web.ReportletHyperlink`，包名归属待统一核验，功能面一致）；
- **禁止两种写法**：① 参数拼在模板路径后（Path 含 `?` 参数串）；② `WebHyperlink` 填模板预览 URL（XML `<WebHyperlink><URL>`）——**模板认证开启时权限不继承**（仅「超链方式=模板路径」可继承），子报表访问异常且**静默无报错**；
- 无头生成默认应产出可继承形态，否则部署开认证后静默失效。

### 11.12 App 端跳转 + 自定义标题（doc-1393）

> 来源: 帆软官方帮助 doc-1393（［App］JS 自定义超链标题）

- JS 超链 Content 直接写新版 JSON 对象写法即可实现 App 端跳转且标题自定义：

```
FR.doHyperlinkByGet({url:'${servletURL}?viewlet=目标.cpt', title:'标题', para:{area:'华北'}})
```

- ⚠ 三约束：**title 仅 App 生效**（PC/H5 不支持，仍显示报表名）；para 键必须与目标模板参数同名；参数 title 仅支持 JSON 对象写法（旧式多参调用不带 title）；
- 与 §11.4「移动端按 JS 接口区分」呼应，`doHyperlinkByGet` 归入 App 端生效接口清单；`${servletURL}` 处生成器禁用 str.format 拼接（§11.3 ⚠️）。

### 11.13 移动端弹窗场景配方（doc-3202）

> 来源: 帆软官方帮助 doc-3202（移动端弹窗）

- 子模板弹窗 = `ReportletHyperlink`（`setReportletPath`/`setShowParameterInterface`/`setExtendParameters`）挂单元格（doc-2128 已核 setter）；
- 文本注释 = JS 超链 `JavaScriptImpl#setContent`；
- 边界：**cpt 填报不生效、仅 frm 支持填报**；10.4.66+ 弹窗内子模板超链可触发；
- 运行时约定：超链 URL 末尾拼 `&_method=POST`（必须全大写、必须末尾）可规避移动端弹窗参数多/长时的「网络请求失败」。

### 11.14 移动端超链打开与返回逻辑（doc-3138）

> 来源: 帆软官方帮助 doc-3138（［通用］移动端超链窗口打开逻辑）

移动端返回行为与 PC 不同且无标签页语境：

- 网络报表/网页链接打开于**新窗口/对话框** → 子模板返回主模板；打开于**当前窗口** → 子模板返回目录；
- JS 超链 `target=not_self` 同新窗口（返回主模板）、`_self` 同当前窗口（返回目录）；
- headless 构建移动端模板时 `setTarget` 决策（dialog/_blank vs _self）**直接决定用户返回路径**——主-明细钻取建议 dialog/_blank，避免移动端用户跳明细后回不到主模板。

### 11.15 JS 触发超链 ↔ 后端节点等价（doc-622）

> 来源: 帆软官方帮助 doc-622（FineReport内置方法）

- `FR.doHyperlinkByGet/Post(url, config, target, feature)` 是 JS 触发动作；无头等价 = 单元格 `<Hyperlink>` 节点（config→Parameters、target(_dialog/_self/iframe name)→打开位置、feature→窗口属性）+ Java 类族 `com.fr.report.cell.cellattr.hyperlink.*`（UrlHyperlinkProvider/ReportletHyperlinkProvider/JavaScriptHyperlinkProvider，类名与挂载 setter 待核验）；

### 11.16 平台新标签页打开：JS 类型超链（doc-4229）

> 来源: 帆软官方帮助 doc-4229（平台新标签页打开超链）

- **JS 类型超链（JavaScriptHyperlink）**：`com.fr.report.cell.cellattr.hyperlink.JavaScriptHyperlink`（`setContent` 写 JS 代码）+ `CellElement.addHyperlink` 挂载（与网络报表超链 ReportHyperlink 同入口不同实现）；XML 落点 `<Hyperlink><JavaScriptHyperlinkProvider><JavaScript>`（节点待导出核对）——区别于 §11.3 的 `com.fr.js.JavaScriptImpl`（NameJavaScript 路径）；
- JS 代码标准形态：`window.parent.FS.tabPane.addItem({title, src:"${servletURL}?viewlet=相对路径&参数名="+JS变量})`；超链参数以 JS 变量直接引用（非 `${}` 模板语法）、值公式 `=$$$` 取当前单元格值（点哪行传哪行）；
- 适用边界：JS 超链用于平台前端行为（平台新标签打开/自定义逻辑），**仅决策平台挂载生效，直接预览不支持**——预览时点超链无反应属正常现象，勿当 bug 排查；报表间跳转仍用网络报表超链；
- 两条实现路径：JS 超链（免插件，代码形态如上）或装「平台内打开标签页」插件后超链配置选「平台内新标签」（与 doc-1696 插件打开方式互相印证）；
- 目标报表须有同名参数接收 `=$$$` 传来的当前单元格值，否则打开无联动。

## 12. 定时调度与结果单元格（doc-3315）

> 若 .cpt 将作为**定时调度对象**（调度周期-公式判断 / 文件名称 / 通知内容引用单元格值），结果单元格必须满足以下约束，否则**静默失败**（来源: 帆软官方帮助 doc-3315）。

- **公式判断只取默认 sheet 的单元格，不得跨 sheet 引用**（跨 sheet 公式 `'sheet1'!A1` 仅 10.0.17+ 且仅公式判断可用，不支持聚合报表）。
- 包裹写法铁律：公式判断里**裸写 A2**；文件名称/通知引用须 **`${A2}`**——写错静默失败。
- JAR ≥ 2018-12-27 时 `${A1}` 取到扩展后的「数组」，更早 JAR 只取第一个值。
- 函数作公式时**不要写 `=` 号**；FORMAT 不能引用模板单元格、WEIGHTEDAVERAGE 参数只能常数数组；调度里无效项：COL()/ROW() 恒 0、REPORTCHECK 不生效、SEQ 恒 1、WEBIMAGE 返回字符串等。
- 用户全局参数 `${fine_username}` 等需勾选「根据默认用户组单独生成结果」才生效。
- **（doc-697 权威出处，§3.3）** 勾选「根据默认用户组单独生成结果」后，**模板类型只支持「预览」**（填报/分析不支持）——生成器不得产出填报型定时任务模板（会直接产出非法任务配置）；过滤维度除 `$fine_username` 外也支持 `$fine_role` / `$fine_position`，逻辑对称。
- 调度任务内**无法触发报表 JS 事件**（与 ckzl/lc/05 §10.6 定时调度不触发 Web 属性事件同源，见 doc-3185）。

> 参考 `practice/topic_3315/`（cpt_params.xml 最小片段 + formula_rules.py ${} 包裹归一化器）。

## 13. 移动端属性（自适应/缩放，doc-2931 + doc-575 + doc-3531）

> 来源: 帆软官方帮助 doc-2931（移动端属性）/ doc-575（移动端自适应）/ doc-3531（移动端自适应）

**三处挂载点与 XML 形态（包裹层数不同，任何硬编码 XPath 的脚本换宿主即失效）**：

| 宿主 | Java 落点 | XML 形态 |
|------|----------|---------|
| .cpt 整本模板 | `WorkBook#setReportMobileAttr(new ElementCaseMobileAttr())` | `<ElementCaseMobileAttr><ElementCaseMobileAttrProvider horizontal="?" vertical="?" .../></ElementCaseMobileAttr>` |
| .frm 表单 | `Form#setFormMobileAttr(com.fr.form.main.mobile.FormMobileAttr)` | `<FormMobileAttr><FormMobileAttr .../></FormMobileAttr>`（内外同名），属性集不同、不可套用 |
| 报表块（ElementCaseEditor 内） | — | **无外层包裹**，直接写 `<ElementCaseMobileAttrProvider .../>` |

- **方向枚举 `com.fr.base.mobile.MobileFitAttrState`**：`DEFAULT(0) / HORIZONTAL(1) / VERTICAL(2) / NONE(3) / BIDIRECTIONAL(4)`；`horizontal`=横屏（Pad 也用它）、`vertical`=竖屏——**属性名是屏幕方向、值是自适应方向**。
- ⚠️ **Java setter 是官方错拼 `setHorziontalAttr`**，XML 属性却是正拼 `horizontal`——写反极易且静默生效（手机上才看得出）。
- ⚠️ **属性挂 WorkBook（整本模板）不挂 WorkSheet**——与章节中其余设置的心智相反，不写明极易找错挂载点。
- **两套枚举**：`MobileFitAttrState`（移动端，含 BIDIRECTIONAL=4）与 `FitAttrState`（PC 端，无 BIDIRECTIONAL）是两套枚举、两套属性——kit 现有生成只写 `<ReportFitAttr>`（PC），移动端子树完全没覆盖，手机上一律吃 DEFAULT 自适应，「排版乱」而无任何报错。
- 参考 `practice/topic_2238_java/`（示例）。

## 14. 模板级移动属性（「手机端模板」开关，doc-3059）

> 来源: 帆软官方帮助 doc-3059（手机端模板）

设计器「模板>移动端属性>手机端模板」对应模板级移动属性 `com.fr.report.mobile.TemplateMobileAttr`（⚠ 待字节码核验）；`Form.setMobileAttr(TemplateMobileAttr)` / `setAppUseMobile(true)`，XML 节点 `<TemplateMobileAttr><MobileAttrAppUseMobile>true</MobileAttrAppUseMobile></TemplateMobileAttr>`（节点名待核）。
