## 7. 扩展后排序（doc-897 基础 + 2684/1782/3622/3309/3717 变体）

> 来源: 帆软官方帮助 doc-897（扩展后排序）/ doc-2684（按分组汇总结果排序）/ doc-1782（横向扩展列多列排序）/ doc-3622（利用内置数据集实现自定义排序）/ doc-3309（扩展后中文按拼音排序）/ doc-3717（汉字数字排序）

> **排序落点路由**：简单静态升降序 → 数据集 `ORDER BY`（doc-903）；需运行期切方向且允许重查 → 数据集参数 `${a}`；不重查 / 按模板内公式或汇总格排 / 复杂多条件 → 单元格层（本节）。扩展后排序是三种排序里**最慢**的（扩展完成后调整所有格子位置），应是路由表的**兜底项**而非默认项。

### 7.0.1 排序方案五选一路由表（doc-2487，钉死五档边界）

> 来源: 帆软官方帮助 doc-2487（数组状态参数排序）/ doc-903（数据集排序）/ doc-1894（单元格排序）/ doc-897（扩展后排序）/ doc-2684（按汇总格跨层排）

| 档 | 方案 | 能力边界 |
|----|------|---------|
| ① | 数据集 `ORDER BY`（doc-903） | 方向固定、静态、性能最好 |
| ② | 数据集参数 `${order}` 内联（doc-903） | 全表切向、**允许重查库** |
| ③ | 单元格 OrderFormula（doc-1894） | 单列切向、不重查 |
| ④ | 扩展后排序 + 单参数取负（doc-897）/ 按汇总格跨层排（doc-2684） | 整表或分组间 |
| ⑤ | 扩展后排序 + **数组状态参数**（doc-2487） | **每分组独立状态、分组内粒度**，唯一需要序列化数组的一档 |

**判据三问**：是否要「每分组各自一份状态」/ 是否允许重查库 / 是否要移动端。前四档做不到分组内独立——遇到「点华东只重排华东」必须走第 ⑤ 档（见 §7.11）。`practice/topic_2487` 已把该表固化为 `route_sort(per_group_state, runtime_toggle, requery_ok)`。

### 7.0.2 扩展前 vs 扩展后排序的 Java 落点（doc-4624）

> 来源: 帆软官方帮助 doc-4624（单元格排序）

两个类上存在**同名同签名的 `setOrder(int)` + `setSortFormula(String)`**，编译期毫无差别，挂错既不报错也不抛异常，只是排序结果不对：

- **扩展前** = `com.fr.report.cell.cellattr.core.group.DSColumn#setOrder(int)` / `setSortFormula(String)`——排数据集分组结果，公式里**只能引用数据集字段**；
- **扩展后** = `com.fr.report.cell.cellattr.CellExpandAttr#setOrder(int)` / `setSortFormula(String)`——排已扩展出的格子，公式里**才能引用单元格坐标**（如 `A2`），挂接 `TemplateCellElement#setCellExpandAttr(..)`。
- `order` 取值统一来自 `com.fr.data.DataConstants`：`NONE=0 / INCREASE=1 / DECREASE=2`（ConstantValue 实读）。
- **判据一句话：排序公式里出现单元格坐标 ⇒ 必须挂 CellExpandAttr**（按「排序=排数据」的直觉挂到 DSColumn 上，那里的公式根本不认识 `A2`）。

### 7.1 基础范式（doc-897）

**落点铁律**：
- ① 排序必须设在**最父格**（同扩展区列号最小的扩展格，如 A2），设在 B2/C2 等子格**不报错也不生效**（静默）。
- ② 方向属性恒写「升序」，方向切换靠公式 `*-1` 取负（`if($order='asc', E2, E2*-1)`）——**不要属性与公式双翻转**（两次翻转互相抵消，静默）。
- ③ 公式引用格必须**数字型**：字符串列不能取负；日期列先 `DATEDIF("1900-01-01", F2, "D")` 转数字。
- ④ 配套模板参数**默认值必须给**（否则首屏走 else 分支 = 降序）；标题格超链改参数，取值锁死白名单。
- ⑤ 版面前提「数据设置=列表」：对应 kit 既有铁律 `<RG class="...FunctionGrouper"><Attr divideMode="1"/></RG>`（doc-897 §2.2 正是这条铁律的官方出处）——漏掉则排序语义从「整表排」退化为「按分组排」。

### 7.2 按分组汇总结果排序（doc-2684）

分组报表同时含「分组格 + 各层小计 + 明细」时，SQL `ORDER BY` 做不到（只能按明细列排），必须模板层。官方解法两步：① 给小计格设**左父格**（`<Expand leftParentDefault="false" left="B2"/>`）；② 给**分组格**设扩展后排序，公式指向同层汇总格。

**错位对应矩阵（极易写反）**：

| 被排序 | 排序公式指向 |
|--------|-------------|
| A2（外层分组） | D4（外层小计） |
| B2（中层分组） | D3（中层小计） |
| C2（内层分组） | D2（明细层） |

**三条铁律**：
- ① 排序公式引用格必须通过**左父格链**挂在被排序格之下（或与之同行）；挂错层/漏挂 → 一个分组对应多个或零个汇总值，排序不可预期且 FR 不报错。
- ② 汇总**逐层上卷**：`D4=SUM(D3)` 而非 `SUM(D2)`，D4 才天然是 A2 的子孙格，层次与排序自洽。
- ③ 隐含执行顺序：**先挂左父格、再设排序公式**；父格未挂时公式引用不到，排序静默失效。

> PC/App/HTML5 均支持，无移动端盲区。声明式 N 层排序计划 + 左父格，详见本文件排序小节。

### 7.3 横向扩展列多列排序（doc-1782，十字交叉表）

纵向最父格 A2 按**横向扩展出来的某一列**（B1=产品）的 B2 值排序。点击交互：B1 列头挂「动态参数」超链，`order = if($order = 1, -1, 1)` + `index = &B1`（`&B1` = 取被点击列序号）。

排序公式（逐字，A2 扩展后排序=升序）：
```
=if(isnull($index), A2, if($order = 1, EVAL("B2[;B1:" + $index + "]"), EVAL("-1*B2[;B1:" + $index + "]")))
```

- `EVAL("B2[;B1:N]")` = 绝对层次坐标，运行期动态取「被点击列」的 B2 值；方向翻转仍靠取负、属性恒升序。
- ① `isnull($index)` 首屏 guard 默认带上（未点列头直接按 A2 排，跳过 EVAL 提升首屏性能）；② B2 设汇总后 **FR 强制不扩展**，生成器不可给 B2 补 `<Expand>`（会被静默忽略）；③ 取负前提仍是数字型。

> 参考 `practice/topic_1782/gen_horizontal_multisort.py`。

**动态列变体（doc-4506，来源: 帆软官方帮助 doc-4624 系列）**：同一套「B1 动态参数超链（order 翻转 + index=&B1）+ A2 扩展后排序 EVAL 绝对层次坐标」可直接套到「使用函数实现动态列」模板。差异点：动态列下 B1/B2 由 UDF 生成、最父格仍是 A2（序号列，纵向扩展）、且须给标题行设 `<RepeatRow><![CDATA[0]]></RepeatRow>` 换页重印表头。kit 目前只覆盖固定交叉表，动态列场景不可误以为该范式不适用。

### 7.4 自定义顺序变体（doc-3622，内置数据集 + inarray）

「华东→华北→华南」业务顺序：内置数据集「自定义顺序」一列（行的先后=最终排序顺序）+ 最父格扩展后排序公式：

```
=inarray(A2, 自定义顺序.select(地区顺序))
```

- ⚠️ **未命中兜底必加**：FR 的 `inarray` 未命中返回 **0**，升序时新值会全部堆到第一行且不报错（doc 原式没做兜底，**不能直接照抄**）：
  ```
  =if(inarray(A2, 自定义顺序.select(地区顺序)) = 0, 9999, inarray(A2, 自定义顺序.select(地区顺序)))
  ```
- inarray 返回数字，倒序可直接 `-1*(inarray(...))`，不受 §7.1③「字符串列不能取负」限制，但属性仍恒写升序。
- 三类静默失效：编码 vs 显示名、首尾/全角空格、顺序表重复值（inarray 只取首个位置）。
- 内置数据集名/列名被**原样拼进公式**（含空格/点/括号即解析失败）——生成器须对内置数据集命名施加标识符白名单。
- 纯服务端排序、零 JS、三端一致；顺序表大时应下沉 SQL 字典表 JOIN sort_no。

> 参考 `practice/topic_3622/gen_custom_order.py`。

### 7.5 中文按拼音排序（doc-3309，`$$$` 自引用）

- 配方：最父格「扩展后排序=升序」+ 公式 `StringPinyin($$$,"",1)`。
- **`$$$` = 扩展后排序里「当前被排序单元格自身」的自引用语法**，与单元格 OrderFormula（doc-1894）的具名格引用（如 A2）不同——生成器拼公式时勿把 `$$$` 误写成具名格，否则排序依据错格但不报错。
- `StringPinyin` 来自「常用函数集合插件」，插件未装时公式**静默失效**（排序退回原序或报错无原因）——生成器须强制标注插件依赖。
- 多音字按插件内置词典默认读音（重庆/长城/银行），业务要求严格时不可控；纯服务端排序、零 JS、三端一致。

> 参考 `practice/topic_3309/gen_pinyin_sort.py`。

### 7.6 汉字数字等「反向构表 + 求下标」通用范式（doc-3717）

FR 没有「汉字数字→阿拉伯数字」的公式，反过来用 `NUMTO()` 把 1..N 批量转成 `[一,二,…]`，再用 `INARRAY()` 求当前值下标当排序键。**可参数化模板**（换掉 `NUMTO` 即得罗马数字/字母序号/自定义编码版本）：

```
=INARRAY($$$, MAPARRAY(RANGE(COUNT(A2[!0])), NUMTO(item)))
```

四件套逐字语义：
- `COUNT(A2[!0])`：`[!0]` = 取该格全部扩展值（与 §15 交叉表占比同一套层次坐标）；`RANGE(n)` → `[1..n]`；
- `MAPARRAY(array, fn)`：逐项转换，**`item` 是隐式循环变量**（不是单元格、不加引号，脚本拼公式时最易误替换成 `A2`）；
- `INARRAY(值, 数组)`：返回 **1-based** 位置、**未命中返回 0** → 强制加兜底 `if(INARRAY(...)=0, 9999, INARRAY(...))`；
- 硬前提：仅当目标序列**从 1 开始且连续**时成立（跳号/从二开始 → 恒 0 → 全部堆第一行，不报错）。

**公式书写铁律**：同一条公式里 `$$$`（被排序格自身）与具名格 `A2`（`COUNT(A2[!0])` 取扩展格数）**并存且分工不同，不可互换**——把 `$$$` 写成 `A2` 则排序依据取错格，把 `COUNT(A2[!0])` 写成 `COUNT($$$[!0])` 则数组长度取错，两种写反都不报错。另外 `NUMTO` 不支持小数、N≥11 形态（十一 vs 一十一）需实测。

> 参考 `practice/topic_3717/gen_cnnum_sort.py`；`MAPARRAY/RANGE/INARRAY/item` 这组数组函数是 kit 排序知识里首个成体系落点。

### 7.7 空值排序与取负写法（doc-4195/doc-4289）

> 来源: 帆软官方帮助 doc-4195（超级链接）/ doc-4289（扩展后排序）

- **空值不参与排序变体**：扩展后排序公式对空值分支赋哨兵值——升序 `max(value('ds1',N))+1`、降序 `-(min(value('ds1',N))-1)`，把空值推出真实数据区间（排到末尾），非空值正常排序；需配合一个被超链翻转的模板参数（如 `$a`）做升/降序分支（见 doc-4289 逐字公式）。
- ⚠️ **`-B2` 直接取负会报错**，翻转方向必须写成 `-1*B2`（doc-4289 明确记录）——生成器若照普通表达式拼 `-格` 会直接编译/预览报错。

### 7.8 多列先后排序 = 位权复合键（doc-2528）

> 来源: 帆软官方帮助 doc-2528（扩展后排序-多列排序）

「先按 A 再按 B」不是两次排序、是**一次编码**。doc 原式逐字：

```
=INARRAY(B2,SORTARRAY(UNIQUEARRAY(B2[!0])))*POWER(10, LEN(MAX(E2[!0])))+E2
```

- 通式：`composite = 主键名次*10^(次键位宽) + 次键值`；N 列推广规则：中间列乘幂 = 其后所有列位宽之和，N 列产出 N-1 个乘幂。
- **两条 doc 未提但已数值验证的静默失效条件**：
  - **(a) 负数击穿位权**：`POWER(10,LEN(MAX(...)))` 只保证上界不保证下界，已验反例 `[('张三',10),('李四',-900)]` → 复合键 `110/-700`，李四被排到张三前；修法 `(E2-MIN(E2[!0]))` 平移或该列下沉 SQL（负值在利润/同比/库存差额类字段极常见）。
  - **(b) 精度预算**：复合键是 IEEE754 double，已验 19 位相邻值折叠为同一浮点（15/16 位未折叠），真实阈值约 17 位，超限表现为静默丢低位 = 最次要排序列失效；生成器取 **15 位保守红线**。
- 数值验证脚本已固化在 `practice/topic_2528/gen_multikey_sort.py`（35/35 自检用例），可直接搬为 kit 校验规则。

### 7.9 数组函数族：UNIQUEARRAY / SORTARRAY / INARRAY（doc-2528）

> 来源: 帆软官方帮助 doc-2528（数组函数）

`UNIQUEARRAY / SORTARRAY / INARRAY` + 层次坐标 `[!0]` 的组合语义：三连即模板层的 **`DENSE_RANK()`**（文本 → 名次，使文本可参与算术），建议抽为 kit 工具函数 `build_rank_expr(cell)`，复用于排序、分档、序号列等所有「文本参与算术」场景。

- **前置条件**：依据格必须真的会扩展，否则 `[!0]` 只取到单值、名次恒为 1、该列排序静默失效。
- ⚠️ `COUNT(UNIQUEARRAY(...))`（文本降序取补用）为本实践推导写法、doc 原文未见，需实跑确认 COUNT 接受数组入参——登记进待核验清单。

### 7.10 多级编号排序键公式生成器（doc-4624）

> 来源: 帆软官方帮助 doc-4624（多级编号排序）

收录一个**参数化**的多级编号排序键公式模板而非常量字符串：

```
=SUM(MAPARRAY(split(<Cell>, "\."), item * POWER(<radix>, <levels+1> - index)))
```

- 生成期断言：① `<levels+1>` 里的 levels 必须 = 实际最大级数（写小了超出的级得到 `POWER(r,≤0)` 变小数权重，靠 double 精度撑着）；② **每级数值必须 < radix**，否则进位串到上一级、排序静默错乱（如 radix=100 时 `1.150.2`）。
- `MAPARRAY` 的实现类 `com.fr.function.MAPARRAY` **extends `com.fr.function.LambdaFunction`**（fine-core 实读）——`item`/`index` 是解析器注入的 lambda 隐式变量，**没有任何 Java 构建 API**，Java 侧只能拼字符串。
- 适用面不止项目符号：版本号、章节号、WBS 编码同理。与 doc-2663 已提出的原则同源：「含结构依赖参数的载荷必须由代码生成、不得作为常量收录」（那次是 JS、这次是公式）。

### 7.11 数组状态参数范式（每扩展块一份状态，doc-2487）

> 来源: 帆软官方帮助 doc-2487（数组状态参数）

doc-2487 的四步公式是**通用范式**而非排序个案：反序列化 `SPLIT($a,",")` → 定位 `&A1`（当前扩展块的 **1-based 序号**）→ 改一格 `REMOVEARRAY(arr,&A1,1)` + `ADD2ARRAY(arr,新值,&A1)`（FR **无按下标赋值**）→ 序列化 `JOINARRAY(arr,",")`（动态参数只收标量）。

- **初始化 `RANGE(COUNT(A1[!0]))*0`**：`0` 为中性档（键全相等→保持原序）——这是「互不干扰」的实现机制本身。
- ⚠️ **`INDEXOFARRAY(arr,n)` 在 FR 里是「取第 n 个元素」而非「求下标」**（反直觉语义，改错后 FR 完全不报错、只是效果不对）。
- 可复用：分组内展开/折叠、分组内切换指标、分组内高亮等一切「每扩展块一份状态」的交互。三处易错点（`*0` 中性档、`&A1` 定位、INDEXOFARRAY 语义）改错后靠调试极难定位。

## 8. 单元格高级排序公式（doc-1894，排序交给公式而非 SQL ORDER BY）

> 来源: 帆软官方帮助 doc-1894（JS实现决策报表中点击标题排序）

> 与 §7 扩展后排序的区别：OrderFormula 在**扩展前/单元格层**排序，`$$$` = 当前扩展值；扩展后排序在**扩展完成后**重排所有格子（最慢）。决策树：简单排序 → SQL；运行期切方向 → 二选一（重查用数据集 `${a}`，不重查用单元格公式）。

- 基本式：`if($a==1, $$$, -$$$)`（乘 -1 即降序）；多列按 flag 分支选列：`if($flag=1, if($a=1, A3, -A3), if($b=1, D3, -D3))`。
- **类型转换铁律**：字符串型数字必须 `TOINTEGER($$$)` 再排，日期用 `tointeger(format(单元格, "yyyyMMddHHmmss"))`，否则按字典序排错（也可 SQL 侧直接产数值辅助列绕开）。
- 标题格挂「JavaScript 超链接」翻转参数触发重算：.cpt 普通报表 `_g().parameterCommit()`；.frm 决策报表 `var re=_g().getWidgetByName("report0"); re.gotoPage(1, {a:a}, "lazy")`（第三参 `"lazy"` 只重算单块，`true` 重算全部→大模板性能差）。
- ⚠️ 多列「只有第一次点击生效」坑：参数 `a` 只取到第一次值；解决 = JS 改用 `var a="${a}"; a = a=="1"?0:1;` 读模板参数原值字符串翻转，而非依赖超链接参数表达式。
- 逻辑 100% 落 XML（参数 `<Parameter>` + 单元格 `<OrderFormula>` + 标题 `<Hyperlink><JavaScript>`），无需 GUI。

> 参考 `practice/topic_1894/gen_sort.py`。
