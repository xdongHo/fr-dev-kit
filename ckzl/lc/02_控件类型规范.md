## 18. 年/日期控件类型规范（Ver0.3 新增）

### 18.0 面板方案选择（Ver0.5 新增）
| 方案 | 结构 | 适用 |
|------|------|------|
| **水印式（默认）** | 无 Label 控件，`watermark` 作提示；纯 ComboCheckBox/YearControl 均布网格（180×26、组间 20px、行距 8px） | 新开发一律默认（级联筛选面板：示例映射A、示例明细表B等） |
| **Label 式（分支）** | Label + 输入控件配对（Label→5px、跨行 Label 列对齐） | 仅改造存量 Label 模板 |

> 完整参数见 `kfgj/tygs/CPT模板/默认格式/2.参数面板控件布局/LAYOUT_SPEC.md`（Ver0.5）。
> 水印式示例：ComboCheckBox 用 `<watermark><![CDATA[提示文字]]></watermark>`，不创建 Label 控件。
> 📌 **水印等价说明（doc-1199）**：设计期 `<watermark><![CDATA[...]]></watermark>` 节点 == 官方 JS `widget.setWaterMark('...')`（在 afterinit 事件里调用）；headless 生成应**直接写 `<watermark>` 节点**，不要为「加输入提示」去注入 afterinit JS 事件。Java API 入口：`com.fr.form.ui.Widget.setWaterMark(String)`。
> 来源: 帆软官方帮助 doc-1199

### 18.1 控件选择
| 筛选类型 | 使用控件 | 类名 |
|---------|---------|------|
| **年份选择** | YearControl | `com.fr.plugin.widget.year.YearControl` |
| **日期/月份选择** | DateEditor | `com.fr.form.ui.DateEditor` |
| **其他下拉** | ComboCheckBox | `com.fr.form.ui.ComboCheckBox` |
| **平铺多选** | 复选按钮组 | `com.fr.form.ui.CheckBoxGroup` |

> 📌 **复选按钮组（doc-1086，doc-3839 字节码实读）**：`com.fr.form.ui.CheckBoxGroup`（extends `ButtonGroup`，fine-report-engine-10.0.jar）——与 ComboCheckBox 区分：**ComboCheckBox=下拉勾选，CheckBoxGroup=平铺按钮**。无头生成多选控件时若误建成 ComboCheckBox，控件形态不符预期且无报错。「支持全选」开关 = `CheckBoxGroup#setChooseAll(boolean)` ↔ XML `<chooseAll>true/false</chooseAll>`。
> 来源: 帆软官方帮助 doc-1086 / doc-3839

### 18.2 YearControl XML 模板
```xml
<InnerWidget class="com.fr.plugin.widget.year.YearControl" 
             pluginID="com.fr.plugin.widget.year.all" 
             plugin-version="3.2.6.6">
  <WidgetName name="para_year"/>
  <WidgetID widgetID="..."/>
  <WidgetAttr aspectRatioLocked="false" ...>
    <MobileBookMark .../>
    <PrivilegeControl/>
  </WidgetAttr>
  <YearAttr/>
  <!-- 默认值必须用公式 =year(now())，不要写死静态年份（如 2026） -->
  <widgetValue>
    <O t="XMLable" class="com.fr.base.Formula">
      <Attributes><![CDATA[=year(now())]]></Attributes>
    </O>
  </widgetValue>
</InnerWidget>
```

> ⚠️ **默认值铁律**：YearControl 的 `widgetValue` 必须用 `=year(now())` 公式（每年自动跟随当前年份）；写死 `2026` 这类静态值会导致报表跨年失效。若控件有级联依赖（如 示例模块 的 para_data_year 被 12 个下拉数据集过滤），公式默认值不影响参数传递。

### 18.3 DateEditor XML 模板
```xml
<InnerWidget class="com.fr.form.ui.DateEditor">
  <WidgetName name="para_period"/>
  <WidgetAttr aspectRatioLocked="false" ...>
    <MobileBookMark .../>
    <PrivilegeControl/>
  </WidgetAttr>
  <DateAttr format="yyyy-MM-dd"/>
  <widgetValue/>
</InnerWidget>
```

> ⚠️ **移动端日历插件边界（doc-3045）**：参数面板内的 DateEditor **不受**「日期移动端日历样式插件」影响——该插件只对决策报表 .frm body 内的日期控件生效；移动端参数面板日期美化走 `06_Web呈现层.md §22.5` CSS 注入（详见 §18.6）。
> 来源: 帆软官方帮助 doc-3045

### 18.4 转换规则
将 ComboCheckBox 转换为 YearControl/DateEditor 时：
- 保留: `WidgetName`, `WidgetID`, `WidgetAttr`, `widgetValue`
- 删除: `LabelName`, `watermark`, `Dictionary`, `RAAttr`, `ReturnValues`, `Listener`
- 新增: `YearAttr` 或 `DateAttr format="yyyy-MM-dd"`
- **排除列选择器**: `para_col_py`/`para_col_cy` 等列对比控件保留为 ComboCheckBox

### 18.5 常用参数组合开关（Ver0.6 实测，2026-08-05）

「常用参数组合」由**两处 XML** 控制（必须都 false 才是真正取消）：

| 位置 | XML | 对应 Java API |
|------|-----|--------------|
| 参数面板 Layout 内 | `<UseParamsTemplate use="false"/>` | `com.fr.form.ui.container.WParameterLayout.setUseParamsTemplate(false)` / `isUseParamsTemplate()`（反射实测，Designer JVM） |
| 报表参数属性 | `<ReportParameterAttr><Attributes ... useParamsTemplate="false" .../>` | `com.fr.main.parameter.ReportParameterAttr`（设计器保存时自动补全，缺省即 false） |

> 用户操作路径（fr-agent 追踪实测）：参数面板标签页 `MutilTempalteTabPane` → 弹出 `JDialog`（OptionPane 确认）→ 确定 → 保存，设计器重写文件并补全属性版开关。
> 批量脚本：`kfgj/tygs/.../2.参数面板控件布局/cancel_params_template.py`（双开关处理）。

### 18.6 移动端样式插件作用范围（doc-3260 / doc-3045 / doc-3195 / doc-3643）

移动端样式插件结论同构：**表单 body 内控件可覆盖 / 参数面板控件不可覆盖**——参数面板的移动端美化统一走 `06_Web呈现层.md §22.5` 的 CSS 注入路线（param_panel_style.py），与插件是两条正交路线，不可互相替代。

| 插件 | 覆盖 | 不覆盖 | 作用层 | 额外前提 |
|------|------|--------|--------|----------|
| 「移动端简约下拉样式插件」（doc-3260） | 表单 body 内的 ComboBox/ComboCheckBox | 参数面板下拉框、填报 CPT 下拉框、视图树、与顶部参数面板插件组合 | 控件壳 | body 内 |
| 「日期移动端日历样式插件」（doc-3045） | 决策报表 .frm body 内的日期控件（DateEditor） | 参数面板内的 DateEditor（文档明确「不支持参数面板」） | **弹出的日历面板** | .frm body 内 |
| 「移动端简约日历样式插件」（doc-3195） | 决策报表 .frm body 内的日期控件 | 参数面板内的 DateEditor | 控件壳 | body 内 且必须是「手机端专属决策报表模板」 |

> ⚠️ 同一个 DateEditor 可被 3045 与 3195 两个插件从两层分别改造（一个改面板、一个改控件壳），**二者不互斥也不互替**——用户说要改移动端日历样式，先分清要改哪一层再选插件，选错后控件位置全对、没有任何报错，只是改的不是想要的那一层；3195 独有的「手机端专属模板」前提恰是照抄 3045 结论会被漏掉的点。

**「是否写模板」分类（doc-3643）**：doc-3260 简约下拉 / doc-3045 日历样式 = **纯样式、不写模板**（卸载后 .cpt 无任何变化，与 headless 生成无关）；「移动端折叠展开树插件」（doc-3643，作用范围：普通报表单元格 + 决策报表报表块单元格）则**往 `<C>` 里写属性**——卸载后模板残留无人认领的节点，且该节点是模板功能的一部分不是装饰，**必须参与 .cpt 生成与校验**。

> ⚠️ headless 生成时指望该插件美化参数面板 = 静默无效果；参数面板下拉/日期移动端美化应改走 CSS 注入。
> 来源: 帆软官方帮助 doc-3260 / doc-3045 / doc-3195 / doc-3643

### 18.7 简约样式属性模型（跨控件复用，doc-3195 / doc-3260）

帆软的「简约XX样式」是一套**跨控件类型复用的统一外观模型**，而非每控件一套——把 doc-3260 与 doc-3195 逐项相同的属性收敛成**一个可复用 spec**（新插件只需登记「作用于哪个控件类」，校验规则零成本复用）：

- 组件背景 / 控件样式（标准、自定义，默认自定义）/ 标签名称（可空）+ 字符字号颜色粗斜 / 控件值 + 字符字号颜色粗斜 / 图标（**16*16 ~ 68*68，PNG、JPG**）/ 控件背景 / 控件边框线型 / 边框颜色 / 圆角 / 宽度（横向撑满 | 自定义，默认撑满，自定义须给数值）。

三条静态校验：图标尺寸格式、宽度模式与数值成对、「配了标签字体但标签名称为空」。

> 来源: 帆软官方帮助 doc-3195 / doc-3260

### 18.8 日期控件 DateEditor 属性级清单（doc-259，原文 doc-258）

日期控件是查询类报表出现频率最高的控件，属性面板 30+ 项里除「星期切换」外全部可 API 化。设置项 ↔ Java ↔ XML 三列全表见 `practice/topic_258_java/README.md`，要点沉淀：

- `com.fr.form.ui.DateEditor`（`getXType()="datetime"`），四层继承链的 setter 分布；
- XML：`<DateAttr [format][start][startdatefm][end][enddatefm] returnDate>`；
- **填报控件与参数控件是同一个类，只是挂载点不同**：`TemplateCellElement#setWidget`（填报） vs `WParameterLayout#addWidget` + `setBounds` + `FormParameterUI`（参数面板）；
- 三条生成期断言：① start/end 必须 `MM/dd/yyyy`；② `widgetValue` 与起止日期**互斥**（有默认值时范围静默失效）；③ 事件名只能取 `supportedEvents()` 实读的 `{afterinit, afteredit, stopedit}`。

> 来源: 帆软官方帮助 doc-259（原文 doc-258）

## 19. 标签宽度自适应（Ver0.3 新增）

### 19.1 宽度估算公式
```python
def calc_label_width(text):
    """根据文本估算 Label 宽度"""
    if not text: return 40
    w = 8  # 左右 padding
    for ch in text:
        if '\u4e00' <= ch <= '\u9fff':  # 中文
            w += 10
        else:  # ASCII/数字/符号
            w += 6
    return max(w, 40)
```

### 19.2 标签文本提取
从 `widgetValue` 的 CDATA 中提取：
```xml
<widgetValue>
  <O><![CDATA[Year:]]></O>
</widgetValue>
```

### 19.3 标签定位
Label 始终贴在关联控件的左侧：
```
label_x = control_x - label_width - 4
```
