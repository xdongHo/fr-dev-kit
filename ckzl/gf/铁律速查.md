# 全局铁律速查

## 全局铁律（所有任务通用，必须遵守）

> 这些规则在**任何阶段**都适用，违反任何一条都可能导致模板损坏或功能异常。
> 规则的详细解释和背景在对应分支 README 中。
> 铁律分两档：**A-K 为核心档**（每个任务都可能命中）；**L-AH 为专项档**（按主题命中，来源 2026-08 官方文档深挖 + 2026-09 R65 情报 + 2026-09 夜间批次 波实战）。

### A. 文件操作安全

| 规则 | 说明 |
|------|------|
| **修改前必备份** | 每次修改 .cpt 前创建 `_backup_YYYYMMDD_HHMMSS/` 备份目录 |
| **修改后必验证 XML** | `python -c "import xml.etree.ElementTree as ET; ET.parse('file.cpt')"` |
| **>2 次修复失败必还原** | 正则修复会累积损坏，超过 2 次失败立即从备份恢复，不要第三次尝试 |
| **Java DOM Transformer 禁用** | `javax.xml.transform.Transformer` 会破坏 FR XML（属性重排、CDATA 损坏）→ 只用 Python 正则 |
| **更新指南前必备份** | 复制到 `FR_HEADLESS_GUIDE_Ver历史备份/<日期>/` 再修改 |

### D. 级联参数 SQL

```sql
SELECT DISTINCT region AS 实际值, region AS 显示值
FROM table
WHERE 1=1 ${if(len(para_bu)==0,"","and bu in ('"+para_bu+"')")}
ORDER BY 1
```

- WHERE 1=1 + FR 公式（不支持 `WHERE bu IN ('${para_bu}')`）
- **ORDER BY 必须在所有 `${if()}` 之后**
- SQL 必须多行格式化（SELECT/DISTINCT/FROM/WHERE/ORDER BY 各占一行）
- **写完 SQL 必须在 FR Designer SQL 编辑器中格式化/预览一次**，否则级联参数绑定不生效

### F. 参数面板布局

| 规则 | 值 |
|------|-----|
| 控件尺寸 | 180×26（ComboCheckBox/DateEditor/TextEditor） |
| 按钮 | 80×26（Import 120×26） |
| Label→控件 | 5px |
| 控件组间 | 20px |
| 按钮间 | 40px |
| 面板内边距 | 12px |
| ≤1500px | 单行排列 |
| >1500px | 分多行（~1300px/行） |

**方案选择（默认 → 分支）**：

| 方案 | 结构 | 适用 |
|------|------|------|
| **水印式（默认方案）** | 无 Label 控件，`watermark` 作提示，纯 ComboCheckBox/YearControl 均布网格（180×26、组间 20px） | **级联筛选面板**（示例映射A、示例明细表B等大多数场景） |
| **Label 式（逻辑分支）** | Label + 输入控件配对（Label→5px、跨行 Label 列对齐、Label>180px 放顶部） | 需显式标签的历史模板/复杂布局 |

> 新开发一律走水印式；仅改造存量 Label 模板时用 Label 分支（`kfgj/tygs/CPT模板/默认格式/2.参数面板控件布局/LAYOUT_SPEC.md` 含两种方案的完整参数）。

**一键格式化参数面板**（生成/修改报表后必做；脚本目录 `kfgj/tygs/CPT模板/默认格式/2.参数面板控件布局/`，所有脚本均自动备份 `_backup_YYYYMMDD_HHMMSS/`，修改后必须验 XML）：

| 场景 | 命令 |
|------|------|
| **坐标级安全格式化（推荐）** | `python fmt_panel_safe.py <cpt> [--mode watermark\|label]`（只改 BoundsAttr 数值，不碰结构/CDATA/JS，改前后 XML 校验+幂等自检） |
| 全目录批量 | `python batch_optimize_cpt.py`（项目报表目录下全部 .cpt：控件尺寸/间距/列对齐/按钮排序/字体/行高） |
| 指定文件全套 | `python run_all.py <cpt路径> [cpt路径...]` |
| 单模板精排 | `python widen_all.py <cpt路径>`（自动识别控件，按宽度约束分行 + 跨行列对齐） |
| FR Java API 版 | `ckzl/frapi/doc/参数面板格式化器/ParamPanelFormatter.java`（引擎语义；⚠ 需 web 会话环境，见其 README） |
| 单项修复 | `add_query_btn.py` / `add_export_btn.py` / `fix_styles.py` / `fix_row_heights.py` / `set_write_no_toolbar.py` 等 |

⚠️ **踩坑（示例实际表.cpt 实测 2026-08-05）**：`batch_optimize_cpt.py` 内 `fix_parameter_controls` 的单行宽度阈值 1200px，会把原本整齐的多列网格拆成 4/4/4/4/2 犬牙交错，且部分 Label 宽度不按文字重算（仍卡 40px）。**对已手工精排 / 多列网格布局的报表慎用全量脚本**，优先 `run_all.py`/`widen_all.py` 定向处理，或对照 `kfgj/tygs/CPT模板/默认格式/2.参数面板控件布局/LAYOUT_SPEC.md` 手工精准修复；任何方式修改后都必须验 XML。

⚠️ **适用边界**：以上脚本均围绕「Label + 输入控件」配对布局（Label 类名含 `Label`，脚本按 y/x 排序后与下一控件配对）。**无 Label 的纯 ComboCheckBox 级联面板（如 示例映射A、示例明细表B的 13 控件筛选面板，水印当提示）不在脚本处理范围**——`widen_all.py` 会报「无控件对」直接返回。此类面板手工按 F 段规格数值排布即可（控件 180×26、组间 20px、内边距 12px、按钮右对齐）。

### K. FR Java API 能力（2026-08-07 实测更新）

> **核心原则**：模板生成**优先使用 FR Java API**（通过 fr-agent `/exec` Nashorn 注入 Designer JVM 执行）。Java API 生成模板格式标准、类型安全、Designer 可正常编辑。

| 规则 | 说明 |
|------|------|
| `TemplateWorkBookIO.writeTemplateWorkBook(wb, path)` | ✅ **可写入**（fr-agent /exec 注入后）；path 为 reportlets 相对路径 |
| `TemplateWorkBookIO.readTemplateWorkBook(path)` | ❌ 磁盘读依赖 web 会话环境（ReadError）；改读用 Designer 内存对象或 Python |
| `Form.export(OutputStream)` | ✅ **可写入 .frm**（fr-agent /exec 注入后）；绝对路径 |
| `ConnectionConfig.getInstance()` | ✅ **可用**（fr-agent /exec 注入后，在 Designer JVM 内执行）；⚠️ 独立 JVM 外不可用（触发 License 验证） |
| `FRFont.getInstance()` / `Style.getInstance()` | ✅ 工厂方法可用（注入后） |
| `new WorkBook()` / `addCellElement()` / `setStyle()` | ✅ Nashorn 在 Designer JVM 内可调用 |
| fr-agent /exec 运行通道 | `python fr-agent\inject.py` 注入 → `python fr_exec.py <js>` 执行 Nashorn 脚本 |
| 独立 Java（非注入） | ❌ 不在 Designer JVM 内则 License/环境不可用；export 时报 `ClassNotFound` / `ClassNotFoundException: com.fr.license.selector.LicenseContext` 即此场景——**可忽略，文件正常生成**（详见 ckzl/lc/01_环境与工具链.md 导出节、ckzl/zsk/tbcw/README.md 索引行） |
| GUI 操作追踪 | 只能动态注入 Agent（`VirtualMachine.attach()`），`-javaagent` 会崩溃 License |
### L. 排序与父子格（扩展）

| 规则 | 说明 |
|------|------|
| **排序公式与左父格是耦合配置** | 不可分开生成；排序公式引用的格若不是被排序格的子孙格，FR 不报错但排序结果不可预期（一个分组对应多个/零个汇总值） |
| **排序先挂左父格** | 必须先挂左父格再设排序公式；汇总逐层上卷 `D4=SUM(D3)` 而非 `SUM(D2)` |
| **合并单元格须被冻结范围整体覆盖** | 冻结区含 `rowSpan/colSpan>1` 的合并单元格时，`columnrow` 必须到达合并单元格的完整边界，否则冻结错位 |


### M. 移动端与引擎互斥

| 规则 | 说明 |
|------|------|
| **行式引擎 ⊥ 移动端** | 启用「用行式引擎执行 + 按页运算分段执行」的模板不支持 App/H5；大数据量层式报表与移动端交付不可兼得，须在需求分析阶段分流 |
| **预览 URL 只用于本机验证** | 对外分发前必须换 IP——`http://localhost:8075/...` 只在本机有效，交付文档/联调时必须替换为服务器地址 |

> 来源：帆软官方帮助 doc-996 / doc-1387。

### N. 联动与图表 JS

| 规则 | 说明 |
|------|------|
| **跨块联动须显式刷新** | 图表↔报表块联动刷新不可依赖 FR 自动追踪，必须由 `getChart().dataRefresh()` 显式触发，且 `name` 必须与模板图表块名严格一致 |

> 来源：帆软官方帮助 doc-1457 / doc-2332。

| 规则 | 说明 |

> 来源：帆软官方帮助 doc-786 / doc-3342。

### P. 定时调度生成

| 规则 | 说明 |
|------|------|
| **调度模板参数必给默认值** | 凡计划挂定时调度的模板，每个模板参数必须给默认值（日期类用 `=format(today(),"yyyy-MM-dd")`），否则调度静默取不到值 |
| **per-user 分发注入层级要区分** | 数据集 SQL 级用 `${fine_username}`；标题/页眉级用 `$fine_username`（两处注入层级不同，作用域不同） |
| **调度对象建议注入统计日期参数** | 让结果报表顶部「使用的参数值」非空，便于产物识别；短信通知类结果建议注入 `$fine_username` 引用 |
| **调度结果单元格在默认 sheet** | 公式判断只取默认 sheet 单元格，不得跨 sheet 引用；被公式判断引用裸写 `A2`，被文件名称/通知引用须 `${A2}` |

> 来源：帆软官方帮助 doc-2208 / doc-695 / doc-2209 / doc-2210 / doc-3315。

### Q. 权限

| 规则 | 说明 |
|------|------|
| **权限锚点空标签不可省略** | `<C>` 下的 `<PrivilegeControl/>`、`<WidgetAttr>` 下的 `<PrivilegeControl/>`、`<Report>` 下的权限节点：无权限限制时是空标签，不能省略，省略=未声明 |
| **系统参数大小写敏感** | `$fine_username`/`$fine_display_name`/`$fine_role`/`$fine_position` 必须小写；大小写错误静默失效 |
| **JAR 升级前先补权限** | 工程 JAR 从 < 2022-08-03 升到 >= 2022-08-03 时，必须**先**为自动化账号补齐所有被引用数据连接的「使用」权限，再升级 |

> 来源：帆软官方帮助 doc-866 / doc-865 / doc-4152。

### R. XML 生成卫生

| 规则 | 说明 |
|------|------|
| **注释禁连续两个减号** | XML 规范禁止注释内出现 `--`；分隔线用 `—` 或 `→`，选项名不能写成 `--xxx` |
| **超链参数名 = JS 变量名** | JS 超链 `<Parameter name=X>` 的 X 会被 FR 注入为 JS 作用域裸变量，必须是合法 ASCII 标识符 |
| **写 JS 禁用 python str.format** | 生成含 `${servletURL}` 等 FR 占位符的 `<Content>`/`<Listener>`/CSS 时，禁用 `str.format()`/`%` 格式化（花括号冲突），用字符串拼接或模板替换 |
| **CDATA 两面都要防** | `<Content>` 必须 CDATA 或 XML 转义；同时内容中不得出现 `]]>`，外链 URL 查询串里的 `&` 必须转义 |
| **.cpt 注释不得含连续减号** | 往 .cpt/XML 写注释时同样适用（含 JS 块内 `-->` 箭头） |

> 来源：帆软官方帮助 doc-4418 / doc-3556 / doc-4204 / doc-1839 / doc-1672。

### S. 引擎与格式边界

| 规则 | 说明 |
|------|------|
| **无头只产出 .cpt** | headless 生成只产出 .cpt（旧引擎）；需要新引擎性能优化须用设计器「批量格式转换」插件，转换产物 .cptx 落在源 .cpt 旁 |
| **op=write 与 write_plus 特性不同** | write_plus 不可用但 op=write 可用的特性：悬浮元素 / 列表控件 / 树节点展开折叠 / 单元格内文本控件样式 / 自定义提交按钮等；拼 URL 时按特性清单选择 |

> 来源：帆软官方帮助 doc-3550 / doc-2194。

### T. 数据连接与 HTML

| 规则 | 说明 |
|------|------|
| **数据连接名契约** | .cpt 数据集只存 `<Database name="X"/>` 连接名、不存 JDBC 详情；连接是否存在取决于目标工程，交付时须附连接清单 |
| **邮件正文 HTML 白名单** | 邮件正文 HTML 仅支持白名单标签（a/b/br/table/img...），须用 table 布局 + 行内样式，不能用外链 CSS/script |
| **引用全局参数=非自包含** | 引用了工程全局参数的 .cpt 不得单独交付；交付物必须含全局参数清单（名称+默认值），部署脚本须在目标工程预置 |

> 来源：帆软官方帮助 doc-299 / doc-684 / doc-159。

### U. JS 生成卫生（前端交互 JS）

| 规则 | 说明 |
|------|------|
| **JS 常量不得硬编码** | 能由模板结构推导的常量（折叠树层数 t=父格链层数+1、扩展列数、sheet 索引、控件名）一律由生成器计算后拼入；官方示例的魔法值（选择器 `#r-0-0`、表 id `'0'`、行号偏移 `-2`）必须先参数化并与构建代码同源（doc-2369/1213/2305） |
| **setInterval 必须可取消** | `if(window.K){clearInterval(window.K);} window.K = setInterval(...)`（K 由控件名派生），禁止匿名 setInterval——body/参数面板二次初始化会叠加定时器（doc-1457/2005） |
| **JS 宿主前缀** | 参数面板内控件取兄弟控件用 `this.options.form.getWidgetByName(name)`；报表主体/决策报表组件用 `_g().getWidgetByName(name)`；按挂载位置选前缀，混用静默拿不到控件（doc-2938/1197） |
| **前端全局对象可用性** | `_g()` / `window.contentPane` / `FR.*` 只在带报表预览容器的页面生效（如 op=write 填报预览）；生成依赖它们的按钮 JS 必须同时确认预览方式（doc-1071） |
| **JS 注入四规则** | ①定时器/状态变量名带控件名后缀（`window.interval_mq_report0`）②事件绑定用命名空间 `off('evt.ns').on('evt.ns', fn)` ③页面取来的值（DOM 文本/title/单元格值）拼进 FR 公式字符串前必须转义 `\` 与 `'` ④选择器按控件收敛（优先 `$(this.element).find(..)`）（doc-2393/4143） |
| **日期类 JS 安全模板** | 「取日期→算偏移→回填」四步：①判空（''/null/undefined 直接 return）②本地零点解析 `new Date(y, m-1, d)`（`new Date('2026-08-08')` 按 ES5 当 UTC 零点，负时区整体回退一天）③日历天加减 `d.setDate(d.getDate()+N)` 而非 `+N*24*60*60*1000` ④按控件格式显式回填字符串。禁止照抄官方 `new Date(this.getValue())` + 毫秒加法（doc-1206） |

### V. 日期与公式

| 规则 | 说明 |
|------|------|
| **日期只写公式，不写构建期常量** | 生成器写入 .cpt 的任何日期/时间值（参数默认值、报表标题、SQL 字面量、单元格初值）一律写 FR 公式对象（`=DATEDELTA(TODAY(),-1)`），不得在构建机用 `LocalDate.now()`/`datetime.now()` 算成字符串写死——构建期与运行期时区/时刻必然分叉，且每次重新生成结果都不同（doc-4068） |

| **XML 属性值走 FR 转义表** | `XMLUtils.xmlAttrEncode` 映射：`& < > ' "` + FR 私加的 `×→&#215;`、`÷→&#247;`（diff 比对时别当脏数据）；转义表**不含换行**，多行 JS/公式存进属性后换行变空格、含 `//` 行注释即报废→凡需把 JS/HTML/公式写进属性值，优先用 Java API 让 FR 自己 writeXML，手写路径禁用 `//` 注释（doc-3245） |
