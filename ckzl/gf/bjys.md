# 布局 / 样式 / 美化 统一规范（最终版）

> **定位**：FRM 驾驶舱 + CPT 报表的样式/布局/美化唯一权威规范。
> **原则**：开发前期专注功能（数据结构/绑定/参数/交互），样式在收尾阶段按本规范统一应用。
> **默认样式脚本**：`frm_apply_style`（FR Java API 一键格式化），除非用户提出调整，否则默认用它。

---

## 一、FRM 驾驶舱样式

### 1.1 画布与全局
- **绝对画布** `WAbsoluteBodyLayout`，**Form 默认大小 1280 × 720**（⚠ 覆盖早期 1920×1080）
- 画布背景 `#f5f5f5`
- **画布三处一致**（否则被撑大）：body Size / absBody Bounds / DesignResolution 三者一致
- **全局字体**：微软雅黑（Microsoft YaHei）；标题 12 号、正文 9 号
  - FRFont 换算：`size=72` → 12pt（标题）；`size=54` → 9pt（正文/图例/标签）

### 1.2 配色（定稿）
| 角色 | 色值 |
|---|---|
| 主强调 / 查询按钮 | `#3676C5` |
| KPI 销售额 | `#3a7ee8` |
| KPI EBIT | `#34c38f` |
| KPI 率 | `#8b6dd6` |
| KPI 项目数 | `#f3b042` |
| 系列 Act | `#3a7ee8` |
| 系列 分类值2 | `#34c38f` |
| 系列 分类值3 | `#f3b042` |

### 1.3 图表对象设置（所有图表统一）
- 取消勾选「标题可见」（不显示原生 Title4VanChart）
- 主题填充**纯白色**，透明度 **80%**
- 圆角 **5**，边框**细线**，组件内边距上下左右各 **5**

### 1.4 图表详细样式
| 项 | 定稿 |
|---|---|
| 图例 | 右侧（位置=2），微软雅黑 9 号 |
| 数据标签 | 仅勾选「值」，格式 `#,##0.00` |
| 系列 | 固定宽 30px / 分类间隔 20% / 圆角 5px |
| 坐标轴 | 隐藏轴标题；轴标签微软雅黑 9 号 |
| 数据表 | 不勾选「显示数据表」 |
| 网格线 | 横向**无**、纵向**无** |
| tooltip | 微软雅黑 9 号 |
| 特效工具栏 | 关闭「排序 / 导出图片 / 全屏显示」 |

### 1.5 图表标题块
- **结构**：图表上方留 **30** 距离，放 **26 高**的 ElementCaseEditor HTML 标题块；标题块尺寸 **220×26**（行高 `FU.valueOfPix(26,96)` 消滚动条）；图表有单独筛选时筛选控件放标题同行。
- **样式（定稿）**：`▎` 符号 + `#2563eb` 蓝色粗体 **18px** + 无底部边框线 + 行高 **44px**
  ```html
  <div style="display:flex;align-items:center;width:100%;height:100%;padding:0 8px;box-sizing:border-box;">
    <span style="font-size:18px;color:#2563eb;margin-right:8px;font-weight:bold;">▎</span>
    <span style="font-size:18px;font-weight:bold;color:#2563eb;font-family:微软雅黑,Microsoft YaHei;letter-spacing:1px;">OEM 维度分析</span>
  </div>
  ```

### 1.6 KPI 卡片
- **每个卡片独立 ElementCaseEditor**（不要多卡合并进一个组件）
- **多格布局**（3 行 × 2 列，便于 Designer 逐格调整）：
  - (0,0) 标签 9px 灰字｜(0,1) 空
  - (0,2) 数值 22px 粗体｜(1,1) 图标 36px 圆（右列 40px 居中）
  - (1,2) 副标题 9px 灰字
- **结构样式**：白底 + `border:1px solid #e8e8e8` + 圆角 5 + 左 3px 色条 + 圆形图标 + 内边距
- **数值**：用 `VALUE("ds_kpi",col,1)` 公式取真实数据动态拼接（不要写死）
- 组件高 90 → HTML 高 88（组件高-2 防滚动条）；行高/列宽用 `FU.valueOfPix(...,96)`
- 卡片色按 §1.2 配色表

### 1.7 画布布局
- **WGridLayout 栅格容器**：`com.fr.form.ui.container.WGridLayout`，`new WGridLayout(rows, cols, hgap, vgap)`，`addWidget(widget, row, col)` 自动等分布局（无 setDesigningResolution）
- **2×2 网格（虚拟 3×3）**：每容器第 1 行 30px 标题区、第 1/3 列 5px 留白、最后一行 5px 底部留白、**正式组件放第 2 行第 2 格**
- 容器宽 = (画布宽 − 外边距×2 − 中间间距) ÷ 2；容器高 = (画布高 − 顶部区 − 底部边距) ÷ 2

## 二、CPT 报表样式

### 2.1 参数面板布局（水印式默认）
| 项 | 定稿 |
|---|---|
| 方案 | **水印式（默认，无 Label）**；Label 式仅改存量模板 |
| 控件尺寸 | 180×26（YearControl 年份 100 宽） |
| 控件组间 / 区块间 | 20px |
| 行间距 | 10px（label-v 20px） |
| 面板内边距 | 12px |
| 单行阈值 | 每行宽 < 1500；总高 < 300 |
| 按钮宽 | `max(80, 中文×15 + 字母符号×8)` |
| 参数面板 | 只要查询按钮（FormSubmitButton）；导出按钮 formSubmit3 蓝 #3676C5 |

### 2.2 单元格样式标准值
| 项 | FR 值 |
|---|---|
| 边框颜色 | `-1841172`（#E1E1E1 浅灰） |
| 前景色（文字） | `-13421773`（#333333 深灰） |
| padding | `paddingLeft=4 paddingRight=4` |
| 文本列 | 显式 `<Format class="com.fr.base.TextFormat"/>` |
| 背景 | 白色 `ColorBackground color="-1"` |
| 表头 | 加粗 + size=80 + 白字 `-1` + 深蓝底 `-10773547` |
| 对齐 | `0`=居中、`1`=左对齐、`2`=右对齐（⚠ 反直觉，文本列用 1、数值列用 2） |

### 2.3 列宽 / 行高 / 冻结 / 隔行
- **列宽**：`FU = clamp(max(数据字段文本数×2.5mm, 表头文本数×5mm), 15mm, 150mm)`，超界回落 20mm；1mm≈144229 FU（存值必须实测 `max(length(col))`，勿拍脑袋）
- **冻结表头 + 隔行换色**：仅行展示明细表（Detail/Import）启用；树形折叠 Overview 不启用
- **隔行换色**：偶数行 `#f5f5f7`（FR 值 `-657929`，⚠ 不是 `-651769`），用 HighlightList + BackgroundHighlightAction（只改背景，不带 horizontal_alignment），且**必须放 HighlightList 第一位**
