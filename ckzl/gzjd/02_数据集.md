# NODE 02 数据集

> 本节点为ckzl/gzjd,自包含:判定题 → 知识点 → Java API → 常见错误 → 验证清单 → 路由。
> 详细展开见 ckzl/lc/ 对应章节(见导航文件 §四),本文件保持轻量。

## 判定题(先回答,再往下读)

- 用数据库数据集(SQL)还是内置数据集(Embedded)?
- SQL 是否需要级联参数(${if(len(...))} 语法)?
- 需要数据字典(下拉显示值/实际值)吗?
- 排序:SQL ORDER BY 能否解决?还是需要运行期排序?
- 数据连接:内置/平台?连接名是否正确?

## 核心知识点(工程向,标注 来源 doc-XXXX)

<!--KB:NODE02-K01-->
- **数据集参数唯一推荐写法**:`WHERE 1=1 ${if(len(p)==0,"","and 字段='"+p+"'")}`;禁裸 `WHERE col='${p}'`(空参静默退化为 `col=''` 返回空表,不报错)(来源 doc-158,详见 ckzl/lc/02 §8.4)
<!--KB:NODE02-K02-->
- **数据集参数「不与数据集绑定」**:多个数据集同名 `${para}` 共享工作簿里同一个参数,值以最后一次赋值/声明为准;需分别传值就改名(来源 doc-158,详见 ckzl/lc/02 §8.4)
<!--KB:NODE02-K03-->
- **参数优先级链(实读)**:`WorkBook#getParameters()` 合并顺序 = 全局参数(ParameterConfig) < 数据集参数(DataOperator) < 模板参数(attr),同一 HashMap 后写覆盖;**「默认值设了不生效」先查此链**(来源 doc-156;官方 doc-156 只写了全局 vs 模板,数据集段文档缺失)
<!--KB:NODE02-K04-->
- **参数为空选全部两条路**:①单元格过滤 `if(len($p)==0,nofilter,$p)`(展示层,不改 SQL)②SQL 层 `1=1 ${if(...)}`(下推前不过滤);二选一不要混用,`nofilter` 绝不能写进 SQL(来源 doc-2394,详见 ckzl/lc/02 §9.3)
<!--KB:NODE02-K05-->
- **模板参数 vs 数据集参数选型**:大数据量→数据集参数(SQL 层下推);小数据/前端二次过滤→模板参数+单元格过滤(来源 doc-157,详见 ckzl/lc/02 §9.1)
<!--KB:NODE02-K06-->
- **排序无专属 API**:排序=SQL 文本(ORDER BY),升/降/多列只是写法差异;运行期排序走单元格「扩展后排序」(来源 doc-903/doc-3622,详见 ckzl/lc/02 §11.2、ckzl/lc/03 §7)
<!--KB:NODE02-K07-->
- **分页 SQL/行式引擎**:分页 SQL 是数据集级属性(`setPaginationQuery`),`${fr_pagenumber}/${fr_pagesize}/${fr_rowcount}` 由引擎注入;查询 SQL 与分页 SQL 字段顺序必须一致(来源 doc-996,详见 ckzl/lc/02 §10)
<!--KB:NODE02-K08-->
- **树数据集(自动构建)**:`TableTreeData` 需 id/parentId/caption 三列且列名与源表字段一致,**根父键必须为空 '' 而非 0/NULL**(来源 doc-1042,详见 ckzl/lc/02 §1.6、ckzl/lc/04 §26)
<!--KB:NODE02-K09-->
- **图表「数据集数据」数据源**:选数据集后绑定分类/系列名(字段值=记录,字段名=列名)/值/汇总方式;Java 侧对应 `com.fr.chart.chartdata.*` 数据集数据定义类,映射需查 jar(来源 doc-176,详见 ckzl/lc/03 §9.3)
<!--KB:NODE02-K10-->
- **数据连接三连**:连接名契约(doc-299)、连接名可被管理员改名即断(doc-4153)、权限模型(doc-2457)——生成器把连接名收敛为顶部常量 CONN,防批量改名静默拖垮模板(来源 doc-299/doc-4153/doc-2457,详见 ckzl/lc/02 §13)
<!--KB:NODE02-K11-->
- **SQL 防注入的实际覆盖面**:`com.fr.data.impl.EscapeSqlHelper` 的唯一模板侧消费点是 `DBTableData#getStatementSql`,即**只拦「数据库查询」数据集的参数**;存储过程数据集、内置/文件数据集、`sql()` 公式都不经过——生成后两类内容时参数侧必须自带白名单/下拉约束(来源 doc-2219,详见 ckzl/lc/02 §8.6)
<!--KB:NODE02-K12-->
- **Compare 常量易混对**:`CONTAINS=10`(包含)vs `IN=12`(包含于)、`BEGINS_WITH=6` vs `ENDS_WITH=8`、`NULL=14` vs `NOT_NULL=15`(类在 fine-core jar);空值语义对照:`ListCondition` 空集求值**恒 true**(doc-4003)vs `CommonCondition` 的 IN 右值为空**恒假**(doc-576)——方向相反,排查「数据太多」与「数据为 0」要往两个相反方向找(来源 doc-2365/576,详见 ckzl/lc/02 §9.7)
<!--KB:NODE02-K13-->
- **参数命名硬约束三条**(doc-2637):①长度 ≤20 字符(`Hyperlink#putExtendParameters` pc80-88 超 20 直接跳过)②不得命中引擎保留字(viewlet/viewlets/op/reportlet/.../fine_username 等)③必须合法 JS 标识符 `[A-Za-z_$][A-Za-z0-9_$]*`(`createContentFunction` 原样拼进形参表零校验);违反统一现象=子表/目标报表 0 行、无异常无日志;全局参数**不参与超链继承**(`GlobalParamFilter` 逐个 remove),须在超链上显式声明(来源 doc-2637,详见 ckzl/lc/02 §12.3)

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- `com.fr.data.impl.DBTableData`: `setName`/`setDatabaseName`(→`<Database>`)/`setQuery`(SQL 内 `${area}` 原样序列化进 `<SQL>` 即声明数据集参数);经 `WorkBook.putTableData(DBTableData)` 挂到工作簿(来源 doc-158/doc-996,详见 ckzl/lc/02 §8.4)
- **分页**:`DBTableData.setPaginationQuery(String)` → `<PaginationQuery>`(设计器「分页查询」按钮内容即序列化于此);行式引擎开关是工作簿级引擎属性,各 10.0 小版本 setter 名不稳定,以所装 jar 为准(来源 doc-996,详见 ckzl/lc/02 §10)
- `com.fr.data.impl.EmbeddedTableData`: `setName`/`addColumn(String,Class)`(参数1=列名/参数2=列类型,添加顺序=最终列序;javap 实测 FR10 无 `addColumn(Object[])` 重载,亦无 `setColumnName(int,String)`,2026-09-12 fine-core-10.0 修正)/`addRow(List)`/`addColumnNameAndData(String[],List,String)`;真实 .cpt XML 落 `<ColumnNames>/<ColumnTypes>/<RowData>` 节点(官方 图表组件-折线.cpt 实测,非 `<columnData>/<columnName>`);`WorkBook.addTableData` 挂载,可被 `.select()` 引用(来源 doc-3622,详见 ckzl/lc/02 §1.4/§1.5、ckzl/lc/03 §7.4)
- **树数据集**:`com.fr.data.impl.TableTreeData`(实现 `com.fr.data.TreeTableData`):`setFromTableDataName`/`setIdColumnName`/`setParentIdColumnName`/`setCaptionColumnName`(来源 doc-1042,详见 ckzl/lc/02 §1.6)。⚠类名未经 jar 验证:FR10 服务端+设计器共 44 jar `which/find` 均 0 命中(2026-09-12 jar_class_probe 实测,同 V1 附录C),真实类名待 fr-agent 运行期确证前不得当事实用于生成
- **数据字典(控件联动)**:`com.fr.data.impl.TableDataDictionary`(setTableDataName 绑数据集)/`com.fr.data.impl.FormulaDictionary`(实际值/显示值两公式,如 `value("ds1","城市","地区",C9)`);联动由字典引用的单元格/参数运行时驱动,**无「联动 API」**,Java 侧只负责把控件+字典+数据集正确写入模板(来源 doc-608;与参数面板级联的机制区别详见 ckzl/lc/04 §20)
- **排序无专属 API**:构造数据库查询数据集 `DatabaseConnection/DBTableData.setQuery(含 ORDER BY 的 SQL)`;动态排序 `${a}` 需同名 `Parameter`(name 与占位符一致,value 默认 "asc")(来源 doc-903,详见 ckzl/lc/02 §11.2)

## 常见错误

<!--KB:NODE02-E01-->
- 裸 `WHERE col='${p}'`:空参静默变 `col=''` 返回空集,产「传空=空表」却不报错的模板,排查方向全跑偏(来源 doc-158)
<!--KB:NODE02-E02-->
- 分页 SQL 与查询 SQL 字段顺序不一致 → 导出与预览结果不一致(来源 doc-996)
<!--KB:NODE02-E03-->
- 树数据集根父键写 0/NULL → 构建失败/静默异常(根父键必须为空串)(来源 doc-1042)
<!--KB:NODE02-E04-->
- 同名参数默认值「设了不生效」:先查优先级链(全局<数据集<模板),再查是否被同名后写覆盖(来源 doc-156)
