## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- 模板导出属性三层链(Excel/Word/PDF 共用):`WorkBook.getExportAttr()/setExportAttr(ReportExportAttr)` → `ReportExportAttr.getExcelExportAttr()/setExcelExportAttr`、`getWordExportAttr/setWordExportAttr`、`setPDFExportAttr/getPDFExportAttr` → `ExcelExportAttr.setExportHiddenRow/setExportHiddenColumn/setOpenPassword/setWritePassword`(密码仅 xls 生效、不支持中文、多 sheet 一密码)、`WordExportAttr.setFixedRowHeight(false)`=不固定行高、`PDFExportAttr.setPassword(非空=需要密码)`。XML:`<ReportExportAttr>` 下 `<ExcelExportAttr exportHiddenRow="true" openPassword=".." writePassword=".."/>`、`<WordExportAttr fixedRowHeight="false"/>`、`<PDFExportAttr password=".."/>`。来源: doc-1118 / doc-1128 / doc-1141
- Word 页眉页脚与页边距:`ReportPageAttr.setTopMargin/setBottomMargin/setLeftMargin/setRightMargin`(上边距=12.7mm 对齐 Word 默认页眉距顶,解决导出后多空白行);`com.fr.io.exporter.WordExporter.export(OutputStream, Report)` 随模板导出页眉页脚;页眉页脚图片须用「背景元素>图片」否则撑出空白页。XML:`.cpt` `<ReportPageAttr>`。来源: doc-1130
- 导出文件名标题公式:`ReportWebAttr.setTitle("${Diqu+"_地区_"+Riqi}")` → `<ReportWebAttr>` title 属性,运行时按模板参数求值(参数须已注册);方法二 `__filename__` 是 servlet URL 参数非 API,与方法一互斥;setter 签名各小版本不稳定以 jar 为准;见 ckzl/lc/06 §11.6。来源: doc-1822
- 超链构造挂载(导出保留超链前置):`HyperlinkGroup.addHyperlink(Hyperlink)` → `TemplateCellElement.setHyperlinkGroup`;`ReportletHyperlink.setReportlet+setParameters`、`WebHyperlink.setURL+setTargetWindow`、`JavaScriptHyperlink.setScript+setParameters`;参数值用 `Formula` 包装($$$/A2);XML `<CellElement><HyperlinkGroup><Hyperlink class="com.fr.js.ReportletHyperlink">`;类名以 AGENTS 0.10 铁律为准(旧文档 NetworkReportLink 已证伪);装配见 ckzl/lc/06 §28。来源: doc-947 / doc-3321
- 单元格级预览/打印/导出开关:`com.fr.report.cell.CellGUIAttr` 经 `TemplateCellElement.setCellGUIAttr` 挂载,`setPageShowContent/setPrintCellContent/setExportCellContent/setPrintFillBackground/setExportFillBackground` 五个布尔开关;XML `<CellElement><CellGUIAttr>`;填报预览不支持,Word/Excel 仅颜色背景;见 ckzl/lc/03 §3.7。来源: doc-225
- 大数据/批量/单报表块导出无公开 Java API:均走前端 JS + servlet URL 参数(`format/extype/op=ec_export/__filename__`),无 com.fr.* 构建路径;`_g().directExportToExcel` 为前端接口,服务端 SXSSFWorkbook 属插件/引擎内部实现;导出执行侧 API 见 ckzl/lc/08 §17。来源: doc-2597 / doc-4518 / doc-4104 / doc-3233

## 常见错误

<!--KB:NODE07-E01-->
- `extype=sheet` 分 Sheet 导出在行式引擎开启后静默失效(来源: doc-3233)
<!--KB:NODE07-E02-->
- 导出密码只对 xls(Excel03)生效,默认 xlsx 导出密码不生效;密码不支持中文;多 sheet 只能设一个密码(来源: doc-1118)
<!--KB:NODE07-E03-->
- 部署到自带 PDF 加密 JAR 的项目 → bouncycastle 同名 JAR 冲突 SecurityException,须删项目自带 JAR(来源: doc-1141)
<!--KB:NODE07-E04-->
- 「保留公式」在分页/分页分 Sheet 导出下不生效;存在隐藏且参与计算的列时勾选也失效(来源: doc-1114)
<!--KB:NODE07-E05-->
- 未开行式引擎时大数据量导出超「临界点」→ 导出失败/内容无效;单 Excel 行数须为固定行数分页整数倍且 ≤65536(来源: doc-1120)
<!--KB:NODE07-E06-->
- 导出慢排查顺序:先分 sessionID 复用 vs 重新取数,再查驱动与图表环境(j2v8/nashorn)(来源: doc-4418)
<!--KB:NODE07-E07-->
- 导出文件名方法一(标题公式)与方法二(__filename__)同时配置 → 二选一,须先清除标题(来源: doc-1822)
<!--KB:NODE07-E08-->
- 定时调度「任务结束即清理」不产生附件;附件目录层级(schedule/任务/日期/时间/用户名)易被误解(来源: doc-683)
