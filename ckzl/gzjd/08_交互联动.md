## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- 超链挂单元格:`HyperlinkGroup.addHyperlink(Hyperlink)` → `TemplateCellElement.setHyperlinkGroup(HyperlinkGroup)`;`ReportletHyperlink.setReportlet+setParameters(Map<String,Formula>)`、`JavaScriptHyperlink.setScript+setParameters`、`WebHyperlink.setURL+setTargetWindow`;参数值统一 `com.fr.stable.script.formula.Formula` 包装;XML `<CellElement><HyperlinkGroup><Hyperlink class="com.fr.js.ReportletHyperlink">`(参数以 CDATA 公式写入);类名以 AGENTS 0.10 为准(旧文档 NetworkReportLink 已证伪);装配见 ckzl/lc/06 §28。来源: doc-947
- 动态参数超链类:`com.fr.write.extension.DynamicParamHyperlink`(XML `type="11"`),`setName(String)` + `setParameter(name,value)`(推断签名,用前 javap 核验 fine-write.jar);XML `<Hyperlink class="..DynamicParamHyperlink" type="11"><Parameters><Parameter name="a" value="ASC"/></Parameters><ParameterName>动态参数1-升序排序</ParameterName>`;真实类名另见 ckzl/lc/03 §11.6。来源: doc-4202
- Web 事件注入链:`AbstractTemplateWorkBook#setReportWebAttr(new ReportWebAttr())`(模板级必须 new 而非全局 getInstance);`WebPage/WebView/WebWrite extends WebContent extends Observer` → `addListener(new Listener(eventName, javaScriptImpl))`;XML `<Listener event="<事件名>" class="com.fr.form.event.Listener"><JavaScript class="com.fr.js.JavaScriptImpl"><![CDATA[...]]></JavaScript></Listener>`;骨架见 ckzl/lc/06 §11.4。来源: doc-1178
- Listener 重载语义铁律:两参 `new Listener(String eventName, JavaScript)` 用于模板级事件;三参 `new Listener(String targetWidget, String eventName, JavaScript)` 首参是 targetWidget 而非事件名,写反落成 `<Listener target="<事件名>">`——XML 合法、fr_check 通过、前端不执行。来源: doc-1178 / doc-2425
- 填报事件名常量:`com.fr.report.web.WebWrite`(EVENT_AFTER_WRITE="afterwrite" 等);分页/数据分析事件名(startload/afterload/beforetopdf...)为 `com.fr.report.web.WebContent` 字面量;全集见 ckzl/lc/06 §11.5。来源: doc-1178
- 图表联动 API:`com.fr.chart.chartattr.Chart` 承载交互属性超链(设计器「特效>交互属性」);`com.fr.chart.web.ChartHyperlink` 基类持超链名/目标/参数映射;「当前表单对象」目标指向同表单组件名,实现类名各小版本不稳定不杜撰(详见 NODE-09)。来源: doc-3556
- 前端 JS 类无 API 落点汇总:显隐/限长/下拉联动/超链跳转(1195/1816/1995/1839/4241/4204/4209)均浏览器端 JS,无 com.fr.* 构建路径;.cpt 仅存事件/超链 `<JavaScript>` 文本节点;JS 超链本体可经 JavaScriptHyperlink 程序化写入(见第 1 条)。来源: doc-1195 / doc-1816 / doc-1995 / doc-1839

## 常见错误

<!--KB:NODE08-E01-->
- 超链参数名与数据集参数名不一致或未注册同名模板参数 → 点击静默失效(来源: doc-4202 / doc-947)
<!--KB:NODE08-E02-->
- Listener 三参重载把事件名当 targetWidget 写 → `<Listener target="afterinit">` 合法但前端不执行(来源: doc-2425 / doc-1178)
<!--KB:NODE08-E03-->
- 事件名拼错或挂错预览区(分页/填报/数据分析)→ 静默失效,JS 永不触发(来源: doc-1178)
<!--KB:NODE08-E04-->
- JS 超链/联动悬浮元素用于 App/HTML5 移动端 → 不支持(来源: doc-1839 / doc-4209)
<!--KB:NODE08-E05-->
- 图表联动不 setTimeout 直接 dataRefresh → 报表块刷新时序问题;扩展图表用错接口(应用 dealReloadChartAjax)不刷新(来源: doc-1392 / doc-3115)
<!--KB:NODE08-E06-->
- 下拉联动模拟点击依赖 `td[id^=D1] .linkspan` DOM 结构,页面改版易碎(来源: doc-1995)
<!--KB:NODE08-E07-->
- sortChart 不包 setTimeout 或图表不在 8 种白名单内 → 排序不生效(来源: doc-2332)
