## 核心知识点(工程向,标注 来源 doc-XXXX)

<!--KB:NODE04-K01-->
1. **扩展方向三态,无头必显式配**(来源 doc-140):纵向/横向/不扩展,枚举 `ExpandType.TOP_TO_BOTTOM/LEFT_TO_RIGHT/NONE`;XML 抽象为 `<Expand dir="0|1|2">`。⚠ 设计器「拖字段默认纵向扩展」仅 GUI 成立,无头生成漏配 expand 属性 → 运行时按「不扩展」处理,整列塌陷。详见 ckzl/lc/03 §3.1。
<!--KB:NODE04-K02-->
2. **单元格样式**(来源 doc-217):`Style` 统一承载格式/字体/边框/背景/对齐;样式只影响显示、不改单元格实际值;预定义样式为设计器内置,无独立 Java 构造入口。详见 ckzl/lc/03 §4。
<!--KB:NODE04-K03-->
3. **分页冻结与重复标题**(来源 doc-368):`WorkBook` 页面属性 ↔ `<ReportSettings><RepeatRow>/<RepeatColumn>` + `<FrozenColumnRow columnrow="B3"/>`;columnrow=冻结区右下角格(如 B3=前2行+前2列);⚠ 冻结区含合并单元格时 columnrow 必须到达合并区右下角,否则第一页冻结内容不显示;取消分页非模板属性,预览 URL 加 `&__bypagesize__=false`。详见 ckzl/lc/03 §3.6/§3.6.1。
<!--KB:NODE04-K04-->
4. **权限细粒度内容控制**(来源 doc-866):单元格可见/新值、整行整列隐藏、控件可见可用、工具栏按钮、sheet 可见均由设计器「权限编辑」写入模板级 `<RolePrivilege>`,**无公开 Java API**;平台侧目录权限属决策系统 RBAC(com.fr.fs)。详见 ckzl/lc/03 §3.8。
<!--KB:NODE04-K05-->
5. **扩展后排序基础范式**(来源 doc-897):`CellExpandAttr.setOrderType/setOrderFormula` ↔ `<Expand dir="0" sortAfterExpand="1">` + `<SortExpression><Attributes>`;⚠ 必须设在【最父格】,设在 B2..F2 静默无效;排序公式引用列必须数字型(日期/字符串不能 *-1)。详见 ckzl/lc/03 §7.1。
<!--KB:NODE04-K06-->
6. **多列按先后排序 = 位权复合键**(来源 doc-2528):`CellExpand.setSortDirection/setSortFormula`,公式如 `INARRAY(B2,SORTARRAY(UNIQUEARRAY(B2[!0])))*POWER(10,LEN(MAX(E2[!0])))+E2`;不填公式只设升序=按值排序;公式由 Java 原样存文本、不负责求值。详见 ckzl/lc/03 §7.8/§7.9。
<!--KB:NODE04-K07-->
7. **按分组汇总结果排序**(来源 doc-2684):`CellExpandAttr.setSortType/setSortFormula/setLeftParentColumn/setUpParentRow`;排序公式指向同层汇总格(外层分组←外层小计),必须经左父格链挂在被排序格之下;先挂左父格、再设排序公式。详见 ckzl/lc/03 §7.2。
<!--KB:NODE04-K08-->
8. **中文拼音 / 汉字数字排序变体**(来源 doc-3309 + doc-3717):拼音走 `StringPinyin($$$,"",1)`($$$ 自引用),⚠ 该函数来自「常用函数集合插件」,服务端未装则排序静默退回 ASCII 序;汉字数字走 `setExtendSortType/setExtendSortFormula` + INARRAY/MAPARRAY/NUMTO(NUMTO 仅整数、汉字须连续从一起始)。详见 ckzl/lc/03 §7.5/§7.6。
<!--KB:NODE04-K09-->
9. **排序方案五选一路由**(来源 doc-2487):分组内排序互不干扰=动态参数+内置数组公式(JOINARRAY/ADD2ARRAY/REMOVEARRAY/INDEXOFARRAY),纯设计器配置、无 Java 代码;选型前先对照五档路由表。详见 ckzl/lc/03 §7.0.1/§7.11。
<!--KB:NODE04-K10-->
10. **.frm 无头改写范式 + 折叠展开**(来源 doc-3252):四步链路 `FormIO.readForm` → `Form.getWidgetByName("report0")`(走 `FormWidgetHelper.findWidgetByName`,返回容器内**真实对象**,改动落盘生效)→ `((ElementCaseEditor) w).setXxx(...)` / `((ChartEditor) w).setXxx(...)` → `FormIO.writeForm`;⚠ 反例 `Form#getBodyContainer()` 字节码是 `container.clone()` 后 removeWidget(参数面板),往里 addWidget/改属性编译运行都正常、**落盘后全部丢失**;报表块=`com.fr.form.ui.ElementCaseEditor`、图表块=`com.fr.form.ui.ChartEditor`,均继承 `AbstractBorderStyleWidget`。
<!--KB:NODE04-K11-->
11. **条件属性(HighlightGroup)运行期语义**(来源 doc-2365/3240):`HighlightGroup#execute` **两遍扫描**——第一遍全部 `Highlight.eval` 冻结命中集,第二遍才按下标顺序 action ⇒ **不是首条命中即停,全部命中都执行,数组下标大的最后写即最终生效**("后配的盖先配的",与 GUI 一致);同组内**无链式触发**(ValueHighlightAction 改值不影响同组其它条件判定);`setHighlightGroup` 声明在 `AbstractDynamicCellElement`(接口 `DynamicAttrElem`),TemplateCellElement/CellElement 上没有;scope 取值 0=本格/1=整行/2=整列(无具名常量,错值静默退化只改本格);`HighlightGroup` **无 add 方法**,只能先聚合再一次性构造,聚合顺序=优先级(最高放数组尾)。详见 ckzl/lc/03 §3.4.5。
<!--KB:NODE04-K12-->
12. **隐藏行列**(来源 doc-1698):静态隐藏=`ElementCase#setRowHeight(int,UNIT.ZERO)/setColumnWidth(int,UNIT.ZERO)`(负值静默 clamp 成 0);条件隐藏=`RowHeightHighlightAction/ColWidthHighlightAction`(无参构造已是 UNIT.ZERO,值为 0 时不写子节点是**正常**形态)挂 `DefaultHighlight` → `HighlightGroup`;取消隐藏无独立 API,写回默认常量;FR **无 `hidden` 布尔位**,别去找 `setHidden`。详见 ckzl/lc/03 §5.6。
<!--KB:NODE04-K13-->
13. **单元格两个公式槽**(来源 doc-854):值槽=`DefaultTemplateCellElement(col,row,new Formula(...))`(落 `<C>`);显示值槽=经 `setCellGUIAttribute(CellGUIAttribute)` + `setResultFormula(Formula)`(落 `<CI>` 下 `<ResultFormula>`,`$$$`=运行期本格值占位符);凡文档出现「高级>显示值/自定义显示/$$$」一律归显示值槽。详见 ckzl/lc/03 §3.14。
<!--KB:NODE04-K14-->
14. **单元格形态(无 setPresent)**(来源 doc-1191/3075):FR 10.0 `CellGUIAttr` **无 `setPresent(Present)` 方法也无 Present 字段**,无头构建统一走 XML `<CellGUIAttr><Present class="...">…</Present></CellGUIAttr>`;形态实现类分两包不可互用:`com.fr.report.cell.present.DictPresent`(数据字典)vs `com.fr.report.cell.cellattr.BarcodePresent`(条形码,+`com.fr.code.bar.core.BarcodeAttr` setType/setBarWidth/setBarHeight/setDrawingText);插件「形态」类须 diff 官方 .cpt 取真实 class 名,不要臆测。详见 ckzl/lc/03 §3.9。

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

1. **单元格扩展**(来源 doc-140):`com.fr.report.cell.TemplateCellElement.setCellExpand(CellExpandAttr)`(实现类 `DefaultTemplateCellElement(column,row)`);`CellExpandAttr.setExtendDirection(ExpandType)`;`com.fr.report.stable.ExpandType.TOP_TO_BOTTOM/LEFT_TO_RIGHT/NONE`;XML `<CellExpandAttr><extendDirection>`(kit 抽象 `<Expand dir="0|1|2">`,0=纵/1=横/2=不扩展);setter 名在个别 10.0 小版本可能为 setExtendDirection/setCellExpand,以 jar 为准。
2. **单元格样式**(来源 doc-217):`com.fr.report.style.Style`:`setFormat`(`format`)/`setFont(java.awt.Font)`+`setForeground(Color)`(`color`)/`setBorder(BorderAttr)`(四边 `BorderLine`(线型 int + Color))(`border`)/`setBackground(ColorBackground.createBackground(Color))`(`bgColor`)/`setHorizontalAlignment/setVerticalAlignment`(`halign/valign`)/`setWrapText`(`wrapText`);经 `DefaultTemplateCellElement.setStyle(Style)` 挂载。
3. **冻结与重复标题**(来源 doc-368):`com.fr.main.impl.WorkBook` + `com.fr.report.core.ReportPageAttr` ↔ `<ReportPageAttr><ReportSettings>`;重复标题行/列 → `<RepeatRow><![CDATA[0,1]]></RepeatRow>`/`<RepeatColumn>`;分页冻结 → `<FrozenColumnRow columnrow="B3"/>`;精确 setter 名各版本不稳定,未核验不杜撰签名,直接按 XML 骨架构造 .cpt 后 `TemplateWorkBookIO.writeTemplateWorkBook` 写出。
4. **扩展后排序**(来源 doc-897/2684/2528/3717/3309):`CellExpandAttr.setOrderType(ASC/DESC)`+`setOrderFormula(String)`(897/3309);`setSortType/setSortFormula/setLeftParentColumn/setUpParentRow`(2684);`CellExpand.setSortDirection(ASCEND/DESCEND)+setSortFormula`(2528);`setExtendSortType/setExtendSortFormula`(3717);XML `<Expand dir="0" sortAfterExpand="1">` + `<SortExpression><Attributes><![CDATA[公式]]>`;工作簿落地 `WorkBook`+`WorkSheet.addCellElement`+`TemplateWorkBookIO.writeTemplateWorkBook`。
5. **权限控制**(来源 doc-866):无公开 API;模板级 `<RolePrivilege>` 由设计器权限编辑态读写,不构造、不杜撰。
6. **.frm 读写入口**(来源 doc-3252):`com.fr.form.main.FormIO.readForm(String)/writeForm(IOFile,String)`;`Form#getWidgetByName(String)`(真实对象,可原地改);⚠ 禁用 `Form#getBodyContainer()`(clone,改动丢);宿主控件 `com.fr.form.ui.ElementCaseEditor`/`ChartEditor`。
7. **移动端折叠展开**(来源 doc-3252):`ElementCaseEditor/ChartEditor#setMobileCollapsedStyle(MobileCollapsedStyle)`(getter 返回字段本身可原地 mutate);`MobileCollapsedStyle.setCollapsedWork(true)` 是**唯一总开关**(不进前端 JSON,只在 createJSONConfig 做服务端 if);XML 外层标签名=运行时 `description()`(`<MobileFormCollapsedStyle>`/`<MobileChartCollapsedStyle>`),**必须带 `class` 属性**,写成父类名/漏 class 均被 readXML 静默跳过;只配样式对象不置总开关=XML 写全但前端一行不跑。

## 常见错误

<!--KB:NODE04-E01-->
- 无头生成漏写 expand 属性 → 运行时按「不扩展」,整列塌陷且无报错(来源 doc-140)。
<!--KB:NODE04-E02-->
- 冻结区含合并单元格但 `columnrow` 未到合并区右下角 → 第一页冻结内容不显示(来源 doc-368)。
<!--KB:NODE04-E03-->
- 扩展后排序设在非最父格(B2..F2)→ 静默无效(来源 doc-897)。
<!--KB:NODE04-E04-->
- 排序公式引用列是日期/字符串却做 *-1 翻向 → 排序失效,需先 DATEDIF 转数字(来源 doc-897)。
<!--KB:NODE04-E05-->
- StringPinyin 公式用了但「常用函数集合插件」未装 → 拼音排序静默退回 ASCII 序,无头批量化最致命(来源 doc-3309)。
<!--KB:NODE04-E06-->
- `.frm` 用 `getBodyContainer()` 拿容器改控件 → 编译运行正常、落盘后全部丢失(来源 doc-3252)。
