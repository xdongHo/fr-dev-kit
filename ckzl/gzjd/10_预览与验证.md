<!--KB:NODE10-K10-->
- **版本/jar 归属判据**:`NoClassDefFoundError` 拿到类名先 `python kfgj/fzpy/jar_class_probe.py --jars C:/frjars find <类简单名>`——**0 命中=版本/插件不匹配(补 jar 无解,须换整套)**,有命中=classpath 顺序或 ClassLoader 问题(补 jar 有解);版本戳比对只比前 10 位日期禁止 equals 原串(accumulator/swift-log-adaptor/third/webui 四 jar 无戳只能比 md5)。来源: doc-1342/1163,详见 ckzl/lc/08 §16.12
<!--KB:NODE10-K11-->
- **公式单测最轻路径**:`com.fr.script.Calculator.createCalculator().evalValue("<公式串>")` 即可求值(无需 WorkBook/Workspace/WorkResource),适合对生成模板里每条公式做单测;断言必须先判 `com.fr.stable.Primitive` 三态(NULL/ERROR_VALUE/ERROR_NAME),`!= null` 恒真;⚠ `QUERY` 等函数在 JDK15+ 静默返回 ERROR_VALUE/NULL(Nashorn 移除),自检断言 `ScriptFactory.newScriptEngine().getClass() != MockScriptEngine.class`。来源: doc-810/1191,详见 ckzl/lc/08 §16.14
<!--KB:NODE10-K12-->
- **JS/CSS 引用加载排查**:`WebUtils.getImportedCSS(attr)` 当探针再调 `getImportedJS(attr)`——EngineModule 未启动/全局 WebAttr 取不到时 CSS 侧直接抛、JS 侧静默降级成空/半集(exception_table 差异);引用的 JS/CSS 一个都没加载时先看 fanruan.log 有无引擎模块 error,再查模板级/服务器级引用。来源: doc-615/3475,详见 ckzl/lc/06 §11.14

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- ReportWebAttr(分页预览):com.fr.web.attr.ReportWebAttr ↔ `<ReportWebAttr>`;workBook.setReportWebAttr/getReportWebAttr;「报表显示位置/以图片方式显示/iframe 自动收缩/重方式输出格子」为布尔/枚举属性;工具栏 ReportWebToolbar/Button 子类;具体 setter 签名各 10.0 小版本不稳定,以 jar 反编译为准;构建路径见 ckzl/lc/06 §11.6。来源: doc-135
- WriteAttr(填报预览):com.fr.web.attr.WriteAttr ↔ `<ReportWebAttr>` 下填报属性;含 sheet 标签页位置/编辑行背景色/未提交离开提示/直接显示控件/自动暂存等开关;`&op=write` 是 URL 分发参数非 API;见 ckzl/lc/05 §21.1.1。来源: doc-136
- 权限/调度平台类无 API:数据连接权限、定时调度权限与调度配置均落 FineDB 表 + 控制台 GUI,无 com.fr.* 构建路径;doc-3185 中的 com.fr.schedule.output.EmailException、com.fr.restriction.MemoryAlarmException 等仅为异常类名(排错参考)。来源: doc-4152 / doc-4154 / doc-4158 / doc-4159 / doc-3185
- 移动端预览无 API:二维码/链接由设计器前端生成,URL 模板 decision/view/report?viewlet=..&op=mobile;设备仿真为浏览器功能;无 Java 构建路径。来源: doc-2432 / doc-4637

## 常见错误

<!--KB:NODE10-E01-->
- 用超管账号验证权限类功能 → 不算通过,须用目标业务账号复验(来源: doc-4152 / doc-4154,AGENTS 0.8)
<!--KB:NODE10-E02-->
- 以为改模板能切换预览方式 → 填报预览靠 URL &op=write,不是模板属性(来源: doc-136)
<!--KB:NODE10-E03-->
- 分页预览设置被误以为对填报/数据分析预览生效(来源: doc-135)
<!--KB:NODE10-E04-->
- 移动端样式/事件在 PC 预览看不出效果 → 须设备仿真或真机(来源: doc-4637 / doc-135)
<!--KB:NODE10-E05-->
- 手动运行任务成功 ≠ 定时调度环境成功(连接池/时区/编码/FineDB 共享冲突,来源: doc-3185)
