# NODE 01 需求与数据判定

> 本节点为ckzl/gzjd,自包含:判定题 → 知识点 → Java API → 常见错误 → 验证清单 → 路由。
> 详细展开见 ckzl/lc/ 对应章节(见导航文件 §四),本文件保持轻量。

## 判定题(先回答,再往下读)

- 报表给谁看、解决什么问题?(明细/汇总/分析/填报录入)
- 数据从哪来?数据库表/Excel/API/内置数据集?
- 要展示/录入哪些字段?字段的格式、精度、单位?
- 模板类型:FRM 决策报表 or CPT 普通报表?(Q1)
- 业务形态:填报 / 明细 / 复杂查看?(Q2)
- 需要哪些交互:超链/联动/导出?

## 核心知识点(工程向,标注 来源 doc-XXXX)

<!--KB:NODE01-K01-->
- **模板类型判定 FRM/CPT 决定构建链**:判定=FRM 时,.frm 容器模型构建链见本节点「Java API 要点」;.cpt 链路详见 ckzl/lc/03(来源 doc-4047)
<!--KB:NODE01-K02-->
- **交互需求判定**:涉及「报表块切换/显隐」类交互时,控件可见性语义是反向坑(`invisible` 取反、缺属性=可见),详见 NODE-03 常见错误(来源 doc-4047)
<!--KB:NODE01-K03-->
- FRM body「初始化事件」eventName 实读为 `afterinit`(来源 doc-4047;事件名全集见 ckzl/lc/06 §11.5)
<!--KB:NODE01-K04-->
- **数据连接判定**:连接名是 .cpt 与服务器连接池的唯一契约,JDBC URL/驱动/密码不落模板;交付必须附【目标数据连接名清单】,名字拼错或服务器缺失 → 31300013(来源 doc-299,详见 ckzl/lc/02 §13.1)
<!--KB:NODE01-K05-->
- **数据连接权限判定**:使用/管理/授权三类权限相互独立,由超管在平台授予;运行账号无「使用」权限则取数失败,与模板 XML 对错无关(来源 doc-2457/doc-4153,详见 ckzl/lc/02 §13.2-13.4)
<!--KB:NODE01-K06-->
<!--KB:NODE01-K07-->
- **数据连接=平台配置**(HSQL 等):在「数据连接管理」界面人工配置,驱动 `com.fr.third.org.hsqldb.jdbcDriver` 是第三方 JDBC 类名、非模板构建 API(来源 doc-2574,详见 ckzl/lc/02 §8.5/§13.7)
<!--KB:NODE01-K08-->
- **权限细粒度参数**:`$fine_username`/`$fine_role`/`$fine_position` 等由平台认证后自动注入 Session,无需也不能用 Java API 显式构造;大小写敏感、必须小写(来源 doc-865,详见 FR_HEADLESS_GUIDE §Q)
<!--KB:NODE01-K09-->
- **模板类型判定补充:移动端组件类需求必须落 .frm**:生成前按根节点判定 `<Form>`(决策报表 .frm)vs `<WorkBook>`(普通报表 .cpt);凡需求是「移动端组件样式/插件类组件」必须落在 .frm body(移动端样式插件只作用 .frm body,doc-3045/3260);凡「点 A 刷新 B」联动需求先判模板类型——单元格→图表可在 .cpt(CellChartHyperlink/悬浮元素),**图表→图表/图表→单元格/单元格→单元格在 .cpt 一张模板内做不到,必须落 .frm**(doc-3556 §2.3.3);凡依赖官方插件的模板,交付物随附插件/版本清单(四件套均 ≥V10.4.49,建议 ≥V10.4.55,doc-3045)
<!--KB:NODE01-K10-->
- **平台管理类需求路由(不误收报表构建)**:数据决策系统平台管理类需求(LDAP 认证/用户同步/角色权限/部门职务)属 com.fr.decision.* 平台体系,**不在** fr_dev_kit 无头报表构建范围,路由到「平台运维/Web 控制台」而非报表构建 SOP(除非是报表里读取同步用户数据——那是数据集 SQL 的事)(doc-4343/2365);「定时调度」类需求先分族:调度公式/参数配置(3315,可无头)vs 管理/授权权限(4158/4159,平台 GUI,不可生成)(doc-4158)

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- **.frm 容器模型构建链**(判定=FRM 时用,详见 NODE-09 FRM决策报表):`FormIO.readForm(path)`/`FormIO.writeForm(IOFile, path)`;`com.fr.form.main.Form(WLayout)`;body=`com.fr.form.ui.container.WAbsoluteBodyLayout("body")`;「绝对布局>固定大小/自适应」=`WAbsoluteLayout#setCompState(STATE_FIXED=1 / STATE_FIT=0)` → `<WidgetScalingAttr compState=".."/>`;`setDesigningResolution(Dimension)` → `<DesignResolution absoluteResolutionScaleW/H>`;报表块 `ElementCaseEditor#setElementCase(com.fr.report.worksheet.FormElementCase)`;按钮 `com.fr.form.ui.FreeButton#setText`(来源 doc-4047)
- **加控件必须包 BoundsWidget**:`addWidget(new WAbsoluteLayout.BoundsWidget(w, Rectangle))` → `<Widget class="…$BoundsWidget"><InnerWidget …/><BoundsAttr x= y= width= height=/></Widget>`;直接子 Widget 不是 BoundsWidget 则坐标丢失(fr_check 应报 warning)(来源 doc-4047)
- **改已有 .frm 一律走 `Form#getWidgetByName(name)`**,禁用 `Form#getBodyContainer()`(字节码 = `container.clone()`,写入静默丢失)(来源 doc-4047/doc-3252)

## 常见错误

<!--KB:NODE01-E01-->
- 把 JDBC 配置(URL/驱动/密码)写进模板,或交付物漏附连接名清单 → 预览 31300013(来源 doc-299,详见 ckzl/lc/02 §13.1)
<!--KB:NODE01-E02-->
- 用超管账号验证权限类功能 → 通过≠业务账号可用,必须业务账号复验(来源 doc-2457/doc-4153)
<!--KB:NODE01-E03-->
- 改 .frm 用 `getBodyContainer()` 拿容器再改控件 → clone 后写入静默丢失、XML 全过校验(来源 doc-4047)
