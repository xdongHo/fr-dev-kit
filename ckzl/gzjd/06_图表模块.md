## 核心知识点(工程向,标注 来源 doc-XXXX)

<!--KB:NODE06-K01-->
1. **图表配置正交三分总纲**(来源 doc-1672):一个图表的配置切成三个**互不覆盖**的子树(①数据绑定 ②样式 ③交互特效),可对同一 `<Chart>` 分三次幂等注入——改样式不碰数据与联动;缺这张总纲时生成器面对「加个图例」会整体重写图表节点、冲掉已配联动。详见 ckzl/lc/03 §9.1。
<!--KB:NODE06-K02-->
2. **图表数据来源二分**(来源 doc-175):数据源已是干净事实表 → 走数据集字段绑定(doc-176);数据需先在单元格二次汇总/转换 → 走**单元格数据绑定**:分类/系列/值填入单元格引用公式,**必须用 F(x) 公式入口**(直接输入被判为普通文本),连续 `=[A1:A3]`、不连续 `=[A1,A3,A5]`;父子格链必须有(分类是系列的父格、系列是值的父格);二次计算会丢单元格属性;单元格数据源插件有地图/甘特/扩展图表盲区。详见 ckzl/lc/03 §9.2/§9.4。
<!--KB:NODE06-K03-->
3. **图表样式九类 + 两层模型**(来源 doc-1672 + doc-4138):标题/图例/标签/系列/坐标轴/数据表/背景/提示 + 配色;两层模型=通用层+图表类型特有层(饼图半径/仪表盘刻度等),凡类型特有样式 spec 必须携带 chart_type;配色是「引用命名方案」而非逐系列铺色;样式可写公式引用模板参数。详见 ckzl/lc/03 §9.5/§9.6。
<!--KB:NODE06-K04-->
4. **图表自定义分类颜色(条件显示)**(来源 doc-3242):单系列/无系列图表默认全分类同色;官方「方法一条件显示」可**完整 Java API 无头构建**:`Chart` → `Plot.setConditionCollection` → `ConditionCollection.addConditionAttr` → `ConditionAttr` + `AttrColor`,逐分类叠加即分类多色;⚠ 旧资料 `com.fr.data.condition.Condition` 在本机 jar 中**不存在**,真实触发类是 `com.fr.data.condition.CommonCondition` + `com.fr.data.core.Compare` 常量。
<!--KB:NODE06-K05-->
5. **图表自定义单系列标签**(来源 doc-2697):与分类颜色同走 `ConditionCollection/ConditionAttr`,区别只在 `addDataSeriesCondition` 挂的是**标签属性对象**而非 AttrColor;两套引擎模型——旧图表引擎 `com.fr.chart.base.AttrContents`、新图表引擎(chartx)`com.fr.chartx.config.info.LabelConfig`(+`LabelAndToolTipContent`),另有插件包 `com.fr.plugin.chart.base.AttrLabel` 勿混淆;多条件 OR 用 `JoinCondition` 连接两个 CommonCondition。
<!--KB:NODE06-K06-->
6. **图表条件键体系**(来源 doc-2697):图表条件显示的 columnName 用「系列序号」「系列名称」「分类名」等**图表专属键**,与单元格条件属性键体系(A2/B2 坐标)不同,无头生成时套错整条规则静默失效。
<!--KB:NODE06-K07-->
7. **扩展图表轮播联动**(来源 doc-2857):.frm 决策报表设计器特效「轮播联动/刷新联动」,由扩展图表插件(com.fr.plugin.chart)GUI 实现,无标准 com.fr.* API 落点;绑定表单对象 + 联动动画 + 联动参数。详见 ckzl/lc/07 §12.6。
<!--KB:NODE06-K08-->
8. **图表单元格联动超链**(来源 doc-4207):被点击格(入口)加「联动单元格图表」超链 → 设「联动单元格」=图表所在格坐标 → 加参数(值=公式 `=$$$` 取当前格值);图表所在格须插入图表并绑定**参数化数据集**,联动本质=超链传参→图表格数据集重查;参数为空选全部用加固 SQL。详见 ckzl/lc/03 §11.5 / ckzl/lc/05 §14.1。
<!--KB:NODE06-K09-->
9. **图表块折叠展开(.frm)**(来源 doc-3252):`ChartEditor` 是图表块宿主,折叠展开走 `setMobileCollapsedStyle(MobileChartCollapsedStyle)`;标签名=运行时 `description()` 且必须带 class 属性,总开关 `collapsedWork=true` 不可省——完整范式见 NODE-04 知识点(doc-3252),本节点仅宿主类与标签名不同。
<!--KB:NODE06-K10-->
10. **扩展图表插件类归类(无核心 API)**(来源 doc-2490/2857/3836):三维地球/流向地图/轮播联动/轮播条形图(扩展图表-柱形图类,插件 4.4)等扩展图表**无标准 com.fr.* API 落点**,核心 jar 不含 com.fr.plugin.chart 实现类;无头生成应走「设计器/插件 GUI 产出 .cpt → XML 解析/校验/局部改写」路线,而非 Java API 从头构建;轮播条形图伪装成核心柱图,须显式隔离禁丢进核心图表生成器(不支持条件属性/自定义标签样式);缺插件/版本错=模板静默打不开、fr_check 全过,须前置断言「扩展图表插件 4.4 + Chrome>=86 + 不支持导出/移动端」。详见 ckzl/lc/03 §9.13。
<!--KB:NODE06-K11-->
11. **扩展图表「装配 vs 样式」二分**(来源 doc-2664/3135/3836):装配侧(建图/绑数据集/绑字段/刷新开关/超链组/落单元格)有完整引擎侧 API——`com.fr.chart.charttypes.ChartTypeManager` + `com.fr.extended.chart.{AbstractChart,AbstractDataConfig,ExtendedField,ExtendedTableDataSet,ExtendedReportDataSet}`(49 类全在 fine-report-engine-10.0.jar,**不需要装插件即可编译链接**);样式侧(颜色风格/渐变/内径占比/值轴最大/背景不透明)在插件私有子类,引擎零 setter,只能走「设计器存模板→读回改→写回」diff 路径。判据一句话:`com.fr.extended.chart.*` 里没有的 setter 就是插件私有。详见 ckzl/lc/03 §9.13。
<!--KB:NODE06-K12-->
12. **VanChart 五段式无头构建链**(来源 doc-1953/1954):`new <XxxVanChartPlot>()` → 手工 seed 默认条件(`getConditionCollection().getDefaultAttr()` + `getExisted(AttrLabel.class)==null` 时 `addDataSeriesCondition(plot.getDefaultAttrLabel())`,官方工厂 protected 跨包不可调)→ 改条件集合里的 AttrLabel/AttrTooltip → `chart.setFilterDefinition(<Xxx>Definition)`(甘特图是两层:`VanGanttDefinition` 包 `VanGanttTableDefinition`;缺中间层=图空白零日志)→ `new VanChart(plot)` → `new ChartCollection(chart)` → `DefaultTemplateCellElement.setValue(cc)` + `setColumnSpan/setRowSpan` → `writeTemplateWorkBook`;`com.fr.plugin.chart.*` 全在 fine-report-engine,**不依赖任何插件**。详见 ckzl/lc/03 §9.14。

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

1. **图表条件显示构建链路**(来源 doc-3242):`com.fr.chart.chartattr.Chart`(`getPlot()/setPlot(Plot)`)+ `com.fr.chart.chartattr.Plot.setConditionCollection(ConditionCollection)`(`<ConditionCollection>` 是 `<Plot>` 直接子节点)+ `com.fr.chart.chartglyph.ConditionCollection.addConditionAttr(ConditionAttr)` + `com.fr.chart.chartglyph.ConditionAttr`(`setName/setCondition(AbstractCondition)/addDataSeriesCondition(DataSeriesCondition)`);XML `<Plot>/<ConditionCollection>/<ConditionAttr>/<AttrColor>`。
2. **着色属性**(来源 doc-3242):`com.fr.chart.base.AttrColor`(extends `DataSeriesCondition`),`setSeriesColor(java.awt.Color)`,写 XML 为 `<AttrColor>`,颜色取 `seriesColor.getRGB()`(0xRRGGBB 整数)。
3. **触发条件类**(来源 doc-3242/2697):`com.fr.data.condition.CommonCondition(String columnName, int comparator, Object value)`;比较符来自 `com.fr.data.core.Compare`(`EQUALS=0/NOT_EQUAL=1/CONTAINS=10/NULL=14` 等,已实读);多条件 OR 用 `com.fr.data.condition.JoinCondition` 连接;⚠ `com.fr.data.condition.Condition` 不存在,勿照抄旧资料。
4. **标签属性对象**(来源 doc-2697):旧引擎 `com.fr.chart.base.AttrContents`(实现 DataSeriesCondition,勾选「值」=其 setter)/ 新引擎 chartx `com.fr.chartx.config.info.LabelConfig` + `...content.LabelAndToolTipContent`(两类的 .class 均在 fine-report-engine jar 确认存在,setter 签名待探针复核);标签节点确切 tag 名(`<AttrContents>`/`<LabelConfig>`)待核验。
5. **图表单元格数据源**(来源 doc-175):无 Java API 落点(公式/概念级);分类/系列/值绑定单元格公式(`=[A1:A3]` 等),Java 侧复现等价能力需另行查证 `com.fr.chart.chartdata.*` 单元格数据定义类,文档未提供,不杜撰。
6. **图表落地写盘**(来源 doc-3242/2697):构建好的 `Chart` 对象放入单元格元素(CellElement/FloatElement)后,由 `com.fr.io.TemplateWorkBookIO.writeTemplateWorkBook(WorkBook, String)` 写出 .cpt。
7. **图表块折叠展开**(来源 doc-3252):`com.fr.form.ui.ChartEditor#setMobileCollapsedStyle(com.fr.form.ui.mobile.MobileChartCollapsedStyle)`;getter 返回字段本身可原地 mutate;XML `<MobileChartCollapsedStyle class="...">`,漏 class 属性被 readXML 静默跳过(同 NODE-04 doc-3252 全表)。
8. **轮播联动 / 联动超链无标准 API**(来源 doc-2857/4207):轮播联动为插件 GUI 能力(com.fr.plugin.chart),无类名可写;联动单元格超链由设计器写入 `.cpt` 的 CellHyperlink/ChartHyperlink 配置节点,文档未给出 Java 构建路径,不杜撰。

## 常见错误

<!--KB:NODE06-E01-->
- 图表单元格数据源直接输入单元格引用文本而非 F(x) 公式 → 被判为普通文本、不绑定(来源 doc-175)。
<!--KB:NODE06-E02-->
- 照抄旧教程写 `com.fr.data.condition.Condition` → ClassNotFound;真实类是 `CommonCondition`(来源 doc-3242)。
<!--KB:NODE06-E03-->
- 分类多色条件显示配错(分类名不匹配/颜色缺失)→ 静默整色失效,headless 阶段应前置校验(来源 doc-3242)。
<!--KB:NODE06-E04-->
- 条件显示 columnName 套用单元格条件键(如 A2/B2 坐标)→ 整条规则静默失效,fr_check/diff 都查不出(来源 doc-2697)。
<!--KB:NODE06-E05-->
- 单系列标签误写成 AttrColor,或漏掉新引擎 chartx 的 LabelConfig 分支 → 标签不生效(来源 doc-2697)。
<!--KB:NODE06-E06-->
- .frm 折叠展开只配样式对象不置 `collapsedWork(true)` 总开关 → XML 写全了、前端一行不跑(来源 doc-3252)。
<!--KB:NODE06-E07-->
- 联动超链参数名未在图表数据集与模板参数中双声明 → 图表静默不刷新(来源 doc-4207)。

## 验证清单

- [ ] 图表数据绑定:单元格数据源全部走 F(x) 公式入口;分类/系列/值三要素齐全;父子格链完整
- [ ] 条件显示:CommonCondition 条件键为图表维度(分类名/系列序号/系列名称);AttrColor 颜色为合法 RGB 整数;条数与分类数匹配
- [ ] 单系列标签:已按引擎分旧(AttrContents)/新(LabelConfig)两套写入,未误用 AttrColor
- [ ] 样式:九类枚举覆盖检查(类别名拼错=该类样式静默丢失);类型特有样式已携带 chart_type
- [ ] 联动:入口格超链 + 联动单元格坐标 + 参数名在模板参数与图表数据集双声明
- [ ] 折叠展开:collapsedWork=true + 标签名按宿主类型(MobileChartCollapsedStyle)带 class 属性

## 图表类型补全(2026-08-09 全量学习收官,来源 doc-1592/1507/1654)

### 地图图表(MapPlot)
<!--KB:NODE06-K13-->
- Plot 基类 `com.fr.chart.chartattr.MapPlot`(已核实);地图类型(区域/钻取/热力/流向/气泡/自定义)在 Plot 层选型,子类名未核实
<!--KB:NODE06-K14-->
- GIS 图层三形态:标准高德(10.0.13+,仅在线查看、WebGL 内存限制、**不支持导出**)/ 自定义 TileLayer(仅在线查看、访问超限失效)/ 自定义 WMS(局域网离线,仅 EPSG:3857)
<!--KB:NODE06-K15-->
- ⚠️ 地理部分(边界/缩放/中心点)**设计器不生效、需预览验证、导出不支持**——写入无头工具链限制清单
<!--KB:NODE06-K16-->
- 选型顺序:地图类型 → GIS 图层 → 图例

### 散点图(ScatterPlot/XYPlot)
<!--KB:NODE06-K17-->
- 类型 `com.fr.chart.charttypes.ScatterChart` + 绘图区 `com.fr.chart.chartplot.ScatterPlot`(extends XYPlot);装配链 new ScatterChart()→setPlot→挂单元格(ChartCellElement/ChartCollection 待核验)
<!--KB:NODE06-K18-->
- 数据绑定四槽「系列名/x/y/值」:x/y 为两数值列;值字段对散点图无意义 → **气泡图**路由
<!--KB:NODE06-K19-->
- 坐标轴 `XYPlot#getXAxis()/getYAxis()` → `Axis#setMinValue/setMaxValue`(按数据集 min/max 自动推导)
<!--KB:NODE06-K20-->
- 专有样式落 Plot 层:线型连线/标记点(自动=内置 8 种)/大数据模式/趋势线(指数|线性|对数|多项式 + 预测周期)
<!--KB:NODE06-K21-->
- 选型判据:XY 轴仅支持数值,横轴分类/时间用**组合图**
<!--KB:NODE06-K22-->
- 基线模板:`%FR_HOME%\webapps\webroot\WEB-INF
eportlets\doc\Primary\BasicChart\散点图.cpt`

### 漏斗图(FunnelPlot)
<!--KB:NODE06-K23-->
- 类型推断 `com.fr.chart.charttypes.FunnelChart` + `com.fr.chart.chartplot.FunnelPlot`(单系列图族,未核实)
<!--KB:NODE06-K24-->
- 数据绑定 = 单系列「系列名+值」双槽(每行一个环节,值列驱动梯形面积)
<!--KB:NODE06-K25-->
- 专有样式落 Plot 层:转化率(当前值/上一值)/ 系列连续性(连续/不连续)
<!--KB:NODE06-K26-->
- 值百分比格式 `com.fr.base.CoreDecimalFormat`(已核实);**无坐标轴**(漏斗/饼图族限制,勿配 Axis)
<!--KB:NODE06-K27-->
- 选型判据:单流程单向环节分析 → 漏斗图
<!--KB:NODE06-K28-->
- 基线模板:`%FR_HOME%\webapps\webroot\WEB-INF
eportlets\doc\Primary\BasicChart\漏斗图.cpt`
