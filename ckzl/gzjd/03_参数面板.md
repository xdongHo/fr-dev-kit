## 核心知识点(工程向,标注 来源 doc-XXXX)

<!--KB:NODE03-K01-->
- **参数三层作用域**:数据集参数 `${p}`(SQL 层下推)/ 模板参数(`ReportParameterAttr`,仅本模板)/ 全局参数(工程级,**不落任何 .cpt**);全局与模板重名时界面只显示一个且**以模板参数为准**(来源 doc-157/doc-159,详见 ckzl/lc/04 §22)
<!--KB:NODE03-K02-->
- **模板参数三要素**:①`ReportParameterAttr` 声明 `<Parameter>` ②面板控件 WidgetName 同名 ③挂该列的数据单元格加「过滤」引用 `$参数`;只做①②漏③ → 表格仍全量显示,静默失效(来源 doc-157,详见 ckzl/lc/04 §22.1)
<!--KB:NODE03-K03-->
- **控件↔参数绑定靠「名称相等」**:`setWidgetName` 必须等于 `Parameter.getName`,Web 端给控件赋值=给参数赋值(来源 doc-157/doc-260,详见 ckzl/lc/04 §22.1)
<!--KB:NODE03-K04-->
- **下拉树四条构建路线**按数据形态分流:普通分层构建(多数据集+`${layer1}/${layer2}`)/ 自动构建(自关联表树数据集)/ 极速分层构建(单扁平数据集+DependLayer/DependField)/ 级联下拉(多 ComboBox+模板参数,不是树)(来源 doc-1050/doc-1042/doc-1990/doc-1284,详见 ckzl/lc/04 §27)
<!--KB:NODE03-K05-->
- **下拉树默认值须写完整节点路径**:单选 `华北,北京,北京`、多选 `华北,北京,北京;华东,上海,上海`(节点间`;`、层间`,`)、或公式 `=[1,11,111]`;多选全选配方 `=JOINARRAY(value("ds",列号),";")`(来源 doc-260/doc-1939,详见 ckzl/lc/04 §29)
<!--KB:NODE03-K06-->
- **联动非独立 API**:本质是「后级数据集 SQL 引用前级 Parameter 名」约定 + 三处命名一致(控件 WidgetName/子控件字典参数声明/SQL `${p}`),缺字典参数声明时 FR 不报错、子下拉不随父刷新;父控件须先于子控件定义(来源 doc-1284,详见 ckzl/lc/04 §7.3)
<!--KB:NODE03-K07-->
- **多选下拉复选框**:返回值=字符串 + 分隔符 `','`(**含单引号字面量**),返回 `华北','华中` 形态才能拼 `in ('...')`;级联父控件场景同样适用(来源 doc-1285/doc-3707,详见 ckzl/lc/04 §23)
<!--KB:NODE03-K08-->
- **前端 JS 类能力无 Java API 落点**:控件间赋值(1194)/日期校验(1197)/选值自动查询(1434)/点击任意位置展开(1899)/层级限制提示(3120)均发生在预览期 DOM 层,只能挂控件事件存为 `<JavaScript>` 文本节点,Java 无法构造该逻辑进 .cpt(来源 doc-1194/doc-1197/doc-1434/doc-1899/doc-3120,详见 ckzl/lc/04 §21/§28/§33)
<!--KB:NODE03-K09-->
- **移动端简约下拉样式插件**仅生效于手机/Pad 的 App 与 H5 表单 body 内下拉控件,**不作用**填报 CPT、参数面板、视图树控件(来源 doc-3260,详见 ckzl/lc/04 §18.6/§25)
<!--KB:NODE03-K10-->
- **参数面板级联(公式字典驱动)**:公式字典 `=if($p1='省份',sql("FRDemo","select …",1),…)` 联动,驱动源=模板参数 `$p1`;与 doc-608 单元格驱动(C9)是两套机制,面板无单元格坐标,把参数级联写成单元格引用会静默失效(来源 doc-1029,详见 ckzl/lc/04 §20)
<!--KB:NODE03-K11-->
- **平铺选择控件四选一速查**:平铺单选=`com.fr.form.ui.RadioGroup`、平铺多选=`com.fr.form.ui.CheckBoxGroup`、下拉多选=`ComboCheckBox`、单个 true/false=`CheckBox`;RadioGroup/CheckBoxGroup 同 extends `ButtonGroup`,唯一分野是 `supportMultiple()`(false/true),属性面 100% 共享;CheckBoxGroup「提供全选」= `setChooseAll(true)` ↔ **空元素 `<ChooseAll/>`**(首字母大写、仅 true 时写出,小写 `<chooseAll>` 是无人认领的旧错记法);`setDelimiter/setStartSymbol/setEndSymbol` 必须在 `setReturnString(true)` 之后调用否则三者不落盘(来源 doc-262/263/1086,详见 ckzl/lc/04 §18.1/§21.7)
<!--KB:NODE03-K12-->
- **控件事件白名单与回读铁律**:`FieldEditor`(参数面板控件系)= `{afterinit, beforeedit, afteredit, stopedit}` 四项;**无 beforeedit 的是 DateEditor**(仅三项);`Observer#addListener` 白名单不命中即静默 return 且 `readXML` 同样走它——**挂完 Listener 必须 `getListenerSize()` 回读**,不匹配是无异常无日志的静默丢弃;`<Listener>` 无 `<Listeners>` 外层包装、排在 `<WidgetName>/<WidgetAttr>` 之前(来源 doc-1629/3836,详见 ckzl/lc/04 §21)

## Java API 要点(com.fr.* 类名/方法/与 XML 对应)

- **模板参数唯一正确写法(实读)**:`ReportParameterAttr attr = wb.getReportParameterAttr(); if(attr==null){attr=new ReportParameterAttr(); wb.setReportParameterAttr(attr);} attr.addParameter(new com.fr.base.Parameter("area","华东"));`——`getReportParameterAttr()` 无懒加载,不判 null 就链式调用 = NPE(来源 doc-156)
- **不存在的 API**:`com.fr.main.parameter.ReportParameterAttr` **无** `setParameters(Parameter[])`(父类 `TemplateParameterAttr` 只提供 addParameter/clearParameter/clearParameters/getParameters);`com.fr.main.impl.WorkBook` **无** `putParameter(...)`(只有 `getParameters()`/`apply4Parameters(Map)`)(来源 doc-156 实读;官方 doc-157 的 `WorkBook.addParameter` 与既有笔记 `putParameter` 均按名调用有 NoSuchMethod 风险,以实读为准,个别小版本以 jar 为准)
- **参数面板容器**:`com.fr.form.ui.parameter.ReportParameterUI` + `WorkBook.setParameterUI(ReportParameterUI)`,`addWidget(Widget)` 加入控件,对应 .cpt `<ParameterUI>` 节点;默认文本控件 `com.fr.form.ui.TextEditor`(来源 doc-157)
- **下拉树控件本体是 `com.fr.form.ui.TreeComboBoxEditor`**(非 TreeComboBox,早期推断错误):`setWidgetName`/`setMultipleSelection`/`setReturnLeafNodeOnly`(仅多选)/`setReturnFullPath`(返回完整路径)/`setAsyncLoad`(自动构建须 false)/`setAllowBlank`/`setAllowEdit`(模糊搜索)/`setDictionary(TreeDictionary)`;字典三种构建方式对应 `com.fr.form.ui.TreeDictionary`(来源 doc-260,构建路线详见 ckzl/lc/04 §26-27)
- **联动构件**:`com.fr.data.impl.DBTableData`(⚠原文 SQLTableData 经 2026-09-12 jar 实测 FR10 全部 1133 jar 0 命中,FR10 无此类;联动数据源即普通 SQL 数据集,同款修正见 ckzl/lc/02 §1 与 ckzl/frapi/doc/JavaAPI构建速查.md L115/362/372)(SQL 内 `${area}` 由同名 Parameter 运行时替换)+ `com.fr.data.impl.TableDataDictionary(String tableDataName, String actualKeyColumn, String displayColumn)` + `com.fr.form.ui.ComboBox`(控件名=参数名)(来源 doc-1284,详见 ckzl/lc/04 §7.3)
- **复选框联动**:`com.fr.form.ui.CheckBoxGroup.setDelimiter("','")` + 返回值类型=字符串(常量如 `Widget.STRING_VALUE`)→ 多选返回 `华北','华中` 形态直接拼入 `in ('...')`;分隔符与控件名=参数名二者缺一不可(来源 doc-1285,详见 ckzl/lc/04 §23)
- **控件可见性(.frm)**:Java 侧只有 `com.fr.form.ui.Widget#setVisible(boolean)`/`isVisible()`,内部存**取反字段 `invisible`**,不存在 `setInvisible`;XML 属性名是 `invisible`(位于 `<WidgetAttr>`),**写 `visible="false"` 是不存在属性、被静默忽略**;`Widget#writeXML` 对 `invisible` 条件写出——**只有 true 才落属性,缺属性=可见**。适用范围:.frm `<WidgetAttr>`;.cpt 参数面板 InnerWidget 显隐属另一序列化路径,以既有指南(ckzl/lc/04 §28/§33)为准(来源 doc-4047)

## 常见错误

<!--KB:NODE03-E01-->
- **参数名两套大小写规则**:运行时 `com.fr.util.ParameterApplyHelper#addPara2Map` 用 `map.put(name.toUpperCase(), p)` → 大小写不敏感(`area`==`AREA`);模板内 `TemplateParameterAttr#hasParameter` 用 `getName().equals()` → 大小写敏感,`area` 与 `Area` 能并存同一 XML、校验全过,运行时却互相覆盖(留哪个看 List 顺序);**同名参数第二次 addParameter 被静默丢弃**,改默认值必须先 `clearParameter(old)`(来源 doc-156)
<!--KB:NODE03-E02-->
- **按名调用 `setParameters`/`putParameter`** → NoSuchMethod;`getReportParameterAttr()` 不判 null → NPE,而 attr 为 null 时 `writeXML` 有 ifnull 保护 → 模板静默无参数、落盘与 fr_check 全部通过(来源 doc-156)
<!--KB:NODE03-E03-->
- .frm 手拼 XML 写 `visible="false"` → 属性不存在被静默忽略(正确:写 `invisible`,且**缺属性=可见**)(来源 doc-4047)
<!--KB:NODE03-E04-->
- 联动漏三处命名之一(最常见:漏子控件字典的参数声明) → 不报错、子下拉不随父刷新,无头生成最高频静默失败(来源 doc-1284,详见 ckzl/lc/04 §7.3)
<!--KB:NODE03-E05-->
- 多选分隔符漏单引号 → 返回串不带引号、SQL 拼出 `in (北京,上海)` 语法错或只导出单个值,运行时全部静默(来源 doc-1285,详见 ckzl/lc/04 §23)
