# FR 10.0 API 验证记录（2026-07-31）

> 通过 `javap` + 实际编译运行验证的 API 事实。

## 已验证

| 条目 | 结论 |
|------|------|
| `JavaScriptImpl.getContent()` | ✅ 返回 `String` |
| `Button.getText()` | ✅ 继承自 `Button`，返回 `String` |
| `GraphHelper.getWidth(String, Font)` | ✅ 返回 `int`，优先于 AWT 兜底 |
| `FormParameterUI.setDesignSize(Dimension)` | ✅ 高度唯一写入口 |
| `WParameterLayout.setDesignWidth(int)` | ✅ 宽度写入口 |
| `CRBoundsWidget`（非 `WAbsoluteLayout.BoundsWidget`） | ✅ `layout.getBoundsWidget()` 返回 `CRBoundsWidget` |
| `TemplateWorkBookIO.writeTemplateWorkBook(wb, path)` | ✅ 真实签名 `public static boolean writeTemplateWorkBook(com.fr.main.TemplateWorkBook, java.lang.String)`——首参是**接口** `TemplateWorkBook`（非 `WorkBook`），返回 **boolean**（非 void，必须检查返回值否则写盘失败被静默吞掉）。来源：doc-1213 字节码核验 |
| `Design_Width` ↔ `DesignAttr width` | ✅ 同份数据两种序列化，改一处两处同步 |
| `DesignAttr height` | ✅ 只有此一处，无独立 Design_Height |
| `TemplateWorkBook.getReportParameterAttr().getParameterUI()` | ✅ CPT 路线取参数面板 |

## 确认的限制

| 限制 | 结论 |
|------|------|
| `TemplateWorkBookIO.writeTemplateWorkBook` | ✅ fr-agent /exec 注入后可用（2026-08-07 实测） |
| `TemplateWorkBookIO.readTemplateWorkBook` | ❌ 磁盘读依赖 web 会话，fr-agent 注入环境亦不可用 |
| JSP 路由 | ❌ FR 10.0 Tomcat Validator NPE，无法编译 JSP |
| `Class.forName` 判插件 | ⚠️ 仅判 classpath，不判禁用状态；禁用时类仍在 classpath |
| `TableDataDictionary` 取值 | ⚠️ 需数据源连接，无头环境不可用，已做静默回退 |

## 导出属性 API↔XML 映射（2026-08-08，doc-1108 常量池实测）

> 宿主是 **`com.fr.main.FineBook#get/setReportExportAttr`**（不在 TemplateWorkBook 上）；`setReportExportAttr` 是全量覆盖，必须先 get 再增量改。

| API | XML 属性 | 备注 |
|-----|---------|------|
| `ExcelExportAttr.setExportHidedRow/Column` | `@hideRow/@hideColumn` | **Hided 不是 Hidden** |
| `ExcelExportAttr.setPassword` | `@pwd` | 明文经 `passwordEncode()` 加密串，手写明文不生效，只能 Java `setPassword(明文)` |
| `ExcelExportAttr.setProtectedWord` | `@protectedWord` | — |
| `PDFExportAttr.setPassword` | `@pdfpwd` | 与 Excel 的 `pwd` 不同名 |
| `WordExportAttr.setExportAsTable` | `@WordTable` | 大写开头 |
| `ImageExportAttr.setResolution/setPaging` | `@imageResolution`(默认96)/`@imageType`(boolean) | — |
