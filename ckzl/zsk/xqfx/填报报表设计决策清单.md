# 填报报表设计决策清单

← [返回主路由](../AGENTS.md)

> **创建任何填报报表之前，必须逐项确认以下设计决策。** 不要假设——问用户。

---

## 1. 主键与提交逻辑（最重要）

### 决策树

```
表有主键吗？
├─ 有主键（单列或复合）
│   └─ IntelliDMLConfig（智能提交）
│       ├─ 自动判断 INSERT / UPDATE / DELETE
│       ├─ PK 列标记 isKey="true"
│       └─ 历史 PK 列只读（无 Widget），非 PK 列可编辑
│
└─ 无主键
    └─ 表有 flag 字段吗？
        ├─ 有 flag（默认=1）
        │   └─ DeleteConfig(flag=1) + InsertConfig
        │       └─ 全量删除后重新插入
        └─ 无 flag
            └─ 需加 flag 列或改用条件删除
```

### PK 列编辑规则

| 行 | PK 列 | 非 PK 列 |
|----|-------|---------|
| 历史行 (row=1) | **只读**（DSColumn 无 Widget） | **可编辑**（DSColumn + Widget） |
| 维护行 (row=2) | **可编辑**（空白 + Widget） | **可编辑**（空白 + Widget） |

### IntelliDMLConfig XML 示例

```xml
<DMLConfig class="com.fr.write.config.IntelliDMLConfig">
  <Table schema="数据schema" name="table"/>
  <ColumnConfig name="bu" isKey="true" skipUnmodified="false">
    <ColumnRow column="0" row="1"/>
  </ColumnConfig>
  <ColumnConfig name="amount" isKey="false" skipUnmodified="false">
    <ColumnRow column="6" row="1"/>
  </ColumnConfig>
</DMLConfig>
```

## 2. 按钮列顺序

**Delete 列必须在 Add 列前面。**

```
| 数据列 0..N | delete(col=N) | add(col=N+1) |
```

- DeleteRowButton 和 AppendRowButton 的 WidgetName **都用 `delete`**（共享 CSS 样式）
- AppendRowButton 的 IconName 仍为 `add`

---

## 3. 参数面板控件顺序

**必须问用户控件排列顺序。** 时间类筛选（年份、月份）通常放最前面。

示例优先顺序：年份 → 月份 → BU → 地区 → 工厂 → 项目

---

## 4. 标准按钮顺序

参数面板右下角按钮，标准顺序：

**查询 → 导出 → 提交 → 导入**

| 按钮 | WidgetName | 类型 | JS |
|------|-----------|------|-----|
| 查询 | search | FormSubmitButton | enter 快捷键 |
| 导出 | EXPORT | FreeButton | `_g().exportReportToExcel('simple')` |
| 提交 | SUBMIT | FreeButton | `verifyAndWriteReport(true)` |
| 导入 | IMPORT | FreeButton (w=120) | `FR.showDialog(...)` |

---

## 5. 分页（数据量 > 200 行）

当数据量超过 200 行时：

1. **参数面板**增加隐藏参数 `__cutpage__`，默认值 `v`
2. **填报属性底部工具栏**增加分页按钮组

```xml
<!-- 参数声明 -->
<Parameter><Attributes name="__cutpage__"/><O><![CDATA[v]]></O></Parameter>

<!-- 底部工具栏 (WebWriteContent/ToolBars, Embed position="2") -->
<Widget class="com.fr.report.web.button.page.First"/>
<Widget class="com.fr.report.web.button.page.Previous"/>
<Widget class="com.fr.report.web.button.page.PageNavi"/>
<Widget class="com.fr.report.web.button.page.Next"/>
<Widget class="com.fr.report.web.button.page.Last"/>
```

## 6. 单元格通用格式化

### 数据类型 → 格式映射

| 数据类型 | Format | 对齐 (horizontal_alignment) | Style 示例 |
|---------|--------|------|-----------|
| 文本 (VARCHAR) | TextFormat（无） | 居左 (1) | `<FRFont name="微软雅黑"/>` |
| 数值 (INT/DECIMAL) | `#,##0.00` | 居右 (2) | `<Format class="com.fr.base.CoreDecimalFormat"><![CDATA[#,##0.00]]></Format>` |
| 百分比 | `#0.00%` | 居右 (2) | 同上改 pattern |
| 日期 (DATE) | `yyyy-MM-dd` | 居中 (0) | 同上改 pattern |

> FR 对齐值：`0`=居中, `1`=居左, `2`=居右

### 列宽自适应

根据表头长度 + 数据类型估算列宽（FU 单位，1mm ≈ 144229 FU）：

| 类型 | FU 值 | 约等于 |
|------|-------|-------|
| 短文本 (≤6字符) | 2743200 | ~19mm |
| 中文本 (7-12字符) | 3200400 | ~22mm |
| 长文本 (>12字符) | 4267200 | ~30mm |
| 数值 | 2286000 | ~16mm |
| 按钮 | 647700 | ~4.5mm |

> 进阶：可通过数据连接查询列值的平均长度来精确调整。

### 冻结表头

```xml
<FrozenColumnRow columnrow="A1"/>
```

### 隔行换色

```xml
<HighlightList>
  <Highlight class="com.fr.report.cell.cellattr.highlight.DefaultHighlight">
    <Name><![CDATA[Alternating Row Color]]></Name>
    <Condition class="com.fr.data.condition.FormulaCondition">
      <Formula><![CDATA[row() % 2 == 1]]></Formula>
    </Condition>
    <HighlightAction class="com.fr.report.cell.cellattr.highlight.BackgroundHighlightAction">
      <Scope val="1"/>
      <Background name="ColorBackground" color="-723466"/>
    </HighlightAction>
  </Highlight>
</HighlightList>
```

### 首列纵向扩展（列表形式）

```xml
<Expand dir="0"/>
```

## 7. 需求收集清单（创建前必问）

| # | 问题 | 选项 |
|---|------|------|
| 1 | 主键是什么？ | 无 / 列出 PK 列 |
