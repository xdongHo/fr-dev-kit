﻿# 帆软报表平台 BOM 拆解（物料清单式）

> 0 级定点 = **报表平台三大组成部分：设计器 / 服务器 / 数据库**（用户 2026-08-11 定稿）。
> 1 级分支 = 各定点的界面区域/子系统；2 级 = 面板；3 级 = 组件/功能。
> 名称一律采用**用户可见名称**（设计器界面、服务器管理页、数据库对象名）；
> 技术备注（Java 类 / XML 节点 / 日志文件）仅供开发对照，不作为界面名称。
>
> 用途：平台能力全景索引 —— 查"某个功能在哪个区域、叫什么、对应什么 API / 文件"。

## 拆解原则（用户 2026-08-11 定稿）

1. **0 级定点 = 报表平台三大组成部分**：设计器 / 服务器 / 数据库。
2. **1 级分支 = 各定点界面区域/子系统**（设计器：顶部工具栏/左侧文件管理/左下数据集管理/顶部参数面板/右侧属性面板；服务器：前端管理页面/后端日志/插件等；数据库：表/视图/存储过程/方法）。
3. **3 级及以下 = 组件 → 功能**：BOM 码按 `0.x / 1.x.x / 2.x.x.x` 逐级下沉。
4. **名称 = 用户可见名称**：只写用户在界面上看到的词（报表块/图表块/下拉复选框…），Java 类名只进"技术备注"列。
5. **不包含规范外功能**：本表仅拆解平台固有能力，不做需求扩展。
