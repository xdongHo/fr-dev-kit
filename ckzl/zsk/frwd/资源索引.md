## 术语消歧：FDL ≠ FineDSL ≠ dsl/ 的报表 DSL

> 查"FDL"相关问题前先看这三行，避免被近名词条带偏。

- **FDL = FineDataLink（常称"数据工厂"；此中文名等式系间接旁证：库内官方词条仅见 FR 数据集插件
  "数据工厂数据集"doc-view-2527，无字面定义）**——帆软**独立产品线**（与 FineReport/FineBI
  并列、自带 4.x 版本号），定位数据集成/ETL：离线同步、SQL 脚本、可视化数据开发、跨数据库取数；
  FR11 可集成其「数据开发」模块做数据加工与数据集复用。查"FDL 语法错误 / FDL ETL / 数据工厂"
  类问题应去帆软官方文档 FineDataLink 产品线，本仓库知识以 FR 报表为主、FDL 产品线内容极少。
- **FineDSL**——本仓库命中的一批逆向笔记说的是它：`com.finedsl.*` 包的 "FineDSL AI Report
  Generator" 插件（自然语言 → LLM → DSL JSON → .cpt/.frm 生成报表），与 FDL 数据工厂产品线
  **无关**，仅名字相近。
- **dsl/ 目录的"报表 DSL"**——本仓库自研的 FS 报表 DSL 编译器（dsl/compile.py +
  semantic_layer.yaml），服务 示例预算表等页面生成，是第三种东西，见 `dsl/README.md`。
- **问法入口（2026-09-13 收官补，RG-021）**：「数据工厂跑批挂了 / 去哪看日志 / 怎么重跑」→ ① FDL 任务运维（日志/重跑）属 FineDataLink 产品线文档，本仓库不承载；② FR 侧工程日志位置与排查入口见 WQ-LOG-0001（%FR_HOME%\logs / LogDB），定时调度运维见 ckzl/gf/zxzt.md。
