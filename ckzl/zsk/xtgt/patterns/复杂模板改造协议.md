# 复杂模板改造协议 — 标注-确认-删除 playbook

← [返回ckzl/zsk/xtgt](../README.md)

> 来源:示例报表工程 `示例项目需求.cpt`(12.4MB / 20 sheet / 3,759 公式)改造实战,2026-08-18。
> 适用:Excel 需求簿转 cpt 后的结构定型、存量复杂模板改造、大批量区域增删。

## 五步流程总览

```
① 转换清源     Excel→cpt 后先清垃圾(空格式格/外部引用/坏命名)
      ↓
② 三色标注     黑=表头 绿=业务逻辑 灰=常量公式 —— 用户视觉确认结构
      ↓
③ 红标待删     建议删除区只标红不删,配区域清单表,用户按区号拍板
      ↓
④ 依赖扫描     公式引用关系扫描,区外引用先静态化/内联/保留
      ↓
⑤ 备份执行     .bakN 链 → 删 → XML 校验 → 断链复扫 = 0
```

## 第①步 转换清源(不做这步,后面全是噪音)

Excel 转换产物三大垃圾,处理顺序固定:

| 垃圾 | 识别 | 清法 | 实战数据 |
|------|------|------|---------|
| 纯格式空格 | `<C>` 无 `<O>`值/公式/DSColumn | 直接删除 | 82,231 格(8.2MB→2.2MB) |
| 坏 definedNames | 名字含控制字符(`\0` `\a`),值 #REF! | zip 级整段剥离 `<definedNames>` | 拆分 xlsx 全部中招 |
| 外部引用 | 公式含 `'[1]Sheet'!` | 剥 `[n]` 前缀或静态化 | 55 处 |

> openpyxl 的 `del wb.defined_names[key]` 删不净 sheet 级(localSheetId)定义名,必须 zip 级手术。

## 第②步 三色标注(结构对齐)

颜色语义见 [README §⓪](../README.md)。执行要点:

- **行列映射**:GUI 整簿转换无平移,cpt r = Excel 行 - 1;若是区间导入(fshift 平移),先算好映射再标
- **先标窄再标宽**:黑(表头)按行整行标;绿/灰按列×行区间标;维度文本列**不标**,留给用户归类
- **StyleList 追加**:三个 marker style 追加到样式表尾部,记牢 id;改 `<C s=>` 时防止 **duplicate attribute**(先删旧 s 再加新 s)
- 标注完成即报告**各色格数** + 标色规则表,请用户纠错("FS 可选列区 AJ~CR 我全给灰了,要翻绿告诉我")

## 第③步 红标确认(⓪ 级沟通的主场)

- 红底 marker 同法追加;**只改样式不动内容**
- 空格式格混入红区会让数字爆炸(本次 9.7 万红格中 8.2 万是空的)——先跑第①步或红标后清空格
- 必配**区域清单表**:区号 / sheet / 行列范围 / 格数 / 内容样例 / 判断理由 / 预案(如 J 区"保留辅助开发,后续可再删")
- 用户按区号回复(实战:"只删 A/B 两大草稿区"),绝不由 AI 替用户扩大范围

## 第④步 依赖扫描(红线步骤)

删除前必扫:**区外宿主公式是否引用区内格子**。

```
扫描:对每个公式格 → 提取 =X/Y 引用 → 行号落在删除区间?
  ├─ 区内互引   → 随区删除,安全
  └─ 区外宿主引用 → 三选一(告知用户):
       a. 静态化:公式 → 目标格缓存值(后续绑数据集时替换)
       b. 内联:  =L108 → =(目标格公式内容)
       c. 保留区域(说明该区不是垃圾,是取数暂存区)
```

实战数据:28 个可见区公式引用草稿区(`=L108` 类,行映射偏移 +75)——草稿区实为 FS 表头取数源,全部静态化后删除才安全。

> 扫描正则注意:排除 `PLH3102` 这类**科目号误报**(字母+数字但不是单元格引用),限列字母 ≤2 位 + 行号 ≤4 位。

## 第⑤步 备份执行

```
备份: <文件>.bak<N>_<YYYYMMDD>   N 递增成链,每轮破坏性操作前一份
执行: 循环内每删一个区域后【重找偏移】——文档变了,旧 offset 全部失效
      (实战踩坑:示例预算表处理后 x 长度变化,示例实际表 用旧偏移 → XML 错位拼接)
校验: expat 解析通过 + 区外引用复扫 = 0 + 各 sheet 最大行号符合预期
回滚: 校验失败 → Copy-Item bak 恢复 → 修脚本再来,不带病落盘
```

## 交付时同步(每轮)

1. 执行统计表(删了什么/多少/残留多少)
2. **台账变化**(新增/关闭/挂起,见 README §12)
3. 备份链清单 + 当前生效版本指针
4. 设计器验收指引(重新打开哪个文件、看什么)
