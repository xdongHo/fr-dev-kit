## 五、常见交互问题与解决方案

### 5.1 事件不触发
| 问题 | 原因 | 解决 |
|------|------|------|
| 事件静默失效 | 事件名写错或挂错分区 | 检查事件名是否在白名单中 |
| .frm事件无效 | body级用了`getBodyContainer()` | 用`Form.getContainer()` |
| 控件事件无效 | WebPage/WebWrite/WebView互不继承 | 确认预览方式与事件分区匹配 |

### 5.2 控件操作问题
| 问题 | 原因 | 解决 |
|------|------|------|
| `getWidgetByName`返回null | 控件名拼写错误 | 检查控件名，设计器中确认 |
| 同名控件取错 | 同名取最后一个 | 用`getWidgetsByName`获取数组 |
| 控件值设置后不生效 | `shouldFireEvent`未传 | `setValue(value, true)` |
| 移动端白屏 | 移动端不支持填报API | 使用其他方式 |

### 5.3 样式问题
| 问题 | 解决 |
|------|------|
| CSS不生效 | 用`!important`或检查选择器优先级 |
| .frm无法引用CSS | 只能通过afterinit JS注入 |
| H5端CSS不生效 | 路径必须带前导`/` |
| 加载动画消失 | 不要覆写`FR.HtmlLoader.loadingEffect` |

### 5.4 超链问题
| 问题 | 解决 |
|------|------|
| 超链跳转后无法返回 | 传`backurl`参数，子表添加返回按钮 |
| 参数传不到目标报表 | 检查参数名是否与目标模板一致 |
| 超链点击无反应 | 检查条件属性是否阻止了显示 |

### 5.5 图表前端常见坑
| 问题 | 说明 |
|------|------|
| resize引用未初始化 | wrapper中回调引用必须在inits中真正建立 |
| 重绘无防抖 | 快速连击导致错乱，需isProcessing 1秒锁 |
| IE降级白屏 | 应给可见的"环境不支持"文案 |
| 静默空图 | 数据缺失时应渲染"暂无数据"态 |
| 定时器泄漏 | DOM移除即clearInterval，参考ExtendedChart的`_checkDomExist` |

## 六、高级主题

### 6.1 决策报表(.frm) vs 普通报表(.cpt)

| 特性 | .cpt | .frm |
|------|------|------|
| 获取报表块 | `contentPane` | `_g().getWidgetByName("report0")` |
| 提交参数 | `contentPane.parameterCommit()` | `_g().parameterCommit()` |
| 引用CSS/JS | `addCSSImport`/`addJSImport` | 只能afterinit注入 |
| 切换Tab | — | `_g().getWidgetByName("tabpane").selectTab(index)` |
| body级事件 | — | `Form.getContainer().addListener(...)` |

### 6.2 Web事件名全集

#### 三预览区共有事件（34个）
`startload`、`afterload`、`beforetopdf`/`aftertopdf`、`beforetoexcel`/`aftertoexcel`、`beforetoword`/`aftertoword`、`beforetoimage`/`aftertoimage`、`beforepdfprint`/`afterpdfprint`、`beforeflashprint`/`afterflashprint`、`beforeappletprint`/`afterappletprint`、`beforeprint`/`afterprint`、`beforeimportexcel`/`afterimportexcel`、`beforeemail`/`afteremail`

#### 填报独有事件
`beforewrite`、`writesuccess`、`writefailure`、`afterverify`、`beforeverifywrite`/`afterverifywrite`、`afterwrite`、`beforeappend`/`afterappend`、`beforedelete`/`afterdelete`

### 6.3 JS挂载点

| 宿主 | 挂载方式 | 事件 |
|------|----------|------|
| 单元格控件 | `Widget.addListener(Listener)` | afterinit/beforeedit/afteredit/stopedit |
| 参数面板控件 | 同上 | 同上 |
| 模板级.cpt | `ReportWebAttr.setWebPage/setWebWrite/setWebView` + `addListener` | afterload等34个 |
| 决策报表组件 | `Form.getWidgetByName(name).addListener(...)` | 控件事件字典 |
| 决策报表body | `Form.getContainer().addListener(...)` | afterinit, click |
| 自定义工具栏按钮 | `CustomToolBarButton.setJSImpl(JavaScriptImpl)` | 无事件名 |

### 6.4 内置权限参数

| 参数 | 说明 |
|------|------|
| `$fine_username` | 当前用户名 |
| `$fine_role` | 当前角色（超级管理员=`superusers`，无角色时为空串） |
| `$fine_position` | 部门+职位JSON |

> 可在SQL/单元格公式中直接引用，实现"不同角色看不同数据"

### 6.6 图表插件前端协议

#### 五件套（FR8/9老协议）
| 方法 | 职责 |
|------|------|
| `inits` | 渲染 |
| `resize` | 容器变化时重画 |
| `refresh` | 刷新 |
| `refreshData` | 数据刷新 |
| `setData` | 设置数据 |

#### ExtendedChart协议（FR10新式）
```javascript
// 基类代劳：构造/resize/clear/自动刷新/联动AJAX/超链派发/导出
var MyChart = ExtendedChart.extend({
    _init: function(dom, chartAttr) { /* 渲染 */ },
    _emptyData: function() { /* 空数据处理 */ },
    _refresh: function(myChart, option) { /* 刷新 */ },
    _refreshChart: function(para) { /* 参数联动刷新 */ }
});
```

**选型建议**：
- 兼容FR9/10 → 老五件套
- 只针对FR10+且要联动/自动刷新 → ExtendedChart.extend（省一半代码，自带防泄漏）
- 确定形态选自绘 → 纯SVG零依赖最优
