## 二、交互设计模式

### 2.1 钻取（Drill-down）

#### 基本钻取 — 网络报表超链
```
类型：网络报表
打开方式：新窗口 / 对话框 / 当前窗口
参数传递：参数名必须与目标模板一致
```

#### JS超链钻取 — 弹窗详情
```javascript
// 点击单元格弹窗显示详情
FR.doHyperlinkByPost({
    url: "detail.cpt",
    paras: { id: this.name },
    feature: "width=800,height=600,title=详情"
});
```

#### 超链跳转后返回原报表
```javascript
// 主表超链传参：backurl = encodeURIComponent(当前报表URL)
// 子表"返回"按钮JS
var backurl = FR.cjkEncode("${backurl}");
if (backurl && backurl !== "") {
    window.location.href = backurl;
} else {
    history.back();
}
```

#### 超链跳转前判断是否有数据
```javascript
var paramValue = this.name;
$.ajax({
    url: "/webroot/decision/view/report",
    data: { op: "fr_write", reportlet: "子模板.cpt", 参数名: paramValue },
    success: function(data) {
        if (data && data.length > 0) {
            FR.doHyperlinkByPost({
                url: "子模板.cpt",
                paras: { 参数名: paramValue }
            });
        } else {
            FR.Msg.toast("该条件下无相关数据！");
        }
    }
});
```

#### 按用户权限控制超链
```javascript
var allowedUsers = ["admin", "Anna", "manager"];
var currentUser = FR.cjkEncode("${fr_username}");
if (allowedUsers.indexOf(currentUser) >= 0) {
    FR.doHyperlinkByPost({
        url: "目标报表.cpt",
        paras: { param1: this.name }
    });
} else {
    FR.Msg.alert("提示", "您没有权限访问此链接！");
}
```

#### 按行超链接（整行可点击）
```javascript
// 加载结束事件中
contentPane.on("cellclick", function(td) {
    var row = td.row;
    var col = td.col;
    var paramValue = contentPane.getCellValue(col, row);
    window.open("目标报表.cpt&参数=" + encodeURIComponent(paramValue));
});
```

### 2.2 联动

#### 参数联动 — 控件值改变触发查询
```javascript
// 控件值改变事件
(function() {
    var category = contentPane.getWidgetByName("category").getValue();
    contentPane.getWidgetByName("subcategory").setValue("");
    contentPane.parameterCommit();  // 触发查询
})();
```

#### 决策报表联动
```javascript
// 决策报表(.frm)中
_g().parameterCommit();  // 提交参数并刷新

// 获取决策报表中的控件
_g().getWidgetByName("控件名");

// 切换Tab
_g().getWidgetByName("tabpane").selectTab(index);
```

#### 图表联动刷新
```
超链类型：联动刷新
说明：与单元格中的图表联动，点击超链后图表跟随参数动态改变
适用：仪表板式多图表联动分析
```

#### 悬浮框联动

```
超链类型：悬浮框
说明：鼠标悬停时显示悬浮元素（图表/文本）

```

## 三、样式定制方案

### 3.1 CSS注入方式

#### 方式一：模板Web属性 → 引用CSS（推荐）
```xml
<CSSImport><![CDATA[help/purchase/css/purchase_v1.css]]></CSSImport>
```
- 路径相对于webroot
- 不能放在WEB-INF下
- H5端必须带前导`/`

#### 方式二：afterinit事件注入
```javascript
$(function() {
    var css = ".my-class { color: red; }";
    $("<style>").prop("type", "text/css").html(css).appendTo("head");
});
```
- .cpt和.frm通用
- .frm只能用这种方式

#### 方式三：Java API注入
```java
ReportWebAttr attr = new ReportWebAttr();
attr.addCSSImport("path/to/style.css");
attr.addJSImport("path/to/script.js");
wb.setReportWebAttr(attr);
```

### 3.2 参数面板CSS注入位置

## 四、填报交互优化

### 4.1 提交前校验
```javascript
// beforeSubmit事件
(function() {
    // 必填校验
    var value = contentPane.getCellValue(0, 2);
    if (!value || value.trim() === "") {
        FR.Msg.alert("校验失败", "订单编号不能为空");
        return false;
    }

    // 格式校验
    var amount = contentPane.getCellValue(3, 2);
    if (!/^\d+(\.\d{1,2})?$/.test(amount)) {
        FR.Msg.alert("校验失败", "金额格式不正确");
        return false;
    }
    return true;
})();
```

### 4.2 填报入库
```javascript
// 校验后提交
contentPane.writeReport(0, null,
    function() { FR.Msg.toast("提交成功"); },
    function() { FR.Msg.alert("错误", "提交失败"); }
);

// 忽略校验直接提交
contentPane.writeReportIgnoreVerify(false);

// 判断是否有未提交数据
if (contentPane.isDirtyPage()) {
    FR.Msg.confirm("提示", "有未保存的数据，确定离开？", function(ok) {
        if (ok) window.location.href = "...";
    });
}
```

### 4.3 快捷键支持
```javascript
// 加载结束事件中注册
$(document).on("keydown", function(e) {
    // Ctrl+S 保存
    if (e.ctrlKey && e.key === "s") {
        e.preventDefault();
        contentPane.writeReportVerifyCheck();
    }
});
```

### 4.4 单击进入编辑模式
```javascript
// 加载结束事件中
contentPane.setEditOnClick(true);   // 单击进入编辑
contentPane.setEditOnMove(true);    // 按键切换格子立即编辑
```
