## 0.1 必读 TOP 差异速查（最常踩的 8 个坑）

| # | 事实 | 影响 |
|---|---|---|
| 1 | `contentPane.getWidgetByCell` 只接受 `"C6"` 字符串（列字母+1基行号），传数字抛 `str.match is not a function` | 数字坐标必须先转字母 |
| 2 | `curLGP.getTDCell(col,row)` 返回**原生 DOM TD**，不是 jQuery（文档称 jQuery）；`getTDCol/getTDRow` 为 **1 基**，`getCellValue` 为 **0 基** | 混用差 1；读文本用 `td.innerText` |
| 3 | `contentPane.parameterEl` 是参数容器对象（有 `getWidgetByName`/`name_widgets`），**不是 jQuery**，无 `.width()` | 面板坐标走 DOM `.parameter-container` |
| 4 | `FR.Msg.alert/confirm/prompt` 本构建**静默无效**（无窗口无回调，无 JS 报错；有头复测同样）；`FR.Msg.toast` 可用 | 消息框改用 `new FR.Dialog` 自绘 |
| 5 | `contentPane.parameterCommit()` 干净态可用；但对参数控件编程式 `setText/setValue` 后立刻调用会抛 `TypeError: ... replace` | 赋值后延迟一拍或走查询按钮事件 |
| 6 | `setCellValue` 对**静态格无效**（no-op），只对含控件/可编辑格生效；且写入仅内存，不提交不落库 | 自动化写值先定位控件格 |
| 7 | `curLGP.moveTDCell` 等选格类方法必须**先点击选格**再调，否则抛 `ftop` TypeError | 自动化先派发 mousedown/mouseup/click |
| 8 | `isStringTypeNumber('24a')` 也返回 true — 校验比文档宽松 | 不能当严格数字格式校验用 |
