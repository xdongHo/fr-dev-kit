```
         ┌─────────┐
         │ 端到端   │  ← 浏览器全流程: 登录→查询→填报→提交→验证数据

         └─────────┘
```

## 快速入口

| 测试类型 | 什么时候做 | 核心命令 |
|---------|-----------|---------|
| XML 合法性 | 每次修改 .cpt 后 | `python -c "import xml.etree.ElementTree as ET; ET.parse('file.cpt')"` |
| 浏览器预览 | 功能开发完成后 | `http://localhost:8075/...viewlet=路径.cpt&op=write` |
| 填报提交 | 填报模板交付前 | 浏览器填报→提交→查数据库验证写入 |
| 级联参数 | 有级联控件时 | 父选值→子控件是否联动刷新 |
