# 模板验证清单

← [返回ckzl/zsk/csff](README.md)

> 每次生成或修改 .cpt 后，逐项检查。配合ckzl/zsk/xtgt框架 §9 验收标准对照使用。

---

## 一、XML 合法性（自动验证）

| # | 检查项 | 方法 | 通过标准 |
|---|--------|------|---------|
| 1 | XML 解析 | `python -c "import xml.etree.ElementTree as ET; ET.parse('file.cpt')"` | 无 ParseError |
| 2 | ParameterUI 配对 | 计数 `<ParameterUI` 和 `</ParameterUI>` | 各出现 1 次 |
| 3 | Layout 闭合 | 计数 `</Layout>` | 出现 1 次 |
| 4 | 无重复 WidgetName | 参数面板内 WidgetName 去重 | 无重复 |
| 5 | 无 `$$` 双美元符 | 正则搜索类名属性 | 零匹配 |

## 二、结构完整性

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 6 | TableDataMap | 填报表有、导入表无（不使用自闭合） |
| 7 | 数据集数量 | 6 字典 + 1 主数据 = 7 |
| 8 | 级联 SQL | 包含 `${if(len(para_...)` 且 ORDER BY 在其后 |
| 9 | ReportWriteAttr | 在 `<Report>` 内部，CellElementList 之后 |
| 10 | FrozenColumnRow | `columnrow="A1"` 冻结表头 |

## 三、功能验证（Designer 填报预览）

| # | 检查项 | 操作方法 | 通过标准 |
|---|--------|---------|---------|
| 11 | 模板加载 | Designer 打开 .cpt | 无错误弹窗 |
| 12 | 参数面板 | 填报预览后查看 | 控件按指定顺序排列 |
| 13 | 级联联动 | 选父控件值 → 查看子控件 | 子控件选项更新 |
| 14 | 数据查询 | 选择筛选条件 → 点查询 | 历史数据正确加载 |
| 15 | 填报编辑 | 点击非主键列单元格 | 可编辑；主键列只读 |
| 16 | 新增行 | 点击 add 按钮 | 新行出现，可编辑 |
| 17 | 删除行 | 点击 delete 按钮 | 当前行移除 |
| 18 | 提交 | 填写数据 → 点提交 | 数据入库，页面刷新 |
| 19 | 导出 | 点击导出按钮 | Excel 下载 |
| 20 | 导入弹窗 | 点击导入按钮 | 弹窗正确打开导入页面 |

## 四、样式检查

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 21 | 字体 | 全部微软雅黑 |

| 24 | 隔行换色 | 奇偶行交替背景色 |

## 使用方式

### 自动验证（第 1-10 项）

```powershell
# 用 ad-hoc Python 脚本验证
python <verify_script>.py <path_to_cpt>
```

### 人工验证（第 11-25 项）

在 FR Designer 中打开模板 → 工具栏 → 填报预览 → 逐项检查。
