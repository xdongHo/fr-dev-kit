# 参数面板布局自动化规范（Ver0.7）

> Ver0.7 变更：新增「水印式自动布局算法」（X/Y 区块规则，用户定稿 2026-08-05），
> 并落地为脚本 `auto_layout_watermark.py`。
> Ver0.5 变更：明确「水印无 Label」为**默认方案**，Label 式为逻辑分支。
> 背景：级联筛选面板（ComboCheckBox/YearControl + watermark）成为主流，无需 Label 控件。

## 方案选择

| 方案 | 结构 | 适用 |
|------|------|------|
| **水印式（默认）** | 无 Label 控件，`watermark` 作提示；纯输入控件均布网格 | 新开发一律默认（级联筛选面板：示例映射A、示例明细表B等） |
| **Label 式（分支）** | Label + 输入控件配对 | 仅改造存量 Label 模板时使用 |

两种方案共用：控件 180×26、组间 20px、内边距 12px、≤1500 单行。

## 控件尺寸

| 类型 | 宽 | 高 |
|------|-----|----|
| Label（标签，仅 Label 式） | 自适应（≥40px） | 26 |
| 输入控件（ComboCheckBox/DateEditor/TextEditor 等） | 180 | 26 |
| **YearControl（年份）** | **100**（4 位数字足够，2026-08-05 用户定稿） | 26 |
| 按钮（Y 区块，Ver0.7） | **max(80, 中文×15 + 字母符号×8)** | 26 |

## 间距

| 关系 | 间距 |
|------|------|
| Label → 控件（仅 Label 式） | **5px** |
| 控件组间 / 区块间 | **20px** |
| 行间距（Ver0.7） | **10px**（旧 8px 已废弃） |
| 面板内边距 | **12px** |

## 区块模型自动布局算法（Ver0.7，默认方案唯一权威）

**区块概念（用户定稿）**：区块是兼容 Label 的布局单元——同一套算法，按是否有 Label 切换三种形态：

| 形态（--mode） | 区块宽 | 区块高 | 组成 |
|---------------|--------|--------|------|
| **watermark（无 Label，默认）** | **200**（180+20） | 26 | 控件 |
| **label-h（Label 在左）** | **300**（100 Label + 180 控件 + 20 留白） | 26 | Label 100 左 + 控件右 |
| **label-v（Label 在上）** | **200**（180+20） | **40**（上 14 Label + 下 26 控件） | Label 上 + 控件下 |

**网格对齐原则（用户定稿）**：区块是**网格单元**——列 x = `MARGIN + col×区块宽`（watermark/label-v 每列 200、label-h 每列 300），**跨行同列左对齐、控件底部对齐**；控件在区块内可窄化（YearControl=100 靠左，区块内右侧留白），但区块网格不收缩、不随控件实际宽累加（修正 2026-08-05：早期"行内按实际宽累加"破坏列对齐，废弃）。

**Y 区块**（按钮/超链接，Label 除外）：宽 `max(80, 中文×15 + 字母符号×8)`（"Import[Excel]A"=14×8=112），间隔 20，行高 26；label-v 模式下 Y 与控件垂直对齐（y 偏移 +14）。

**算法**：
1. ΣX区块 + ΣY区块 < **1500** → 全部放一行
2. 否则按单元数分行：数量规则（<15→5/行，≤24→6，>24→7）与**宽度上限**取小：
   `每行单元数 = min(数量规则, floor((1500−2×12) ÷ 最大区块宽))`（如 label-h 每行最多 4 个，5×300=1500 不满足 <1500）
3. 最后一行剩余空间 = (每行单元数 − 最后一行单元数) × 200（标准区块估算）；
   若 `(最后一行单元数×200 + ΣY区块) < 每行单元数×200` → **Y 并入最后一行**贴右；否则 Y 新行右对齐；面板宽 = max(行右缘) + 12
4. 行间隔：watermark/label-h = **10**，label-v = **20**（区块间留白）

**全局约束（用户定稿）**：
- **每行最宽 < 1500**（宽度上限已内置于步骤 2）
- **总高度 < 300**：布局后检查，超限打印 `⚠️ 超总高 300 约束！`（watermark 约 7 行、label-v 约 4 行为安全上限）

**边界修正（实现时）**：单元数整除每行数（余数 0）→ 最后一行已满，Y 强制新行；Y 区块宽含尾间隔，摆放时最后一个贴右缘去掉尾间隔；label-h/v 模式无 Label 可配对时自动退化 watermark。

> 实现：`auto_layout_watermark.py <cpt> [--mode watermark|label-h|label-v] [--dry-run]`（坐标级安全修改，不碰 CDATA/JS）。

## 布局算法（Label 式，分支，旧版）

1. 计算总宽 → ≤1500 单行，>1500 分行（按组宽自适应）
2. 按钮右对齐：以所有行最大右边缘为基准，从右往左（Import 最右、其次 Export/Query）
3. 面板宽 = 所有行最大右边缘 + 12
4. 行 y 序列：`MARGIN, MARGIN+(CTRL_H+ROW_GAP), ...`

## 列对齐（水印式）

1. 每行控件 x 均布：`MARGIN + col*(CTRL_W+CTRL_GAP)`（13, 213, 413, …）
2. 同列控件左对齐

## 列对齐（Label 式，分支）

1. 跨行取每列最大 Label 宽度
2. 同列 Label 左对齐，Combo 左对齐
3. Label >180px → 放控件顶部

## 参考常量

```python
# Ver0.7 区块模型自动布局
CTRL_W, CTRL_H = 180, 26
X_W_BY_CLS = {'YearControl': 100}   # 窄控件：年份 4 位数字 100 够，其余 180

X_BLOCK_DEF = 200       # 标准区块（Y 并入的剩余空间估算）
Y_MIN_W, Y_CJK_W, Y_ASCII_W = 80, 15, 8   # Y = max(80, 中文×15 + 字母符号×8)
Y_GAP = 20
ROW_GAP, ROW_GAP_V = 10, 20         # 行间隔：watermark/label-h=10，label-v=20
MARGIN = 12
SINGLE_ROW_MAX, PANEL_H_MAX = 1500, 300   # 全局约束：每行宽<1500，总高<300
PER_ROW = {5: 'X<15', 6: '15≤X≤24', 7: 'X>24'}

# 旧 Label 式
LABEL_GAP, CTRL_GAP, BTN_GAP = 5, 20, 40
ROW_H = 26
```
