# WebKit 页面快速体检工具 · 开发方案
# 生成: 2026-09-04 · 定位: DSL 编译链路的"运行期体检层"
# 状态: ✅ v1.0 已交付（P0+P1 全部 + P2 部分；坏页实弹验收 PASS；迭代日志见 README.md）
#
# ══════════════════════════════════════════════════════════════
# 一、要解决的问题（为什么静态检查不够）
# ══════════════════════════════════════════════════════════════
# 现有链路三层都是"落盘前"的：guardrails(引用/权限/SQL) → fr_check(结构/官方规则) → --smoke(SQL 执行)。
# 模板真正在浏览器里跑起来之后的问题，目前只能靠人肉：
#   1. 页面级 JS 执行报错（未捕获异常、console.error）
#   2. FR 数据集错误弹窗 / 加载遮罩卡死 / 空表格（SQL 对但页面渲染不出来）
#   3. 元素布局错乱：参数面板控件重叠/越界/零尺寸、label 错位、单元格文本溢出
#   4. 超链链路（主表→科目下钻弹窗）能不能点通
# fr_check --browser 现状 = 输出一段 JS 让人手动贴 console —— 半自动，未闭环。
#
# ══════════════════════════════════════════════════════════════
# 二、技术选型（2026-09-04 实测本机就绪）
# ══════════════════════════════════════════════════════════════
# Playwright (sync API) + chromium headless：
#   ✅ Python311 已装 playwright，chromium 可启动（实测 launch OK）
#   ✅ 事件全：pageerror(未捕获异常)/console/requestfailed，元素 boundingBox，截图
#   ✅ FR 服务器 localhost:8075 在线（/webroot/decision → 302 正常入口）
#   备选 selenium（也装了）不选：无 pageerror 事件、auto-wait 弱。
#
# ══════════════════════════════════════════════════════════════
# 三、架构
# ══════════════════════════════════════════════════════════════
# web_kit/
#   probe.py            # CLI 主入口（唯一命令，与 fr_check 同风格）
#   checks/
#     entry.py          # HTTP/入口/登录态/耗时
#     runtime.py        # JS 异常/console/FR 业务错误信号
#     widgets.py        # 参数面板体检（P1：重叠/越界/零尺寸/错位）
#     grid.py           # 表格体检（P1：行列数/行高采样/文本溢出）
#     links.py          # 超链弹窗冒烟（P2）
#   report.py           # md+json 报告，落 _runs/webprobe/<时间戳>_<页面>/
#   baseline.yaml       # 误报基线（沿 fr_check 三族理念：已知噪声按页登记，正则匹配豁免）
#
# CLI（草案）:
#   python web_kit/probe.py <cpt路径|完整URL> [--params k=v ...] [--op write]
#                          [--layout] [--links] [--batch <目录>] [--timeout 30]
#   退出码 0=干净 / 2=仅警告 / 1=有错误（与 fr_check 对齐）
#
# 认证与URL：
#   - 首次自动登录（凭据取 kfgj/env.md / 帆软资源索引，账号 frdev1），
#     storage_state 缓存到 _runs/webprobe/state.json 复用，过期自动重登
#   - cpt 路径 → http://localhost:8075/webroot/decision/view/ReportView?viewlet=示例报表工程/明细报表/<名>
#     参数从 semantic_layer.yaml SMOKE_DEFAULTS 取默认，--params 覆盖
#
# ══════════════════════════════════════════════════════════════
# 四、检测项清单（判定逻辑）
# ══════════════════════════════════════════════════════════════
# P0 打开即测（0.5 人日）——不需要语义层，任何 cpt 可测：
#   1 入口: 最终URL/状态码/是否被踢到登录页/加载耗时>10s 记 WARN
#   2 JS: pageerror 未捕获异常=ERROR；console.error 逐条收集(基线豁免)
#   3 FR 信号: 数据集错误弹窗(DOM 文本含"错误/Exception")、加载遮罩 >timeout 未消失=卡死、
#     ErrorMarkWidget 实例数（复用 fr_check check_browser_signals 的探针 JS，改为自动执行）
#   4 渲染: 报告区 iframe 存在、表格行数>0（空 grid=ERROR）、分页控件存在
#   5 截图: 全页 PNG（人工/审阅 agent 直接看图定位）
#   6 报告: 每条错误带证据（console 行原文/选择器/截图锚点），md+json 双格式
#
# P1 布局与参数（0.5 人日）：
#   7 面板体检: 逐控件 boundingBox → 两两重叠相交=ERROR、越出面板宽=ERROR、
#     宽或高=0=ERROR、label 与控件 y 差>4px=WARN
#   8 表格体检: 行高采样 vs cpt 声明 RowHeight（±5%）、列宽数、
#     单元格文本溢出(scrollWidth>clientWidth+2) 计数=WARN
#   9 参数注入: 默认参数自动填→触发查询→等刷新→复测 3/4 项（空参和带参各测一遍）
#   10 op=write: 填报页可写控件抽查（ tyranny 控件存在+未禁用 ）
#
# P2 链路与集成（0.5~1 人日）：
#   11 超链冒烟: 定位第一个挂 NameJavaScript 的格子→点击→捕获弹窗 URL→对子页递归跑 P0（限一层）
#       ——自动验证 科目下钻/Comments/ADJ 全链路
#   12 批量: --batch 扫目录全部 cpt，输出 体检矩阵（页 × 检测项）
#   13 diff: 同页两次体检的截图+DOM 指标对比（改造前后回归）
#   14 集成: compile.py 加 --probe（落盘→部署→体检一条命令）；README SOP 增"交付前必跑"
#
# ══════════════════════════════════════════════════════════════
# 五、误报治理（关键，沿用三族教训）
# ══════════════════════════════════════════════════════════════
# - 首批先对 4 存量页（两主表+两下钻）跑 P0/P1，把 FR10 固有噪声（如埋点请求失败、
#   字体告警）登记进 baseline.yaml，之后新错误才有意义
# - 每条报告错误必须带机器证据，可定性可复现；禁止裸文本"可能有问题"
#
# ══════════════════════════════════════════════════════════════
# 六、验收标准
# ══════════════════════════════════════════════════════════════
#   A. 4 存量页 P0+P1 通过，错误清单全部可定性（对照 baseline）
#   B. 构造 2 个坏页逐一被拦：①数据集引用不存在→抓到错误弹窗/空grid（guardrails 拦不住的运行期问题）
#      ②面板控件故意重叠→抓到 overlap
#   C. P2: 主表点击科目名→下钻弹窗自动走通并出子页报告
#   D. 全链路演示: compile.py --smoke --probe 一条命令从 DSL 到页面体检报告
#
# ══════════════════════════════════════════════════════════════
# 七、风险与前置
# ══════════════════════════════════════════════════════════════
# - FR10 页面是 iframe 套壳：probe 必须遍历 page.frames 找报告区（递归到含 .sheet 容器的 frame）
# - 大模板加载慢：等待条件用"加载遮罩消失"而非固定 sleep，超时可配
# - 登录：内网无验证码（若有，走 storage_state 人工登一次缓存）
# - 端口冲突/服务器未启：probe 前置探活，给出明确启动提示
#
# 工作量: P0 0.5d + P1 0.5d + P2 0.5~1d ≈ 1.5~2 人日（可按包拆会话，P0 独立可交付）
