# SN-02 架构与生命周期设计（S2 设计）

**类型**：标准节点（确定性）｜**拦截**：P08 生命周期状态失效（复发链）、P09 命名空间冲突（设计侧复核）、P11 POI lite schemas、P14 单一布尔早退、P22 Swing 四坑、P23 范围失控（设计侧兜底）
**输入**：身份表+范围卡｜**输出**：架构一页纸 + 生命周期矩阵 + 依赖实证清单（D2 用户确认架构形态）

## 检查清单

### 2.1 生命周期矩阵（P08，三行必填，填不出=设计没想清）

| 事件 | 状态存哪 | 恢复策略 | 本插件答案 |
|---|---|---|---|
| FR/设计器重启 | — | — | （例：token 失效→重取链，demo_plugin_repo WP5） |
| 插件重载（类加载器更换） | — | — | （例：static 全清→草稿 2s 防抖落盘 `~/.<名>_draft.txt`，aicopilot v0.11.0） |
| 独立进程（如有）生命周期 | — | — | （例：跟随设计器退出；版本协商 /ping+shutdown，aicopilot v0.12.1/v0.12.12） |

- [ ] 每行"状态存哪"优先答**文件**（`~/.<名>/`），static/内存必须有防抖落盘或可重建说明
- [ ] 有独立进程 → 版本协商设计在场（`/ping` 返回版本 + 版本不符自动换新）

### 2.2 依赖实证（P11）

- [ ] 每个 FR/三方依赖的关键类**先 javap 后写码**：`javap -cp <jar> com.fr.xxx.Y`（demo_plugin_repo POI lite schemas 缺 CTTblW/CTTcW 编译期才暴露；aicopilot"全程 javap 实证无一臆测"为正面基准）
- [ ] 依赖清单落盘：jar 名 → 用途 → 已实证类列表（放 `docs/依赖实证.md`）
- [ ] lite schemas 类缺失预案：XmlCursor 裸写 or POI 字符串 API（demo_plugin_repo 实测路径）

### 2.3 交互与渲染设计红线（P14/P22）

- [ ] 判定逻辑禁单一布尔早退（P14：zTree isParent 早退丢实体报表；改用"节点有 path"类语义判据）
- [ ] Swing 专项（如涉及）：窗口必须有 owner；子窗继承 alwaysOnTop；EDT 上禁同步 IO（树渲染零 IO，用内存缓存+TTL）；拖拽/双击用 AWT 全局事件监听兜底（P22 四坑全部来自示例插件A实测）
- [ ] 生成视觉物的验证方式在设计期就写死（截屏像素采样/双客户端，见 SN-10）

### 2.4 架构一页纸

- [ ] 命名空间六冲突点复核（P09）：插件 ID / Spring 路径 / HttpHandler 段名 / 前端 shortcut / 配置目录 / 菜单 id 与既有插件逐一比对不撞
- [ ] 模块图（谁挂载、谁提供端点、谁渲染 UI、数据流向）
- [ ] D2 决策记录：用户确认的形态（单进程/跨进程、商业层有无、依赖集）

## 反例

- P08：demo_plugin_repo token 失效只影响运维（有手册兜底），aicopilot static 清空直接丢用户草稿——**设计期一行矩阵就能预防的 bug，运行期用三个版本才修完**。
