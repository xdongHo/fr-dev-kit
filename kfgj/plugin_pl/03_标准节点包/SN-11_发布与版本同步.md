# SN-11 发布与版本同步（S5 打包 / S6 发布）

**类型**：标准节点（确定性，机器检查）｜**拦截**：P05 复发链（版本多处不同步）、P08(半) 版本协商、P25 旧进程静默
**输入**：发布物（jar/plugin.xml/资源）｜**输出**：版本核对记录 + 发布冒烟记录｜**机器检查**：sn_gate `C07`

## 检查清单

### 11.1 版本同步（P05，机器闸）

- [ ] **版本号单一事实源 = plugin.xml**，其余位置（PetApp.VERSION 式常量、build 脚本 DIST/VERSION、前端页头版本）全部列入 `C07` 版本对，发版前机器核对全等
- [ ] demo_plugin_repo 口径：`plugin.xml version + change-notes` 与 `build.sh DIST/VERSION` 三处同步；aicopilot 口径：`PetApp.VERSION 与 plugin.xml 同步改（版本协商 /ping 用它）`
- [ ] `change-notes` 写清本版变化（升级用户在插件管理器能看到的第一信息）
- [ ] **版本协商必备**（有独立进程/前后端分离时）：`/ping` 返回版本 + 版本不符自动换新（aicopilot v0.12.12：旧进程无新端点 → "半好半坏"错觉，404 静默极难排查）
- [ ] 前端版本号显示真实宠物/插件版本（页头版本号=真实版本，v0.13.3 教训）

### 11.2 发布物检查

- [ ] jar 内资源路径按 SN-03 总表复核（斜杠形式、无前导斜杠）
- [ ] dist 形制 `plugin-<id>-<ver>/`（plugin.xml + jar + 依赖 jar + 字体）；依赖 jar 随包（demo_plugin_repo 形制）
- [ ] 升级路径：旧版**只删 plugin.xml 再删目录**；jar 被运行中设计器锁定属正常，孤儿无害（aicopilot 部署速查）

### 11.3 发布后冒烟（S6 退出标准，每轮 15 分钟内跑完）

- [ ] 设计器重启 → 插件加载无报错 → 核心入口出现
- [ ] 核心端点三连：健康端点 200 / 权限外 403 协议正确 / 未知参数 404 + 机器可读 code
- [ ] 真浏览器走一遍主入口（与 SN-08 G-BROWSER 同链路，发布环境再跑一次）
- [ ] 版本协商验证：旧进程自动换新 or 明确提示升级
- [ ] 回滚预案确认：保留上一版 jar（SN-06 白名单）；发布记录含"回滚=重装上一版"一步话说明

## 反例

- P05：aicopilot 0.13.8 vs 0.13.14 双版本并存——版本协商拿旧号，用户看到的"升级成功"是假的。
- P25：v0.12.4 网页功能全失效的真因=旧宠物进程没有新端点（聊天能用造成半好半坏错觉）——版本协商上线后此类问题归零。
