## 检查清单

### 12.1 机器终跑（不可跳过，对齐 AGENTS.md STEP 7 / EXEC_CONTRACT 哲学）

python kfgj/plugin_pl\scripts\sn_gate.py --config <工程>\sn_gate.config.json --report <工程>\_runs\sn_gate_report_<日期>.md

### 12.2 台账回写（P 复发的治理闭环）

- [ ] 本期新问题 → 按 `08_知识沉淀判定.md` 定性后**先入台账**（自建 `~/.fr_dev_kit/experience/` 复盘台账：现象/根因类/拦截节点/机制），再散记任何文档
- [ ] 旧问题本期**复发** → 台账该行加复发记录（版本/日期/出处），状态保持 OPEN 并复盘"为什么节点没拦住"→ 修补节点检查项
- [ ] 旧问题本期**零复发** → 状态保持 MITIGATED（CLOSED 需连续 2 个新插件零复发，不由单次判断）

### 12.3 知识沉淀（衔接 AGENTS.md STEP 6 知识回路）

- [ ] 强制定性：新知识六选一（新错误对/新 API 实证/新工具脚本/纠错/新配方/无）——"无"也写一行结论
- [ ] 定性为"是"→ 按 `08_知识沉淀判定.md` 的增改流程落库（单一事实源、KB_INDEX 头、jcxt/js 两个 build 增量、项目经验回写 ~/.fr_dev_kit/experience/ 可选）
- [ ] 节点知识增改：改 SN 文档必须 bump 流水线版本号并在文末记录（版本/日期/变更摘要/触发的台账 ID）

### 12.4 归档产物（D5 用户确认范围）

- [ ] 交付记录（版本时间线：主题/核心内容/踩坑——demo_plugin_repo README §2 版本表为模板）
