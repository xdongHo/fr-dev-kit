# SN-05 键与路径归一化（S3 开发）

**类型**：标准节点（确定性，清单+单测）｜**拦截**：P02 复发链（demo_plugin_repo normKey / aicopilot 反斜杠-正斜杠锁定失效）
**输入**：键清单（哪些语义键会跨模块比较）｜**输出**：唯一 normalize 函数 + 往返单测

## 检查清单

- [ ] **每个语义键（路径/表名/ID）只有一个 normalize 函数**，写在一个工具类里，全工程 import 它——禁止两侧各自"随手 toLowerCase/replace"
- [ ] 键登记表落盘（`docs/键清单.md`）：键名 → 出现位置（存储侧/查询侧） → normalize 规则（小写？剥 schema 前缀？`\`→`/`？）
- [ ] **往返单测**（模板见下）：覆盖 `\`↔`/`、schema 前缀（`finereport.x` vs `x`）、大小写、重复归一幂等
- [ ] 跨进程共享键文件（如 locks json）→ 双进程 import 同一 normalize（无共享代码时，宠物/网页侧请求一律发原始路径，由唯一一侧归一）
- [ ] 归一化键做**集合成员/前缀匹配**时，单测加一条 `startsWith` 正反例（P02 实锤失效模式）
- [ ] 缓存/持久化结构变更 → **bump CACHE_VER**（demo_plugin_repo CACHE_VER=3 实战：版本不符整体作废重析，一次成本换一致性）

## 往返单测模板（Java）

```java
// NormalizeTest.java —— P02 复发链回归（三用例缺一不可）
assertEquals(Norm.key("Fin_报表.CPT"),  Norm.key("fin_报表.cpt"));          // 大小写
assertEquals(Norm.key("C:\\a\\b\\x.cpt"), Norm.key("C:/a/b/x.cpt"));        // 斜杠族
assertEquals(Norm.key("finereport.t1"),   Norm.key("t1"));                   // schema 前缀
assertEquals(Norm.key(Norm.key(k)),       Norm.key(k));                      // 幂等
// startsWith 语义：锁前缀 "R:" 远程键与本地键不串（aicopilot v0.13.2 R: 键设计）
assertFalse(Norm.key("R:/a.cpt").startsWith(Norm.key("C:/a.cpt")));
```

## 反例

- P02：demo_plugin_repo 血缘图同表双节点（`finereport.x` vs `x`）；两年内同根因在 aicopilot 复发为"锁定判定全失配且静默"——**静默失效是这类 bug 的共同特征**，没有往返单测就等于没有防线。

- [ ] **键域登记表**（P32，B 代理实践）：同一工程允许多套合法 normalize，但必须按键域登记——表键域（normKey：小写+剥 schema 前缀）vs 路径键域（normalize：反斜杠归一）。往返单测用例必须按键域分组写，禁止混域断言。
