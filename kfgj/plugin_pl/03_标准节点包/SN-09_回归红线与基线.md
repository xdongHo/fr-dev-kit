## 基线比对命令模板

```powershell
# 字节等价（豁免行先过滤再比对）
$exc = '生成时间|Generated at'
$a = Get-Content baseline_v2.0.0.md | Where-Object { $_ -notmatch $exc }
$b = Get-Content current.md          | Where-Object { $_ -notmatch $exc }
Compare-Object $a $b   # 空 = 等价通过
```
