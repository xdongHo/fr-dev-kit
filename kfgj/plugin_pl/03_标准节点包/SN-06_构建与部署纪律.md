# SN-06 构建与部署纪律（S3/S5）

**类型**：标准节点（确定性，机器+清单）｜**拦截**：P06 清理破坏运行资产（复发链）、P15 javac 旧类假错误、P16 批量改源码三陷阱
**输入**：构建脚本｜**输出**：白名单化 build 脚本 + 部署链｜**机器检查**：sn_gate `C11`（删除策略扫描）

## 检查清单

### 6.1 清理白名单（P06 复发链，一次事故都不许再出）

- [ ] **清理只删可再生构建产物**（build/classes、dist），**绝不删 jar 与 lib**（aicopilot v0.13.7：清理删掉 spawn 引用 jar → 宠物找不到主类；确立"只删 plugin.xml 保留 jar 作回滚资产"）
- [ ] 大目录删除**一律 mv 到 `.trash/<时间戳>/`**，不 `rm -rf`（demo_plugin_repo：129 文件触发 safe-delete 弹窗后台中止；mv 不触发；`.trash/` 入 .gitignore 定期清）
- [ ] 动 plugins 目录前**先停 FR**（运行中 jar 被锁，mv 失败需 WARN）
- [ ] 部署链固定（demo_plugin_repo 实战模板）：
  ```
  js/css only : cp → jar cf → cp 到 plugins → 重启设计器(35-45s 轮询 8075) → 重取 token
  Java only   : javac(cp lib/*) → jar cf → cp → 重启
  全量        : build.sh（Git Bash + JDK8 + FR_LIBS + C:/frjars + 字体）
  ```
- [ ] jar 打包**在 classes 目录内执行**保证无多余顶层目录：`(cd build/classes && jar cf ../x.jar .)`

### 6.2 编译纪律（P15）

- [ ] 增量编译**显式列出改动源文件**（旧 class 优先于 -sourcepath 新源码 → "构造器歧义"假错误），或直接全量 clean 构建
- [ ] 编译失败**先 git checkout 回滚再重来**，禁止在损坏文件上继续打补丁（demo_plugin_repo HtmlGenerator 两次损坏教训）

### 6.3 批量改源码纪律（P16）

- [ ] 禁按行号盲改：用 marker/结构锚点定位；写脚本前先 `print(repr(line))` 确认真实字符形态（`\"` vs `"`、全角字符）
- [ ] 多点插入**从后向前**处理（防行号漂移）；XML 类结构用标签计数定位（`<section` 计数归零法）
- [ ] 改完先跑括号平衡扫描（`{}`/`()` 配对）再编译

## 反例

- P06：demo_plugin_repo `rm -rf` 中止构建是小事，aicopilot 删 jar 直接让公仔消失且与用户重启时序竞争——**同一根因（删除无白名单）从烦人升级成事故**。
- P15/P16：demo_plugin_repo v2.1.1 i18n 批量改造两次损坏源文件，靠"回滚重来+结构化定位"收敛。
