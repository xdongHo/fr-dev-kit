# SN-08 测试与沙箱（S4 自测）

**类型**：标准节点（确定性，机器单测 + attest）｜**拦截**：P01 复发链（G-BROWSER）、P13/P18/P20/P21/P24/P25/P26
**输入**：测试计划｜**输出**：单测+e2e+沙箱配置+G-BROWSER 留痕

## 检查清单

### 8.1 单测（不依赖 FR 运行时，合成 fixture）

- [ ] **合成 fixture** 启动时动态生成、跑完自动备份/还原用户态文件（demo_plugin_repo：6 个合成 cpt/frm + 备份还原 `~/.demo_plugin_repo`，46 项断言）
- [ ] 结构契约断言（P18 正面案例：bounds 子 Map、SQL 归一化——单测首轮抓出两真 bug）
- [ ] 工具 schema 契约测试（P20）：LLM 工具/对外 API 的 schema **完整平铺**+缺省值+非法值三组用例（空 schema 白烧 5 轮的教训）
- [ ] LLM 供应商协议用例（P24）：content=null 归一、tool_call_id 补全、reasoning_content 不入历史
- [ ] 无头双模式（aicopilot TestV09x 口径）：`unit`（离线）/`e2e`（真 key 真链路），基线 JSON 落盘

### 8.2 e2e 沙箱隔离（P21，红线级）

- [ ] 任何会写盘的 e2e：**临时 reportletsPath + 只含沙箱的隔离 locks + 用户态文件（properties/locks/sessions）备份-还原**
- [ ] e2e 失败处理沿用重派纪律（B10）：原道重试 1 次 → 换道 1 次 → 两败即止记台账
- [ ] 真实数据 e2e（P13）：用真实工程数据跑一遍核心断言（demo_plugin_repo 用 1108 模板实测脏链接/挂载树）
- [ ] FineUI/树类判据（P14）：禁 `isParent` 等单一布尔早退（实体报表 isParent=true 会丢预览入口——判据用"节点有 path"）；DOM 注入只走 `view.addDiyDom`（zTree 渲染的树不实例化 LeafItem）

### 8.3 G-BROWSER 浏览器路径实测闸（P01 复发链，attest 型——本节点灵魂）

- [ ] **凡是"命令行/无头测不出"的链路，必须起真实环境人工/自动化浏览器走一遍**：
  1. 起 FR（designer.bat 内嵌 8075）→ 轮询就绪 → 登录取 token（`POST /webroot/decision/login/cross/domain`）
  2. 真浏览器（Playwright 分段 evaluate / cookie 预注入跳过 login）走**每个面向用户的入口**：菜单出现、页面加载、按钮触发、POST 真实到达（看服务端副作用，不看前端提示）
  3. Playwright 纪律：cookie 预注入防跳转销毁上下文；每段独立 evaluate，`window.__fw` 跨段传 widget；reload 是 unforgeable——拦截点击观察导航即证据
- [ ] **前端错误可见化**（P25/P26）：window.onerror 上状态条；fetch 封装检查非 200/网络错误并提示；操作后**局部更新**保持用户状态（整树重载丢展开态=用户以为没生效）
- [ ] attest 格式（对齐 kfgj/guard.py 声明机制）：收尾报告写 `--attest G-BROWSER <日期> <入口清单>`，未声明 = FAIL
